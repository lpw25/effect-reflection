\begin{abstract}
  Programming languages increasingly support algebraic effects and
  handlers for writing effectful code in a principled way by temporarily
  extending the language with additional effectful operations. However,
  integrating effects into type systems typically requires specialized
  effect systems that add complexity to the language.

  We introduce \emph{effect reflection}, an alternative presentation of
  algebraic effects and handlers that provides, for any algebraic
  signature $\Sigma$ and type $\tau$, an isomorphism:
  \begin{equation*}
    \ind{\Sigma}(\tau)
    \qquad \cong \qquad
    \yoneda{\Sigma} \arr \glob \tau
  \end{equation*}
  where:
  \begin{itemize}
  \item $\ind{\Sigma}(\tau)$ is the free algebra of $\Sigma$ at $\tau$,
    sometimes called the \emph{freer monad} of $\Sigma$.
  \item $\yoneda{\Sigma}$ is a type representing how to inject operations of
    $\Sigma$ into the current \emph{ambient monad}: the monad describing
  which effects ordinary functions can perform.
  \item$\glob$ is a comonadic \emph{global modality} used to track which values do not
  depend on the ambient monad.
  \end{itemize}
  This isomorphism emerges naturally, as a corollary of the Yoneda
  lemma, from the \emph{Ambient Monad model}: a novel semantic model of
  algebraic effects in terms of presheaves over Lawvere
  theories.

  Effect reflection provides all the expressiveness of typed algebraic
  effects without requiring language-level support for an effect system. We
  demonstrate this by implementing effect reflection as a library in
  OxCaml.
\end{abstract}

\section{Effect reflection and the Ambient Monad model}
Algebraic effects and effect handlers have emerged as a powerful
approach to structured programming with effects. However, integrating
effects into type systems typically requires adding specialized effect
systems. Unfortunately, such effect systems require extensive effect
annotations even for functions that do not use algebraic effects. This
limits the wider adoption of algebraic effects into mainstream
languages.

Recent work, in particular Brachth{\"a}user et
al.~\cite{brachthauser2022effects} and Tang et al.~\cite{tang2025modal},
improves the situation by lowering the annotation burden for functions
not using effects. However, these systems still require specialized type
system support. Can we get the benefits of algebraic effects and
handlers without the need for specialized type system support?

One of the attractive properties of algebraic effects is their elegant
mathematical model. However, these more recent approaches do not come
with such a model. Can we give a simple semantic model of algebraic
effects that justifies our design?

\subsection{Algebraic effects and effect handlers}
\label{sec:handlers}
Algebraic effects and effect handlers allow the programmer to
temporarily extend the set of available effectful operations.

For example, in OCaml, one can write:
\begin{lstlisting}[style=oxcaml]
    type 'a Effect.t +=
      | Get : int Effect.t
      | Set : int -> unit Effect.t
  
    let handle_state (f : unit -> 'a) : int -> 'a =
      match f () with
      | x -> fun _ -> x
      | effect Get, k -> fun s -> continue k s s
      | effect Set s', k -> fun _ -> continue k () s'
\end{lstlisting}
and for the duration of the \lstinline[style=oxcaml]{f ()} function call
two additional effectful operations are available:
\begin{lstlisting}[style=oxcaml]
    let get () : int = perform Get
    let set (i : int) : unit = perform (Set i)
\end{lstlisting}

Effect handlers have a couple of key benefits compared to using an explicit monad:
\begin{itemize}
\item They allow writing code in ``direct style'' -- i.e. using ordinary
  functions and native arrow types. In particular, higher-order
  functions can automatically support effectful functions.
\item
  Multiple effect handlers compose with each other automatically in an
  easy-to-understand manner.
\end{itemize}

However, they also have an obvious issue: what happens if you try to
call \lstinline[style=oxcaml]{get} or \lstinline[style=oxcaml]{set}
outside of the \lstinline[style=oxcaml]{handle_state} handler?

In OCaml, the effects are untracked: nothing prevents attempting to
perform an effectful operation that is not currently available,
resulting in an \lstinline[style=oxcaml]{Unhandled} exception being
raised. This is essentially the same approach as unchecked exceptions,
which are a common source of bugs in many languages.

\subsection{Effect systems}

Most algebraic effect systems \cite{hillerstrom2016liberating,
leijen2014koka, convent2020doo,
biernacki2019binders, brachthauser2020effects,
xie2022first} solve the problem of unhandled effects by extending
their type system to explicitly track the effects that a function may
perform.

In such a system, the operations of our integer state example would have
types like:
\begin{lstlisting}[style=oxcaml]
    val handle_state : (unit -[istate | 'e]-> 'a) -> int -['e]-> 'a
    val get : unit -[istate]-> int
    val set : int -[istate]-> unit
\end{lstlisting}
with effect annotations on function arrows describing the monad
implicitly used by those functions, and effect variables used to relate
the monads of different functions.

The details vary between systems, but to avoid excessive user
annotation, such effect systems tend to have subtle inference built on
row polymorphism \cite{hillerstrom2016liberating, leijen2014koka} or implicit subtyping.

A particular source of complexity in such systems is that they require
\emph{effect polymorphism} to type higher-order functions. For example,
the \lstinline[style=oxcaml]{List.map} function, which maps a function
over a list, must be given a type like:
\begin{lstlisting}[style=oxcaml]
    val map : ('a -['e]-> 'b) -> 'a list -['e]-> 'b list
\end{lstlisting}
which includes effect annotations even though
\lstinline[style=oxcaml]{map} does not use algebraic effects.

\subsection{Extending the Ambient Monad}

Some more recent systems \cite{brachthauser2020effects,
brachthauser2022effects, tang2025modal} provide an elegant
alternative to effect polymorphism: they treat effect handlers as
extending the effects available in the \emph{ambient monad} -- the monad
associated with ordinary unannotated arrows. This means that, within a
handler for integer state, all functions are permitted to use integer
state without needing to track this fact in their type. Any effect
annotations on a function's type are requirements for additional effects
over and above what is currently available in the ambient monad.

In such systems the type of \lstinline[style=oxcaml]{List.map} can be:
\begin{lstlisting}[style=oxcaml]
    val map : ('a -> 'b) -> 'a list -> 'b list
\end{lstlisting}
whilst still allowing it to interoperate with functions using algebraic
effects. The types of our integer state operations might be something like:
\begin{lstlisting}[style=oxcaml]
    val get : unit -[istate]-> int
    val set : int -[istate]-> unit
\end{lstlisting}
specifying that an integer state effect must be added to the ambient
monad before they can be used. The type of their handler would be:
\begin{lstlisting}[style=oxcaml]
    val handle_state : (unit -[istate]-> 'a) -> int -> 'a
\end{lstlisting}
indicating that it extends the ambient monad with an additional effect.

Brachth{\"a}user et al.~\cite{brachthauser2020effects} describe this
approach as ``lightweight effect polymorphism'' because it brings many
of the benefits of effect polymorphism without requiring effect
annotations on all higher-order functions.

However, allowing functions to use any effects available at their
definition site requires restricting them in some way: they must be
prevented from leaving the scope of an effect handler in case they are
implicitly relying on that effect handler.

Existing systems accomplish this by making functions second-class, or
via sophisticated modal effect or capability types that can be used to
track which effect handlers a value may depend on. In this paper we show
all that is required is some type-level way to track locality such as
Rust's lifetimes or OxCaml's \lstinline[style=oxcaml]{local} mode.

\subsection{The Ambient Monad model}

If we are going to make changing the ambient monad the basis of our
algebraic effects then we should build a changeable ambient monad right
into our semantic model. \emph{We should index the meaning of types and
  terms by the ambient monad}. Rather than have the semantics of our
simple types be sets, $\sem{\tau} \types \setc$, we should have them be
functors from $\lawc$ to $\setc$:
\begin{equation*}
\sem{\tau} \types \lawc \arr \setc
\end{equation*}
where $\lawc$ is a suitable category of algebraic theories. For each
object $L \types \lawc$ we write $T_L$ for its corresponding monad. This
restriction to monads corresponding to algebraic theories is the essence
of algebraic effects: it ensures that every pair of monads has a
well-defined sum, allowing them to be handled by effect handlers.

For this model to remain set-theoretic, we also need to restrict the
types used for the parameters and arities of operations to a
\emph{predicative} fragment, which we describe in
Section~\ref{sec:predicative}.

These functors from $\lawc$ to $\setc$ are presheaves and so they
support all the standard constructions (products, coproducts,
exponentials, etc.) needed to support all the usual type formers
(products, sums, arrows, etc.) in the standard way.

The monad we use for computations, $\mon$, is just the current ambient
monad:
\begin{equation*}
  \mon(\sem{\tau})(L) = T_L(\sem{\tau}(L))
\end{equation*}
which we use to give the semantics of functions:
\begin{equation*}
  \sem{\tau_1 \arr \tau_2} = \sem{\tau_1} \arr \mon(\sem{\tau_2})
\end{equation*}
This is what allows ordinary functions to perform effects from the
ambient monad.

A few things fall out of this model for free, whose combination suggests
an alternative presentation of algebraic effects.

\subsubsection{Reflecting operations}

The Yoneda embedding of $L \types \lawc$ immediately gives us a suitable
semantics for a family of \emph{effect capability} types $\yoneda{L}$:
\begin{equation*}
\sem{\yoneda{L}} = \homset{\lawc}{L}{\_}
\end{equation*}
Elements of $\sem{\yoneda{L}}(L^\prime)$ represent
the ability to reflect effectful operations from $L$ into the ambient
monad $T_{L^{\prime}}$.

We can expose this ability as a reflection construct: for any
parameterized operation $op \types \tau_p \rightarrowtail \tau_a$ in an
algebraic signature $\Sigma$, we can provide a computation
$\perform{v_h}{op}{v_p}$ that uses the effect capability
$v_h \types \yoneda{\Sigma}$ to perform $op$ parameterized by the value
$v_p \types \tau_p$, returning a value of type $\tau_a$.

These effect capabilities are closely related to \emph{named
  handlers}~\cite{xie2022first} and \emph{lexical effect
  handlers}~\cite{biernacki2019binders}. They give you values that can represent
the handlers that are currently in scope.

The Yoneda Lemma applied to the semantics of computations tells us that
functions from $\yoneda{L}$ correspond to the sum of the ambient monad
$T_{L^{\prime}}$ with the monad $T_L$:
\begin{equation}
\label{eq:yoneda}
\sem{\yoneda{L} \arr \tau}(L^{\prime}) \cong T_{L^{\prime}+L}(\sem{\tau}(L^{\prime}+L))
\end{equation}

\subsubsection{The global modality}

$\lawc$ has an initial element $\initial$ corresponding to the identity
monad. We can use this to define a global comonad, closely
related to the purity comonad of Choudhury and
Krishnaswami~\cite{choudhury2020recovering}:
\begin{equation*}
\glob(\sem{\tau})(L) = \sem{\tau}(\initial)
\end{equation*}
This amounts to restricting $\tau$ to only the elements which do not
depend on the ambient monad. In particular,
\begin{equation*}
\glob(\sem{1 \arr \tau}) \cong \glob(\sem{\tau})
\end{equation*}
showing that thunks within the global comonad are pure.

We will use this as the semantics for a global modality $\glob$:
$\sem{\glob \tau} = \glob(\sem{\tau})$.

\subsubsection{Reifying terms}

If we restrict our attention to monads that correspond to some algebraic
signature $\Sigma$ with no equations -- i.e. the objects in $\lawc$ that
correspond to free monads -- then we can represent the sum of
$T_{\Sigma}$ with the ambient monad directly as an inductive type
$\ind{\Sigma}$. $\ind{\Sigma}$ is sometimes called the freer
monad~\cite{kiselyov2015freer}.

$\ind{\Sigma}(\tau)$ has a unit constructor $\ret{v_r}$ where
$v_r \types \tau$, and for each parameterized operation
$op \types \tau_p \rightarrowtail \tau_a$ in $\Sigma$ it has a
constructor $\indintro{op}{v_p}{v_k}$ where $v_p \types \tau_p$ and
$v_k \types \glob \tau_a \arr \ind{\Sigma}(\tau)$.

\begin{example}
  $\ind{\Sigma}$ for the signature of the integer state effect in OxCaml
  is equivalent to:
\begin{lstlisting}[style=oxcaml]
    type 'a t =
      | Return of 'a @@ global
      | Get of (int -> 'a t)
      | Set of int * (unit -> 'a t)
\end{lstlisting}
  where \lstinline[style=oxcaml]{@@ global} is the OxCaml syntax
  corresponding to the global modality.
\end{example}

By Theorem~4 of Hyland et al.~\cite{hyland2006combining}, we have that:
\begin{equation*}
T_L(\sem{\ind{\Sigma}(\tau)}(L)) \cong T_{L+\Sigma}(\sem{\tau}(\initial))
\end{equation*}
which, combined with (\ref{eq:yoneda}), gives us an isomorphism:
\begin{equation*}
\mon(\sem{\ind{\Sigma}(\tau)}) \cong \sem{\yoneda{\Sigma} \arr \glob \tau}
\end{equation*}

This isomorphism allows us to reify effectful computations as inductive
types, giving the same expressive power as effect handlers. Note that it
can be expressed with only effect capabilities, inductive types and a
global modality.

The forwards direction of the isomorphism is already provided
by reflection of operations. We can provide the backwards direction as a
reification construct: for any signature $\Sigma$, we provide a
computation $\reify{\loc}{c}$ that binds $\loc$ to an effect capability
of type $\yoneda{\Sigma}$ in the computation $c \types \glob \tau$ and
reifies the uses of $\loc$ in $c$ as a $\ind{\Sigma}(\tau)$.

\subsection{Locality in OxCaml}
\label{sec:locality}

The Ambient Monad model suggests expressing effect reflection and
reification only really requires a global modality, or more broadly some
type system mechanism for tracking locality. OxCaml has support for
tracking locality in types, which we describe here. For a full treatment
see Lorenzen et al.~\cite{lorenzen2024oxidizing}.

Values in OxCaml are associated with both a type -- which describes how
values can be introduced and eliminated -- and a \emph{mode} -- which
tracks properties related to operations other than introduction and
elimination. Modes are a product of a number of different axes, tracking
a variety of different properties, but here we are only interested in
one of them: \emph{locality}. Ignoring the other axes, a mode is either
\lstinline[style=oxcaml]{local} or \lstinline[style=oxcaml]{global}.

Locality tracks whether a value can escape the current
\emph{region}. By default, the current region ends when a function
returns, so local values cannot be returned from functions.
\begin{lstlisting}[style=oxcaml]
  let leak_local x =
    let (o @ local) = Some x in
    o
  (*@ \textcolor{red}{Error: This value escapes its region.} @*)
\end{lstlisting}
This tight alignment between regions and function bodies can be
inconvenient, so there is an \lstinline[style=oxcaml]{exclave} construct
that allows functions to return local values:
\begin{lstlisting}[style=oxcaml]
  let return_local x =
    exclave
      (let (o @ local) = Some x in
       o)
\end{lstlisting}
\lstinline[style=oxcaml]{exclave e} can only appear in tail position
within a function.  It ends the function's region early and then
executes the expression \lstinline[style=oxcaml]{e}. Since
\lstinline[style=oxcaml]{e} is executed within the region of the caller
of the function, any local values created within it can be safely
returned to that caller.

Arrow types are labelled with two modes: one for the argument and one
for the return value.
\begin{lstlisting}[style=oxcaml]
  val return_local : 'a @ local -> 'a option @ local
\end{lstlisting}
For convenience, and backwards compatibility with OCaml, either mode can
be omitted, in which case it defaults to
\lstinline[style=oxcaml]{global}.

By default, modes are deep: a local
\lstinline[style=oxcaml]{string list} is a local list of local
strings. However, the depth to which a mode applies can be controlled via
\emph{modalities}. Record fields can be annotated with the
\lstinline[style=oxcaml]{global} modality to indicate that the contents
of the field are global even when the surrounding record is local. For
example:
\begin{lstlisting}[style=oxcaml]
  type 'a gbl = { g : 'a @@ global }
\end{lstlisting}
gives a record whose only field has the \lstinline[style=oxcaml]{global}
modality. The contents of the \lstinline[style=oxcaml]{g} field are always
global, for example:
\begin{lstlisting}[style=oxcaml]
  let project_global (r @ local) =
    r.g
\end{lstlisting}
gives a function of type:
\begin{lstlisting}[style=oxcaml]
  val project_global : 'a gbl @ local -> 'a @ global
\end{lstlisting}
Variant constructor arguments can also be annotated with modalities.

Note that, whilst there is a \lstinline[style=oxcaml]{global} modality,
there is no \lstinline[style=oxcaml]{local} modality. It does not make
sense for a value which has the ability to leave a region to contain a
value which doesn't have that ability: when the first value leaves a
region it will implicitly cause the second one to leave that region as
well. This means the \lstinline[style=oxcaml]{global} mode is always
deep.

\subsection{Effect reflection in OxCaml}
\label{sec:reflection-in-oxcaml}

Using OxCaml's support for locality and the untracked algebraic effects
it inherits from OCaml, we can implement effect reflection as a simple
library with no specific compiler support.

Given an algebraic signature represented as a module with a single type
constructor:
\begin{lstlisting}[style=oxcaml]
    module E : sig type 'a t end
\end{lstlisting}
the library provides $\yoneda{\Sigma}$ as an abstract type
\lstinline[style=oxcaml]{Handler(E).t}, and $\ind{\Sigma}$ as
\lstinline[style=oxcaml]{'a Term(E).t}:
\begin{lstlisting}[style=oxcaml]
    type 'a t = 'a Term(E).t =
      | Return : 'a @@ global -> 'a t
      | Perform : 'r E.t @@ global * ('r, 'a) Continuation(E).t -> 'a t
\end{lstlisting}
For technical reasons (see Section \ref{sec:interface}) we use the type
\lstinline[style=oxcaml]{('r, 'a) Continuation(E).t} in place of
\lstinline[style=oxcaml]{'r -> 'a Term(E).t}. Elements of this type
can be applied using a \lstinline[style=oxcaml]{continue} function.

The reflection and reification operations are provided by the
\lstinline[style=oxcaml]{Reflection} functor as functions
\lstinline[style=oxcaml]{perform} and \lstinline[style=oxcaml]{reify}:
\begin{lstlisting}[style=oxcaml]
    val perform : 'a E.t -> Handler(E).t @ local -> 'a

    val reify :
      (Handler(E).t @ local -> 'a) @ local -> 'a Term(E).t @ local
\end{lstlisting}

We can use this library to write an effect handler equivalent to the
OCaml one in Section~\ref{sec:handlers}:
\begin{lstlisting}[style=oxcaml]
    module State = struct
      type 'a t =
        | Get : int t
        | Set : int -> unit t
    end
    module State_eff = Reflection(State)

    let handle_state (i : int)
          (f : Handler(State).t @ local -> 'a) : 'a =
      let rec loop s : 'a Term(State).t @ local -> 'a = function
        | Return x -> x
        | Perform(Get, k) -> loop s (State_eff.continue k s)
        | Perform(Set s', k) -> loop s' (State_eff.continue k ())
      in
      loop i (State_eff.reify f)
\end{lstlisting}
The handler calls \lstinline[style=oxcaml]{f} and passes it a local value of
type \lstinline[style=oxcaml]{Handler(State).t}. For the duration of the
call to \lstinline[style=oxcaml]{f} the ambient monad is extended with
two additional effectful operations, which can be used via reflection:
\begin{lstlisting}[style=oxcaml]
    let get (h : Handler(State).t @ local) : int =
      State_eff.perform Get h

    let set (h : Handler(State).t @ local) (i : int) : unit =
      State_eff.perform (Set i) h
\end{lstlisting}

The locality of the \lstinline[style=oxcaml]{Handler(State).t} value
passed to \lstinline[style=oxcaml]{f} ensures that these operations can
only be performed when available in the ambient monad. The type system
prevents this handler value from escaping the scope of
\lstinline[style=oxcaml]{f}, which in turn prevents
\lstinline[style=oxcaml]{get} or \lstinline[style=oxcaml]{set} from
being called outside that scope.

\subsubsection{Lightweight effect polymorphism}

The following function uses the state handler to calculate the total of
a list of integers:
\begin{lstlisting}[style=oxcaml]
  let total l =
    handle_state 0 (fun h ->
      List.iter (fun x -> set h (get h + x)) l;
      get h)
\end{lstlisting}
This relies on the locality of the function parameter of
\lstinline[style=oxcaml]{List.iter}:
\begin{lstlisting}[style=oxcaml]
  val iter : ('a -> unit) @ local -> 'a list -> unit
\end{lstlisting}
The \lstinline[style=oxcaml]{local} annotation on the parameter ensures
that any function passed will not escape the current region. This allows
us to pass in a closure that closes over the
\lstinline[style=oxcaml]{local} handler \lstinline[style=oxcaml]{h} and
use it to perform some effects.

\subsection{Contributions}

We make the following contributions:
\begin{itemize}
\item We propose \emph{effect reflection}, a new presentation of effect
  handlers that ensures all effectful operations are properly handled
  without requiring an effect system.
\item We present a simply-typed lambda calculus with effect
  reflection. We prove that the extended system maintains subject
  reduction, confluence and strong normalization. We prove \emph{effect
    safety}: a closed well-typed program never attempts to perform an
  unhandled operation. We prove that the ordinary simply-typed lambda
  calculus embeds into it. (Section \ref{sec:language})
\item We propose the Ambient Monad model of effectful computations. We
  use it to give a denotational semantics of our lambda calculus with
  effect reflection.  We prove that this semantics is sound,
  compositional and adequate. We identify a class of \emph{predicative
    signatures} for which the model remains entirely set-theoretic
  whilst still supporting operations with arbitrarily large parameters
  and arities.  (Section \ref{sec:semantics})
\item We give a simple implementation of effect reflection in OxCaml
  using its support for tracking locality in the type system and the
  untracked algebraic effects it inherits from OCaml. We demonstrate its
  usability with some classic examples of algebraic effects. (Section
  \ref{sec:practice})
\end{itemize}

\section{Simply-typed lambda calculus with effect reflection}
\label{sec:language}

We present a simply-typed lambda calculus extended with effect
reflection. This extension requires adding a separate syntax and typing
judgement for computations, in the style of the Fine-Grained
Call-By-Value lambda calculus~\cite{levy2003modelling}, with function
application treated as a computation.

\subsection{The base language}

Our language is simply typed, featuring all the usual type-formers. The
syntax and typing rules for the base language are shown in
Fig.\ref{fig:typing-standard}.

For convenience we allow some simple pattern forms in variable binding
positions. We allow $()$ to be used in place of a variable when binding
a unit value, and we allow $(x_1, x_2)$ to be used in place of a single
variable when binding a product value. Unit patterns are encoded as just
an unused variable, whilst product bindings are encoded using a variable
$x_0$ and applying the substitutions
$\sub{x_1}{\fst{x_0}}\sub{x_2}{\snd{x_0}}$ to the body of the binding.

Note that $\casename$ -- the eliminator for sum types -- is a value
rather than a computation. We can define a computation version as:
\begin{align*}
    &\case{v}{x_1}{c_1}{x_2}{c_2} := \\
    &\qquad (\case{v}{x_1}{\abs{()}{c_1}}{x_2}{\abs{()}{c_2}}) \; ()
\end{align*}

\subsection{Locality}

The syntax and typing rules related to locality are shown in
Fig.~\ref{fig:typing-locality}. We track locality via a global
comonadic modality $\glob$. In our setting, being global means not depending on the ambient monad. For
example, $1 \arr \tau$ represents computations that may use operations from
the ambient monad, while $\glob (1 \arr \tau)$ contains only pure
computations that ignore the ambient monad.

When using $\gbox{v}$ to build a value of global type $\glob \tau$,
the value $v$ may only refer to variables that are themselves known to
be global. We achieve this using a standard approach for modal types:
we extend contexts with a binding form that marks a variable as global
and then we restrict the context in which we type $v$ to only include
such bindings. The new global binding form is written
$\gbind{\Gamma}{x}{\tau}$: it binds $x$ to a value of type $\tau$ that
is available in global contexts, so it corresponds to having a value of
type $\glob \tau$ in the context. We create global bindings in the
context using the elimination form: $\gunbox{x}{v_1}{v_2}$. As with $\casename$,
this elimination form is a value, but we can define a computation
version directly in terms of it.

Restricting the context is implemented via an operation on contexts
$\cdiv{\Gamma}$ that removes all local bindings, leaving only the global
ones:
\begin{align*}
  &\cdiv{\cempty} = \cempty \\
  &\cdiv{(\lbind{\Gamma}{x}{\tau})} = \cdiv{\Gamma} \\
  &\cdiv{(\gbind{\Gamma}{x}{\tau})} = \gbind{\cdiv{\Gamma}}{x}{\tau}
\end{align*}

Global computations do not depend on the ambient monad, so we also
include a value form $\grun{c}$, which allows treating a global
computation $c$ as a value.

The global comonad distributes over sum types:
\begin{equation*}
  \glob (\tau_1 + \tau_2)
  \qquad \cong \qquad
  (\glob \tau_1) + (\glob \tau_2)
\end{equation*}
which we realize via $\caseboxname$, a global form of the
$\casename$ construct, which allows you to match on a global sum and get
out global components.

For convenience we allow $(\gbox{x})$ to be used as a pattern in
variable binding positions. These are treated as binding a variable
$x_0$ and prefixing the body of the binding with $\gunbox{x}{x_0}{}$.

We add a modalities category, $m$, to the formal syntax, which is either
blank space or $\glob$, to make it easier to describe rules that are
parametric in the presence or absence of the global modality. As part of
this, the $\cdiv{\Gamma}$ operation is extended to work on modalities
$\cmdiv{\Gamma}$ with $\cldiv{\Gamma} = \Gamma$.

\begin{figure}
\begin{align*}
  \mathrm{types}, \tau ::=\;& \ldots \mid \glob \tau \mid \ldots \\
  \mathrm{modalities}, m ::=\;& \nothing \mid \glob \\
  \mathrm{contexts}, \Gamma ::=\;& \ldots \mid \gbind{\Gamma}{x}{\tau} \\
  \mathrm{values}, v ::=\;& \ldots \mid \gbox{v} \mid \gunbox{x}{v}{v} \mid \\
                          &\casebox{v}{x}{v}{x}{v} \mid \grun{c} \mid \ldots
\end{align*}
\begin{mathpar}
\inferrule{\\}
{\ccons{\mbind{\Gamma_1}{x}{\tau}}{\Gamma_2} \turnv x \types \tau}
\and
\inferrule{\cdiv{\Gamma} \turnv v \types \tau}
{\Gamma \turnv \gbox{v} \types \glob \tau}
\and
\inferrule{\Gamma \turnv v_1 \types \glob \tau_1 \\
           \gbind{\Gamma}{x}{\tau_1} \turnv v_2 \types \tau_2}
{\Gamma \turnv \gunbox{x}{v_1}{v_2} \types \tau_2}
\and
\inferrule{\cmdiv{\Gamma} \turnv v_1 \types \tau_1 + \tau_2 \\
           \mbind{\Gamma}{x_1}{\tau_1} \turnv v_2 \types \tau_3 \\
           \mbind{\Gamma}{x_2}{\tau_2} \turnv v_3 \types \tau_3}

\and
\inferrule{\cdiv{\Gamma} \turnc c \types \tau}

\end{mathpar}

\label{fig:typing-locality}
\end{figure}

\subsection{Signatures and inductive types}
\label{sec:signatures}

Effect reflection requires, for any signature $\Sigma$ that is being
reflected, an inductive type $\ind{\Sigma}$ to represent the free
algebras of $\Sigma$. $\ind{\Sigma}$ is sometimes called the \emph{freer
  monad} of $\Sigma$~\cite{kiselyov2015freer}. It is a form of
W-type, and in a dependently-typed setting we would probably use W-types
directly.

As is standard for algebraic effect systems, we only support handlers
for algebraic theories without any equations, even though our semantics
is defined in terms of arbitrary theories. We define algebraic
signatures $\Sigma$ as finite sets of operations:
\begin{equation*}
\{ op_1 \types \tau_{p_1} \rightarrowtail \tau_{a_1}; \ldots; op_n
\types \tau_{p_n} \rightarrowtail \tau_{a_n} \}
\end{equation*}
An operation type $\tau_p \rightarrowtail \tau_a$ indicates an operation
parameterized by $\tau_p$ and with arity $\tau_a$.

\begin{example}
  The signature for boolean state, which we'll call $\Sigma_{bs}$,
  is:
  \begin{equation*}
    \{ \mathrm{get} \types 1 \rightarrowtail (1 + 1);
       \mathrm{set} \types (1 + 1) \rightarrowtail 1 \}
  \end{equation*}
\end{example}

We also allow the sum of two signatures $\Sigma_1 + \Sigma_2$ to be used
as a signature. It has operations:
\begin{align*}
\{ \; &\mathrm{left}(op_{1,1}) \types \tau_{p_{1,1}} \rightarrowtail \tau_{a_{1,1}}
        \seq \ldots \seq
        \mathrm{left}(op_{1, n}) \types \tau_{p_{1, n}} \rightarrowtail \tau_{a_{1, n}}
        \seq \\
      &\mathrm{right}(op_{2, 1}) \types \tau_{p_{2, 1}} \rightarrowtail \tau_{a_{2,1}}
        \seq \ldots \seq
        \mathrm{right}(op_{2, m}) \types \tau_{p_{2, m}} \rightarrowtail \tau_{a_{2, m}}
        \; \}
\end{align*}
where $op_{1,1} \seq \ldots \seq op_{1,n}$ are the operations of
$\Sigma_1$ and $op_{2,1} \seq \ldots \seq op_{2,m}$ are the operations
of $\Sigma_2$.

For each operation $op \types \tau_p \rightarrowtail \tau_a$,
$\ind{\Sigma}(\tau)$ has a constructor $\indintro{op}{v_p}{v_k}$
where $v_p \gtypes \tau_p$ and
$v_k \types \glob \tau_a \arr \ind{\Sigma}(\tau)$. $\ind{\Sigma}(\tau)$
also has a constructor $\ret{v}$ where $v \gtypes \tau$.

The eliminator for $\ind{\Sigma}$ is written
\begin{align*}
\indelim{v_s}
  {&\indretcase{x}{v_e} \seq \\
   &\indcase{op_1}{x_{p_1}}{x_{k_1}}{v_1} \seq \\
   &\ldots \seq \\
   &\indcase{op_n}{x_{p_n}}{x_{k_n}}{v_n}}
\end{align*}
The syntax and typing rules for inductive types are shown in
Fig.\ref{fig:typing-inductive}.

As with $\casename$, $\indelimname$ is defined as a value and we can
define a computation version in terms of it.

\begin{figure}
\begin{align*}
  \mathrm{types}, \tau ::=\;& \ldots \mid \ind{\Sigma}(\tau) \mid \ldots \\
  \mathrm{signatures}, \Sigma ::=\;& \{ op \types \tau \rightarrowtail \tau \seq \ldots
                                       \seq op \types \tau \rightarrowtail \tau \}
                                     \mid \Sigma + \Sigma \\
  \mathrm{values}, v ::=\;& \ldots \mid \indintro{op}{v}{v}
                           \mid \ret{v} \mid \\
                         & \indelim{v}
                           {\indretcase{x}{v} \seq
                           \indcase{op}{x}{x}{v} \seq \ldots
                           \seq \indcase{op}{x}{x}{v}} \ldots
\end{align*}
\begin{mathpar}
\inferrule{op \types \tau_1 \rightarrowtail \tau_2 \in \Sigma \\
           \cdiv{\Gamma} \turnv v_1 \types \tau_1 \\
           \Gamma \turnv v_2 \types \glob \tau_2 \arr \ind{\Sigma}(\tau)}
{\Gamma \turnv \indintro{op}{v_1}{v_2} \types \ind{\Sigma}(\tau)}
\and
\inferrule{\cdiv{\Gamma} \turnv v \types \tau}
{\Gamma \turnv \ret{v} \types \ind{\Sigma}(\tau)}
\and
\inferrule{\Gamma \turnv v_s \types \ind{\Sigma}(\tau_1) \\
           \Sigma = \{ op_1 \types \tau_{p_1} \rightarrowtail \tau_{a_1};
             \ldots; op_n\types \tau_{p_n} \rightarrowtail \tau_{a_n} \} \\
           \gbind{\Gamma}{x_r}{\tau_1} \turnv v_e \types \tau_2 \\
           \lbind{\gbind{\Gamma}{x_{p_1}}{\tau_{p_1}}}{x_{k_1}}{\glob \tau_{a_1} \arr \tau_2} \turnv v_1 \types \tau_2 \\
           \ldots \\
           \lbind{\gbind{\Gamma}{x_{p_n}}{\tau_{p_n}}}{x_{k_n}}{\glob \tau_{a_n} \arr \tau_2} \turnv v_n \types \tau_2}
{\Gamma \turnv \indelim{v_s}{\indretcase{x_r}{v_e} \seq
                                   \indcase{op_1}{x_{p_1}}{x_{k_1}}{v_1} \seq \ldots \seq
                                   \indcase{op_n}{x_{p_n}}{x_{k_n}}{v_n}} \types \tau_2}
\end{mathpar}
\caption{Inductive type syntax and typing rules}
\label{fig:typing-inductive}
\end{figure}

\begin{example}
  \label{example:negate}
  The following value of type $\ind{\Sigma_{bs}}(1)$ represents a
  reified computation that negates the value of the state:
  \begin{align*}
    &\indintro{get}{()}{\\
      &\quad\abs{(\gbox{x_a})}{\\
          &\qquad \return{\indintro{set}{\grun{\app{\mathit{negate}}{x_a}}}
            {\abs{(\gbox{x_r})}{\return{\ret{x_r}}}}}}}
  \end{align*}
  where $\mathit{negate}$ is the function that negates a boolean.
\end{example}

\subsection{Effect reflection}

We provide a type $\yoneda{\Sigma}$ for each algebraic signature
$\Sigma$ to represent mappings from the operations of $\Sigma$ into the
current ambient monad. We call such mappings \emph{effect
  capabilities}. Effect reflection appears as two constructs: reflection
and reification. Reflection $\performraw{v}{op}$ uses a value
$v \types \yoneda{\Sigma}$ to map the operation $op$ from $\Sigma$ into
the ambient monad.  Reification $\reifyname$ extends the ambient monad
with the operations from some $\Sigma$, and provides a value of type
$\yoneda{\Sigma}$ for constructing those operations via reflection.
These constructs implement the core isomorphism of effect reflection:
reification can convert functions $\yoneda{\Sigma} \arr \glob \tau$ into
terms $\ind{\Sigma}(\tau)$, while reflection provides the inverse
direction. Their syntax and typing rules are shown in
Fig.\ref{fig:typing-reflection}.

\begin{figure}
\begin{align*}
  \mathrm{locations}, \loc \in\;& \locs \\
  \mathrm{types}, \tau ::=\;& \ldots \mid \yoneda{\Sigma} \mid \ldots \\
  \mathrm{contexts}, \Gamma ::=\;& \ldots \mid \lbind{\Gamma}{\loc}{\Sigma} \\
  \mathrm{values}, v ::=\;& \ldots \mid \loc \mid \outl{v} \mid \outr{v} \\
  \mathrm{computations}, c ::=\;& \ldots \mid \perform{v}{op}{v} \mid \reify{\loc}{c}
\end{align*}
\begin{mathpar}
\inferrule{\\}
{\ccons{\lbind{\Gamma_1}{\loc}{\Sigma}}{\Gamma_2} \turnv \loc \types \yoneda{\Sigma}}
\and
\inferrule{\Gamma \turnv v \types \yoneda{\Sigma_1 + \Sigma_2}}
{\Gamma \turnv \outl{v} \types \yoneda{\Sigma_1}}
\and
\inferrule{\Gamma \turnv v \types \yoneda{\Sigma_1 + \Sigma_2}}
{\Gamma \turnv \outr{v} \types \yoneda{\Sigma_2}}
\and
\inferrule{\Gamma \turnv v_1 \types \yoneda{\Sigma} \\
           op \types \tau_1 \rightarrowtail \tau_2 \in \Sigma \\
           \cdiv{\Gamma} \turnv v_2 \types \tau_1}
{\Gamma \turnc \; \perform{v_1}{op}{v_2} \types \glob \tau_2}
\and
\inferrule{\lbind{\Gamma}{\loc}{\Sigma} \turnc c \types \glob \tau}
{\Gamma \turnc \; \reify{\loc}{c} \types \ind{\Sigma}(\tau)}
\end{mathpar}
\caption{Effect reflection syntax and typing rules}
\label{fig:typing-reflection}
\end{figure}

We introduce a separate set of variables $\loc$ for the bindings
introduced by reification. This makes it easier to define the desired
reduction rules and normal forms. We give them their own binding form
$\loc \types \Sigma$ in the context, which is also removed by the
$\cdiv{}$ operation.

Note that we treat reflection of individual operations
$\performraw{v}{op}$ as primitive. We can define reflection of
terms $\reflectraw{v}$ in terms of $\performraw{v}{op}$:
\begin{align*}
    \reflect{v}{c} := \quad &\letv{x_w}{c}{\\
        &\indelim{x_w}{ \\
        &\qquad \indretcase{x_r}{\return{(\gbox{x_r}})} \seq \\
        &\qquad \indcase{op_1}{x_{p_1}}{x_{k_1}}
          {\letv{x_{a_1}}{\perform{v}{op_1}{x_{p_1}}}{\app{x_{k_1}}{x_{a_1}}}} \seq \\
        &\qquad \ldots \seq \\
        &\qquad \indcase{op_n}{x_{p_n}}{x_{k_n}}
          {\letv{x_{a_n}}{\perform{v}{op_n}{x_{p_n}}}{\app{x_{k_n}}{x_{a_n}}}}}}
\end{align*}
which has this admissible typing rule:
\begin{mathpar}
\inferrule{\Gamma \turnv v \types \yoneda{\Sigma} \\
           \Gamma \turnc c \types \ind{\Sigma}(\tau)}
{\Gamma \turnc \; \reflect{v}{c} \types \glob \tau}
\end{mathpar}

\begin{example}
  The value from Example~\ref{example:negate} can also be constructed
  via reflection:
  \begin{align*}
    &\reify{\loc}{\\
      &\qquad \letv{(\gbox{x})}{\perform{\loc}{get}{}}{\\
      &\qquad \perform{\loc}{set}{\grun{\app{\mathit{negate}}{x}}}}}
  \end{align*}
  where $\mathit{negate}$ is the function that negates a boolean.
\end{example}

We also provide projections $\outl$ and $\outr$ that decompose an effect
capability for $\Sigma_1 + \Sigma_2$ into effect capabilities for
$\Sigma_1$ and $\Sigma_2$ respectively.

\subsection{Operational semantics}
\label{sec:operational}

We define the operational semantics as a pair of mutually defined
reduction relations $\stepstov$ and $\stepstoc$ for values and
computations respectively. These are shown in Fig.\ref{fig:reduction},
omitting the congruence rules. We write $\reducestov$ and $\reducestoc$
for the reflexive transitive closures of these relations. The
definitions of normal forms for values and computations are given in
Fig.\ref{fig:normal}.

\begin{figure}
\begin{align*}
\fst{(v_1, v_2)} &\stepstov v_1 \\

Note that the reduction rules are for strong reduction, i.e. there is a
congruence rule for abstraction:
\begin{mathpar}
\inferrule{c_1 \stepstoc c_2}
{\abs{x}{c_1} \stepstov \abs{x}{c_2}}
\end{mathpar}

We prove subject reduction for this semantics in
Appendix~\ref{apdx:subject-reduction} by induction on the reduction
relations.
\begin{theorem}
\label{lemma:subject-reduction}[Subject reduction]
  \begin{align*}
    &\Gamma \turnv v_1 \types \tau
      \quad \wedge \quad v_1 \stepstov v_2
      \quad \implies \quad \Gamma \turnv v_2 \types \tau \\
    &\Gamma \turnc c_1 \types \tau
      \quad \wedge \quad c_1 \stepstoc c_2
      \quad \implies \quad \Gamma \turnc c_2 \types \tau
  \end{align*}
\end{theorem}

These reduction relations are confluent:
\begin{theorem}
\label{lemma:church-rosser}[Confluence]
  \begin{align*}
    &v_1 \reducestov v_2
      \quad \wedge \quad v_1 \reducestov v_3
      \quad \implies \quad \exists\, v_4. \quad v_2 \reducestov v_4
      \quad \wedge \quad v_3 \reducestov v_4 \\
    &c_1 \reducestoc c_2
      \quad \wedge \quad c_1 \reducestoc c_3
      \quad \implies \quad \exists\, c_4. \quad c_2 \reducestoc c_4
      \quad \wedge \quad c_3 \reducestoc c_4
  \end{align*}
\end{theorem}
which we prove using the standard approach via an equivalent notion of
parallel reduction in Appendix~\ref{apdx:church-rosser}.

They are also strongly normalizing. We call the sets of values and
computations for which there exist no infinite chains
of reductions $\snv$ and $\snc$ respectively.
\begin{theorem}[Strong normalization]
\label{lemma:strong-normalization}
\begin{align*}
    &\Gamma \turnv v \types \tau
      \quad \implies \quad v \in \snv \\
    &\Gamma \turnc c \types \tau
      \quad \implies \quad c \in \snc
\end{align*}
\end{theorem}
We prove this using logical relations in
Appendix~\ref{apdx:strong-normalization}.

In Appendix~\ref{apdx:effect-safety} we prove a progress lemma: every
well-typed term that cannot reduce is a normal form according to
Fig.~\ref{fig:normal}. Inspecting those normal forms, $\return{\omega}$
is the only normal computation form that is well-typed in the empty
context: the other forms all require a location or variable from the
context. Combined with subject reduction and strong normalization, this
gives effect safety: a well-typed program can never attempt to perform
an effectful operation that is not handled.
\begin{theorem}[Effect safety]
\label{lemma:effect-safety}
  \begin{equation*}
    \turnc c \types \tau
    \quad \implies \quad
    \exists\, \omega. \quad c \reducestoc \return{\omega}
  \end{equation*}
\end{theorem}

\subsection{Embedding the Simply-Typed Lambda Calculus}

Using the global modality and $\grun{c}$ construct we can embed the
Simply-Typed Lambda Calculus (STLC) into this language as values. This
demonstrates that the language is a proper extension of STLC. We show this
embedding and prove it correct in Appendix~\ref{apdx:embedding}.

\section{The Ambient Monad model}
\label{sec:semantics}

The design of effect reflection falls out naturally from a novel
semantic model of algebraic effects. The key idea is to index the
meaning of types and terms by an ambient monad of effects: rather than
have the semantics of each type be a set of elements, the semantics of
each type is a mapping from the ambient monad to a set of elements. We
give a denotational semantics to the language from
Section~\ref{sec:language} using this model.

\subsection{Algebraic Theories and Free Algebras}

We need the monads we use for the ambient monad to have a well-defined
notion of sum. This is a requirement for composable effect handlers:
within the effect handler the ambient monad will be the sum of the
handled effect and the ambient monad from outside of the handler. That
rules out allowing all monads as the ambient monad, since the sum of two
arbitrary monads may not exist.

Algebraic effects ensure that such a sum always exists by only
supporting monads that are the free algebra of some algebraic theory. We
use the same approach for the Ambient Monad model.

We recall the definitions of algebraic signature, terms of a signature,
algebraic theory and models of a theory.
\begin{definition}[Algebraic signature]
  An \emph{algebraic signature} is a set of operations, each with an
  associated \emph{arity}.
\end{definition}

\begin{example}
  The algebraic signature for boolean state $\Sigma_{bs}$ is:
  \begin{equation*}
    \{ (\mathrm{get}, 2); (\mathrm{set\_true}, 1); (\mathrm{set\_false}, 1) \}
  \end{equation*}
\end{example}

\begin{definition}[Term]
  A \emph{term} $t$ of some algebraic signature $\Sigma$ is either a
  free variable $x$ or $op(t_1, \ldots, t_k)$ where $op$ is an operation
  of $\Sigma$ with arity $k$ and each $t_i$ is itself a term.
\end{definition}

\begin{definition}[Algebraic theory]
  An \emph{algebraic theory} consists of an algebraic signature $\Sigma$ and a set of
  equations on terms of $\Sigma$.
\end{definition}

\begin{example}
  The algebraic theory for boolean state $L_{bs}$ adds the following
  equations to the signature of boolean state $\Sigma_{bs}$:
  \begin{align*}
    &\mathrm{set\_true}(\mathrm{get}(x, y)) = \mathrm{set\_true}(x)
    &\mathrm{set\_false}(\mathrm{get}(x, y)) = \mathrm{set\_false}(y) \\
    &\mathrm{set\_true}(\mathrm{set\_true}(x)) = \mathrm{set\_true}(x)
    &\mathrm{set\_true}(\mathrm{set\_false}(x)) = \mathrm{set\_false}(x) \\
    &\mathrm{set\_false}(\mathrm{set\_true}(x)) = \mathrm{set\_true}(x)
    &\mathrm{set\_false}(\mathrm{set\_false}(x)) = \mathrm{set\_false}(x) \\
    &\mathrm{get}(\mathrm{set\_true}(x), \mathrm{set\_false}(x)) = x
  \end{align*}
\end{example}

\begin{definition}[Model]
  A \emph{model} $M$ of some algebraic theory $L$ consists of a carrier
  set $S$ and for each operation $op$ in the signature of $L$ a function
  $op_M : (\Pi_k S) \rightarrow S$ where $k$ is the arity of $op$, such
  that the equations of $L$ are respected when interpreting the terms
  using these functions for the operations. Models of $L$ are also
  called algebras of $L$.
\end{definition}

\begin{example}
  We can model the theory of boolean state $L_{bs}$ using the carrier
  set $2 \rightarrow 2$ and interpreting the operations with:
  \begin{align*}
    &\mathrm{get}(x, y) = \lambda s.\, \mif s \mthen x(s) \melse y(s) \\
    &\mathrm{set\_true}(x) = \lambda s.\, x(\mathrm{true}) \\
    &\mathrm{set\_false}(x) = \lambda s.\, x(\mathrm{false})
  \end{align*}
\end{example}

Arities in algebraic signatures are often taken to be natural numbers,
but they can be generalised to sets, with a natural number $k$
corresponding to a $k$-element set. The arguments of an operation are
then a family of terms indexed by that set. It is also convenient to allow
families of operations parameterized by some set. This gives us
signatures of the form:
\begin{equation*}
\{ op_1 \types P_1 \rightarrowtail A_1; \ldots; op_n
\types P_n \rightarrowtail A_n \}
\end{equation*}
where $op \types P \rightarrowtail A$ indicates an operation $op$
parameterized by $P$ and with arity $A$.

\begin{example}
  The algebraic signature for boolean state $\Sigma_{bs}$ can be written
  as:
  \begin{equation*}
    \{ \mathrm{get} \types 1 \rightarrowtail 2; \mathrm{set} \types 2 \rightarrowtail 1 \}
  \end{equation*}
\end{example}

Given an algebraic theory $L$ and a set $A$ we can construct the free
model, or \emph{free algebra}, of $L$ on $A$. We write $T_L(A)$ for its
carrier: the set of terms built using the elements of $A$ and the
operations of $L$, quotiented by the equations in $L$.  $T_L$ is a monad
on $\setc$, which we call the \emph{free algebra monad} of $L$.

\begin{example}
  The free algebra monad $T_{\Sigma_{bs}}$ of the signature of boolean
  state is equivalent to the type:
  \begin{lstlisting}[style=oxcaml]
  type 'a t =
    | Return of 'a
    | Get of unit * (bool -> 'a t)
    | Set of bool * (unit -> 'a t)
  \end{lstlisting}
  The free algebra monad $T_{L_{bs}}$ of the theory of boolean state is
  the same type quotiented by the equations of $L_{bs}$.
\end{example}

Every algebraic signature $\Sigma$ yields an endofunctor $F_{\Sigma}$ on
$\setc$ whose free monad is the free algebra monad $T_{\Sigma}$. The
elements of $F_{\Sigma}(A)$ are of the form $op(a_1, \ldots, a_k)$ where $op$ is an operation of
$\Sigma$ with arity $k$ and each $a_i$ is an element of $A$.
\begin{example}
  $F_{\Sigma_{bs}}$ is equivalent to the type:
  \begin{lstlisting}[style=oxcaml]
  type 'a t =
    | Get of unit * (bool -> 'a)
    | Set of bool * (unit -> 'a)
  \end{lstlisting}
\end{example}

\subsection{Lawvere theories}

\emph{Lawvere theories} are a categorical representation of algebraic
theories that doesn't depend on the particular choice of operations and
equations. We will use them as our concrete representation of the
ambient monad.

\begin{definition}
  A \emph{Lawvere theory} is a category $L$ with finite products in
  which every object is isomorphic to some finite cartesian product
  $X^n = X \times \ldots \times X$ of a distinguished object $X$.
\end{definition}
The objects of a Lawvere theory correspond to the different possible
arities and the morphisms $X^n \rightarrow X$ correspond to terms
of $L$ with $n$ free variables quotiented by the equations in $L$. A
model of a Lawvere theory $L$ is a product-preserving functor
$L \rightarrow \setc$.

We will mostly describe Lawvere theories and constructions on them in
terms of their presentations as algebraic theories, so an understanding
of the details of Lawvere theories is not required for understanding the
bulk of this paper.

Lawvere theories form a category $\lawfc$ whose morphisms are equivalent
to maps from the operations of one theory to terms of another that
preserve the equations of the first theory according to the equations of
the second.

\subsection{Bounded Lawvere theories}
\label{sec:small}

Traditional algebraic signatures are restricted to the case of a finite
set of operations each with a finite arity, but programming languages
require more generality. In terms of effect reflection, this would
amount to demanding, for any operation
$op \types \tau_p \rightarrowtail \tau_a$, that $\tau_p$ and $\tau_a$ be
finite types. This would allow for boolean state, but would not support
$\nat$-valued state.

In the algebraic effects literature the most common choice is to use
algebraic signatures with countable arity. However, this is still too
restrictive, supporting $\nat$-valued state but not
$(\nat \rightarrow \nat)$-valued state.

We want to allow arbitrarily large types for the parameters and arities
of our operations. However, we also wish our category of Lawvere
theories to be small. To achieve this we will parameterize our model and
semantics by a regular cardinal $\kappa$, and use algebraic theories
that can be presented using at most $2^{<\kappa}$ operations whose
arities are smaller than $\kappa$. We will not worry about the choice of
$\kappa$ as for any given program, subject to the restriction that
signatures be predicative (see Section \ref{sec:predicative}), there is
always a sufficiently large $\kappa$ available, which we prove in
Appendix \ref{apdx:bounds}.

We can extend the definition of Lawvere theory to support algebraic
theories bounded by a regular cardinal $\kappa$:
\begin{definition}
  A \emph{$\kappa$-bounded Lawvere theory} is a small category with
  $\kappa$-small products, a distinguished object $X$ such that every
  object is isomorphic to $X^S$ for some $|S| < \kappa$, and whose set
  of morphisms has cardinality less than or equal to $2^{<\kappa}$.
\end{definition}
The models of a $\kappa$-bounded Lawvere theory $L$ are the
product-preserving functors from $L$ to $\setc$.

Morphisms between $\kappa$-bounded Lawvere theories are
product-preserving functors that preserve the distinguished object
$X$. Such functors correspond to homomorphisms of algebraic theories:
maps from the operations of one theory to the terms of another that
preserve the equations of the first theory according to the equations of
the second.

$\kappa$-bounded Lawvere theories and their morphisms form a small
category $\lawc$. This category has coproducts $L + L^{\prime}$ which
correspond to the algebraic theory made by unioning the operations and
equations of $L$ and $L^{\prime}$. It also has an initial object
$\initial$, which is the algebraic theory with no operations or
equations and corresponds to the identity monad. We prove these
properties of $\lawc$ in Appendix~\ref{apdx:lawprops}.

\subsection{Presheaves}
\label{sec:presheaves}

Now that we have a concrete representation for potential ambient monads,
we can define our semantics in terms of sets indexed by such
monads. More specifically, we can use functors $\setc^{\lawc}$ as the
semantics of our types. Using functors, rather than mere families of
sets indexed by the objects of $\lawc$, ensures that the elements of a
type at a particular ambient monad can always be mapped to any larger
ambient monad, and that terms respect this mapping. These functors have many
convenient properties because they are \emph{presheaves}.

For a category $\cat$, $\psh = \setc^{\catop}$ is the category of
presheaves over $\cat$. Its objects are contravariant functors from
$\cat$ to $\setc$ and its morphisms are natural transformations between
such functors.

In these terms, we use $\pshlawcop = \setc^{\lawc}$ as the basis of the
Ambient Monad model. The $\op$ in the definition of
presheaves and the $\op$ in $\lawcop$ cancel out, but it is still
profitable to think in terms of presheaves because presheaves come with
a lot of useful technology.

The Ambient Monad model uses objects from $\pshlawcop$ to represent
types and contexts, and morphisms in $\pshlawcop$ to represent
values.
\begin{equation*}
\sem{\tau} \mathrel{:} \pshlawcop \qquad
\sem{\Gamma} \mathrel{:} \pshlawcop \qquad
\sem{\Gamma \turnv v \types \tau} \mathrel{:} \homset{\pshlawcop}{\sem{\Gamma}}{\sem{\tau}}
\end{equation*}

A category of presheaves over a small category, such as $\lawc$, is a
topos, which gives it many useful properties. As a topos, $\pshlawcop$
has products and coproducts, which are defined pointwise. We will use
these as the semantics of product types and sum types.
\begin{equation*}
\sem{1} = 1 \qquad
\sem{\tau_1 \times \tau_2} = \sem{\tau_1} \times \sem{\tau_2} \qquad
\sem{\tau_1 + \tau_2} = \sem{\tau_1} + \sem{\tau_2} \qquad
\end{equation*}
The semantics of the corresponding introduction and elimination forms
follows the usual categorical semantics of such types.

We also use products for the semantics of contexts:
\begin{equation*}
\sem{\cempty} = 1 \qquad
\sem{\lbind{\Gamma}{x}{\tau}} = \sem{\Gamma} \times \sem{\tau}
\end{equation*}

\subsection{Representing computations: The free algebras monad}
\label{sec:monad}

Our aim is to have a semantics where the meaning of types is indexed by
the ambient monad -- or more precisely by a representation of the
algebraic theory whose free algebras are the ambient monad. In
particular, we would like the interpretation of computation types to be
applications of the ambient monad.

Given a $\kappa$-bounded Lawvere theory $L$, the underlying sets of its
free algebras form a monad $T_L$ on $\setc$. $T_{\_}$ is functorial and
we can use it to construct a monad $\mon$ on $\pshlawcop$ such that:
\begin{equation*}
\mon(P)(L) = T_L(P(L))
\end{equation*}
We call $\mon$ the \emph{free algebras monad}, and it is the
representation of computations in the Ambient Monad model.
\begin{align*}
  &\sem{\Gamma \turnc c \types \tau} \mathrel{:}
    \homset{\pshlawcop}{\sem{\Gamma}}{\mon(\sem{\tau})} \\
  &\sem{\Gamma \turnc \return{v} \types \tau} =
    \unit{\mon}_{\sem{\tau}} \circ \sem{\Gamma \turnv v \types \tau} \\
  &\sem{\Gamma \turnc \letv{x}{c_1}{c_2} \types \tau_2} =
    \mult{\mon}_{\sem{\tau_2}}
    \circ \mon(\sem{\lbind{\Gamma}{x}{\tau_1} \turnc c_2 \types \tau_2})
    \circ \strength{\mon}_{\sem{\Gamma}, \sem{\tau_1}}
    \circ \langle id_{\sem{\Gamma}}, \sem{\Gamma \turnc c_1 \types \tau_1} \rangle
\end{align*}
where $\unit{\mon}$, $\mult{\mon}$ and $\strength{\mon}$ are the unit,
multiplication and strength respectively of $\mon$.

As a topos, $\pshlawcop$ has exponentials, which combine with the free
algebras monad to give us our semantics for function types.
\begin{equation*}
  \sem{\tau_1 \arr \tau_2} = \arrow{\sem{\tau_1}}{\mon(\sem{\tau_2})}
\end{equation*}

\subsection{The global modality}
\label{sec:global}

For any category $\cat$ with a terminal object $\terminal$, we
can define the global modality $\glob \types [\psh, \psh]$ such that:
$\glob(P)(L) = P(\terminal)$. In the case of $\pshlawcop$ this becomes:
\begin{equation*}
\glob(P)(L) = P(\initial)
\end{equation*}
$\glob$ forms a comonad on $\pshlawcop$. $\glob$ also distributes over
both products: $\glob (P \times Q) = (\glob P) \times (\glob Q)$, and
sums: $\glob (P + Q) = (\glob P) + (\glob Q)$.

Within the ambient monad model, this amounts to restricting a type to
only the elements which do not depend on the ambient monad. This is very
similar to the purity comonad of Choudhury and
Krishnaswami~\cite{choudhury2020recovering}. In particular,
\begin{equation*}
  \glob (\mon(P)) \quad = \quad T_{\initial} \circ \glob P
  \quad \cong \quad \glob P
\end{equation*}
as elements of the free algebras of the initial algebraic theory are
just elements of their carrier sets.

We use the $\glob$ comonad as our semantics for $\glob$ types and
$\glob$ bindings.
\begin{align*}
&\sem{\glob \tau} = \glob \sem{\tau} \\
&\sem{\gbind{\Gamma}{x}{\tau}} = \sem{\Gamma} \times \glob \sem{\tau} \\
&\sem{\gbind{\Gamma}{x}{\tau} \turnv x \types \tau} = \counit{\glob}_{\sem{\tau}} \circ \snd \\
&\sem{\Gamma \turnv \gbox{v} \types \glob \tau} =
  \glob \sem{\cdiv{\Gamma} \turnv v \types \tau}
  \circ \comult{\glob}_{\sem{\cdiv{\Gamma}}} \circ \bdiv{\Gamma} \\
&\sem{\Gamma \turnv \gunbox{x}{v_1}{v_2} \types \tau_2} =
  \sem{\gbind{\Gamma}{x}{\tau_1} \turnv v_2 \types \tau_2}
  \circ \langle id_{\sem{\Gamma}},
                \sem{\Gamma \turnv v_1 \types \glob \tau_1} \rangle \\
&\sem{\Gamma \turnv \grun{c} \types \tau} =
  \counit{\glob}_{\sem{\tau}} \circ \ununit_{\sem{\tau}}
  \circ \glob \sem{\cdiv{\Gamma} \turnc c \types \tau}
  \circ \comult{\glob}_{\sem{\cdiv{\Gamma}}} \circ \bdiv{\Gamma}
\end{align*}
where $\counit{\glob}$ and $\comult{\glob}$ are the counit and
comultiplication of $\glob$,
$\bdiv{\Gamma} \types \Gamma \rightarrow \cdiv{\Gamma}$ is the morphism
that projects the global bindings from $\Gamma$, and $\ununit_P$ is the
isomorphism from $\glob (\mon(P))$ to $\glob P$.

\subsection{Predicative signatures}
\label{sec:predicative}

We want $\sem{\Sigma}$ to be the $\kappa$-bounded Lawvere theory
corresponding to the signature $\Sigma$. However, whilst we can increase
$\kappa$ as necessary to support arbitrarily large types in signatures,
that is not actually sufficient to support all possible types in
signatures.

The issue is one of impredicativity. Our support for lightweight effect
polymorphism, whilst not full polymorphism, is sufficiently
polymorphism-like that using it within the parameter or arity of a
signature would require an impredicative (i.e. not set-theoretic)
model. In this paper we wish to keep the Ambient Monad model
set-theoretic, so instead we restrict the types that can be used in
signatures.

This impredicativity shows up in the denotation of function types. In
the general case an element of the set $\sem{\tau_1 \arr \tau_2}(L)$
contains a component in $T_{L^\prime}(\sem{\tau_2}(L^\prime))$ for
every $L^\prime$ in $\lawc$, and the set itself can be as large as the
product of those components. Sets in the image of $T_{L^\prime}(\_)$
can have cardinality $2^{<\kappa}$ -- which is not less than $\kappa$
and so cannot be the arity of an operation. However, if $\sem{\tau_1}$
is \emph{$\kappa$-generated} -- a coproduct of fewer than $\kappa$
representable presheaves -- then instead of $L^\prime$ ranging over all
Lawvere theories in $\lawc$ it only needs to range over a specific set
of fewer than $\kappa$ Lawvere theories determined by $\sem{\tau_1}$.

For example,
$\sem{(\yoneda{\Sigma} + 1) \arr \tau}(L) \cong T_{(L +
  \sem{\Sigma})}(\sem{\tau}(L + \sem{\Sigma})) \times
T_L(\sem{\tau}(L))$ so the semantics of the type
$(\yoneda{\Sigma} + 1) \arr \tau$ at $L$ depends only on
$T_{(L + \sem{\Sigma})}$ and $T_L$ rather than on all possible
$T_{L^\prime}$.

We can define a syntactic restriction that ensures a type's semantics
are $\kappa$-generated. We call these \emph{generated types}. We can
then define \emph{bounded types} as those where the domains of
functions are generated types. In Appendix~\ref{apdx:bounds} we show
that the cardinality of the semantics of a bounded type does not depend
on $\kappa$.
\begin{align*}
  \mathrm{generated\ types}, \taug ::=\;& \taug \times \taug \mid 1 \mid \taug + \taug
                              \mid \glob \taub
                              \mid \yoneda{\Sigma} \\
  \mathrm{bounded\ types}, \taub ::=\;& \taub \times \taub \mid 1 \mid \taub + \taub
                              \mid \taug \arr \taub \mid \glob \taub
                              \mid \ind{\Sigma}(\taub)
                              \mid \yoneda{\Sigma}
\end{align*}
Function types and our inductive types are not generated, however
$\glob \taub$ is generated for any bounded type $\taub$. This means
that, for example, the image of the embedding of the simply-typed lambda
calculus (Appendix~\ref{apdx:embedding}) lies entirely in the bounded
types, since it boxes the domain of every function type. Similarly, the
continuations of our inductive types already take their arguments boxed
(Fig.~\ref{fig:typing-inductive}).

A \emph{predicative signature} is one where the types of its parameters
and arities are all bounded. For any predicative signature $\Sigma$:
\begin{equation*}
  \{ \, op_1 \types \taub_{p_1} \rightarrowtail \taub_{a_1} \seq
  \ldots \seq
  op_n \types \taub_{p_n} \rightarrowtail \taub_{a_n} \, \}
\end{equation*}
$\sem{\Sigma}$ is the $\kappa$-bounded Lawvere theory for:
\begin{equation*}
  \{ \, op_1 \types \sem{\taub_{p_1}}(\initial)
                    \rightarrowtail \sem{\taub_{a_1}}(\initial) \seq
  \ldots \seq
  op_n \types \sem{\taub_{p_n}}(\initial)
              \rightarrowtail \sem{\taub_{a_n}}(\initial) \, \}
\end{equation*}
Note that by applying the types to the initial theory $\initial$ we
restrict them to their global elements: those that do not depend on the
current ambient monad.

In Appendix~\ref{apdx:bounds} we show that for any predicative signature
$\Sigma$ these parameters and arities are bounded by a cardinal
$\card{\Sigma}$ that is determined by the syntax of $\Sigma$,
independently of $\kappa$. Thus $\sem{\Sigma}$ is an object of $\lawc$
for any regular $\kappa$ with $\card{\Sigma} < \kappa$, and since
successor cardinals are regular a sufficiently large $\kappa$ always
exists. When working with the model we will assume all signatures are
predicative.

\subsection{Reflecting operations: The Yoneda embedding}
\label{sec:reflection}

We want to be able to reflect operations into the ambient monad. This
requires some way to represent operations of the ambient monad. We can
do that by using the \emph{Yoneda embedding}. For some category $\cat$,
the Yoneda embedding $\yoneda{\_}$ is a functor that maps objects
$C \types \cat$ to the presheaf of the morphisms into it:
\begin{equation*}
  \yoneda{C} = \homset{\cat}{\_}{C}
\end{equation*}
It is a full and faithful embedding of $\cat$ into $\psh$.

In our setting, this means that for each $\kappa$-bounded Lawvere theory
$L$ there is a presheaf $\yoneda{L}$ in $\pshlawcop$ such that:
\begin{align*}
&\yoneda{L}(L^{\prime}) = \homset{\lawc}{L}{L^{\prime}} \\
&\yoneda{L}(l^{\prime}) = \lambda f.\; l^{\prime} \circ f
\end{align*}
In other words, $\yoneda{L}$ gives you the set of mappings from $L$ into
the current ambient monad.

For an operation $op \types P \rightarrowtail A$ of a Lawvere theory
$L$, we can build a morphism:
\begin{align*}
&op_{\mon} \types
  \homset{\pshlawcop}
         {\yoneda{L} \times \glob P}
         {\mon(\glob A)} \\
&{(op_{\mon})}_{L^\prime}
  = \lambda(y, p). (y(op))_{T_{L^\prime}}(p, \unit{T_{L^\prime}}_{A})
\end{align*}
which uses an element of $\yoneda{L}$ to map $op$ to a term of the
ambient monad and then uses that to construct a term in the free
algebras monad.

We use $\yoneda{L}$ as the semantics for our effect capabilities, and
$op_{\mon}$ as the semantics for reflection.
\begin{align*}
&\sem{\yoneda{\Sigma}} = \yoneda{\sem{\Sigma}} \\
&\sem{\Gamma \turnc \perform{v_1}{op}{v_2} \types \glob \tau_a} = \\
&\quad op_{\mon}
       \circ \langle \sem{\Gamma \turnv v_1 \types \yoneda{\Sigma}},
                      \glob \sem{\cdiv{\Gamma} \turnv v_2 \types \tau_p}
                      \circ \comult{\glob}_{\sem{\cdiv{\Gamma}}} \circ \bdiv{\Gamma} \rangle
\end{align*}

The Yoneda embedding preserves finite products, which for our case
means:
\begin{equation*}
\yoneda{L + L^{\prime}} \cong \yoneda{L} \times \yoneda{L^{\prime}}
\end{equation*}
which we use for the semantics of $\outlname$ and $\outrname$.

\subsection{Representing effectful computations: The Yoneda lemma}

We can represent computations in a specific monad using the Yoneda
lemma. The Yoneda lemma says that, for any $P \types \psh$ and
$\catobj \types \cat$, there is an isomorphism:
\begin{equation*}
  \homset{\psh}{\yoneda{\catobj}}{P} \cong P(\catobj)
\end{equation*}

Applying that to the composition of the free algebras monad and the
global modality we get:
\begin{equation*}
  \homset{\pshlawcop}{\yoneda{L}}{\mon(\glob \sem{\tau})} \cong \mon(\glob \sem{\tau})(L) = T_L(\sem{\tau}(\initial))
\end{equation*}

In terms of our semantics, this means that computations of type
$\glob \tau$ with a single free variable of type $\yoneda{\Sigma}$ are
isomorphic to values of the free algebra of $\sem{\Sigma}$ at
$\sem{\tau}(\initial)$.

\subsection{Effect reification and inductive types}
\label{sec:reification}

The essence of algebraic effect handlers is taking a computation in
$T_{L + \Sigma}(S)$, the free algebras of the sum of an algebraic theory
$L$ and an algebraic signature $\Sigma$, splitting out and handling
$\Sigma$, leaving a computation in only the algebraic theory
$T_{L}(S^\prime)$.

The key to this process is the following lemma, which is Theorem~4
of Hyland et al.~\cite{hyland2006combining}.
\begin{lemma}
\label{lemma:sums}
  For any $\kappa$-bounded Lawvere theory $L$ and algebraic signature $\Sigma$
  \begin{equation*}
  T_{L + \Sigma}(S) \cong \mu X.T_L(S + F_\Sigma(X))
  \end{equation*}
\end{lemma}
where $\mu X.G(X)$ is the initial algebra of some endofunctor $G$. This
lemma is crucial because it shows that computations using both ambient
effects $L$ and the signature $\Sigma$ can be reorganized as a recursive
structure that separates the two effect sources -- exactly what effect
handlers need.

Effect reification works by exposing $\mu X.T_L(S + F_\Sigma(X))$ to the
user via an inductive type. Presheaves over small categories, such as
$\lawcop$, have W-types, so we can construct the required initial
algebra as a presheaf. Given an algebraic signature $\Sigma$ and a
presheaf $P$, we define the following family of initial algebras:
\begin{align*}
&\ind{\Sigma} \types [\pshlawcop, \pshlawcop] \\
&\ind{\Sigma}(P) = \mu X. ((\glob P) + F_\Sigma \circ \mon X)
\end{align*}
and observe the following variation on Lemma \ref{lemma:sums}.
\begin{lemma}
\label{lemma:sums2}
  For any $\kappa$-bounded Lawvere theory $L$ and algebraic signature $\Sigma$
  \begin{equation*}
  T_{L + \Sigma}(P(\initial)) \cong \mon(\ind{\Sigma}(P))(L)
  \end{equation*}
\end{lemma}

We use these initial algebras as the semantics of $\ind{\Sigma}$:
\begin{mathpar}
\sem{\ind{\Sigma}(\tau)} = \ind{\sem{\Sigma}}(\sem{\tau})
\end{mathpar}

Exponentials in categories of presheaves are defined such that
$\arrow{P}{Q}(\catobj) \cong \homset{\psh}{\yoneda{\catobj} \times
  P}{Q}$.  Applying this to $\arrow{\yoneda{L}}{\mon(\glob P)}$ and then
applying the Yoneda Lemma we get:
\begin{align*}
\arrow{\yoneda{L}}{\mon(\glob P)}(L^{\prime})
  &\cong \homset{\pshlawcop}{\yoneda{L^{\prime}} \times \yoneda{L}}{\mon(\glob P)} \\
  &\cong \homset{\pshlawcop}{\yoneda{L^{\prime} + L}}{\mon(\glob P)} \\
  &\cong \mon(\glob P)(L^{\prime} + L) \\
  &\cong T_{(L^{\prime} + L)}(P(\initial))
\end{align*}

In the case where $L$ is a signature $\Sigma$, we can further apply
Lemma \ref{lemma:sums2} and, observing that all the steps in this proof
were natural in $L^{\prime}$, produce this isomorphism:
\begin{equation*}
  \mon(\ind{\Sigma}(P)) \cong \arrow{\yoneda{\Sigma}}{\mon(\glob P)}
\end{equation*}
which we call $\reifyc{\Sigma}{}$.

$\reifyc{\Sigma}{}$ gives us our semantics for reification.
\begin{align*}
&\sem{\Gamma \turnc \reify{\loc}{c} \types \ind{\Sigma}(\tau)} =
  \reifyc{\Sigma}{\sem{\tau}} \circ \currying{\sem{\lbind{\Gamma}{\loc}{\Sigma} \turnc c \types \glob \tau}}
\end{align*}

\subsection{Properties of the denotational semantics}

The denotational semantics is sound:
\begin{theorem}
\label{lemma:soundness}
  \begin{align*}
    &\Gamma \turnv v_1 \types \tau
    \wedge v_1 \stepstov v_2
    \implies \sem{\Gamma \turnv v_1 \types \tau}
           = \sem{\Gamma \turnv v_2 \types \tau} \\
    &\Gamma \turnc c_1 \types \tau
    \wedge c_1 \stepstoc c_2
    \implies \sem{\Gamma \turnc c_1 \types \tau}
           = \sem{\Gamma \turnc c_2 \types \tau}
  \end{align*}
\end{theorem}
and adequate for contextual equality $\ctxeq$:
\begin{theorem}
\label{lemma:adequacy}
  \begin{equation*}
    \sem{\turnv v_1 \types \tau} = \sem{\turnv v_2 \types \tau}
    \implies \turnv v_1 \ctxeq v_2 \types \tau
  \end{equation*}
\end{theorem}

We present the full semantics, precisely define contextual equality, and
prove these properties in Appendix~\ref{apdx:denotational}.

\section{Effect reflection in practice}
\label{sec:practice}

We provide effect reflection as a simple library API in OxCaml based on
OxCaml's support for locality (see Section~\ref{sec:locality}). In this
section we describe this API and its implementation.

\subsection{Effect reflection interface}
\label{sec:interface}

\begin{figure}
\begin{lstlisting}[style=oxcaml]
  module type Sig = sig type 'a t end
  module Continuation(E : Sig) : sig type ('r, 'a) t end
  module Term (E : Sig) : sig
    type 'a t =
      | Return : 'a @@ global -> 'a t
      | Perform : 'r E.t @@ global * ('r, 'a) Continuation(E).t -> 'a t
  end
  module Handler(E : Sig) : sig type t end
\end{lstlisting}
\caption{Effect reflection types}
\label{fig:ox-types}
\end{figure}
The types of the effect reflection interface are shown in
Fig.~\ref{fig:ox-types}. These types are higher-kinded: they are
parameterized by type constructors representing the operations of an
algebraic effect. In OxCaml, such types must be built using functors. We
use a simple module type \lstinline[style=oxcaml]{Sig} to act as the
parameter type for these functors.

The \lstinline[style=oxcaml]{'a Term(E).t} type corresponds to
$\ind{\Sigma}(\tau)$ and represents terms in the free algebra of
\lstinline[style=oxcaml]{E}.

The \lstinline[style=oxcaml]{Handler(E).t} type corresponds to
$\yoneda{\Sigma}$ and represents the capability to perform operations
from \lstinline[style=oxcaml]{E}.

\lstinline[style=oxcaml]{('r, 'a) Continuation(E).t} is equivalent to
\lstinline[style=oxcaml]{'r -> 'a Term(E).t} when global and equivalent
to \lstinline[style=oxcaml]{'r -> 'a Term(E).t @ local} when local. This
ensures that the global modality distributes over
\lstinline[style=oxcaml]{Term(E).t}, which is an important property of
$\ind{\Sigma}$. The need for this type is an artifact of OxCaml's
approach to locality: the global modality does not distribute over the
function arrow in OxCaml.

\begin{figure}
\begin{lstlisting}[style=oxcaml]
  module Reflection (E : Sig) : sig
    val reify :
      (Handler(E).t @ local -> 'a) @ local -> 'a Term(E).t @ local

    val reify_global : (Handler(E).t @ local -> 'a) -> 'a Term(E).t

    val perform : 'a E.t -> (Handler(E).t @ local -> 'a)

    val continue :
      ('r, 'a) Continuation(E).t @ local -> 'r -> 'a Term(E).t @ local

    val continue_global :
      ('r, 'a) Continuation(E).t -> 'r -> 'a Term(E).t
  end
\end{lstlisting}
\caption{Effect reflection interface}
\label{fig:ox-interface}
\end{figure}
The main piece of the API is a family of isomorphisms:
\vspace{-1mm}
\begin{equation*}
  \text{\lstinline[style=oxcaml]{'a Term(E).t}} \qquad
  \cong \qquad \text{\lstinline[style=oxcaml]{Handler(E).t @ local -> 'a}}
\end{equation*}
\vspace{-1mm}
which we expose as three functions: \lstinline[style=oxcaml]{reify},
\lstinline[style=oxcaml]{reify_global} and
\lstinline[style=oxcaml]{perform}. These are provided by the
\lstinline[style=oxcaml]{Reflection} functor
(Fig.~\ref{fig:ox-interface}), along with the functions for continuing a
continuation.

\lstinline[style=oxcaml]{reify} and
\lstinline[style=oxcaml]{reify_global} implement the right-to-left
direction of the isomorphism. We need two separate functions because
OxCaml currently lacks any form of locality polymorphism.
\lstinline[style=oxcaml]{perform} is equivalent to the left-to-right
direction of the isomorphism. It reflects individual operations as
opposed to full terms, which is a more convenient primitive in practice.

\subsection{Effect reflection implementation}

We can implement the effect reflection interface directly in terms of
OCaml's untracked effect
handlers~\cite{Sivaramakrishnan2021retrofitting}. The entire
implementation is given in Appendix \ref{apdx:implementation}. The trick
is to generate a fresh effect constructor for each reification, pass
that constructor around as part of the
\lstinline[style=oxcaml]{handler}, and then use it to perform operations
during reflection. Performing effects involves a single indirect call
and then an underlying perform operation, so its performance is
essentially the same as the performance of OCaml's algebraic effects.

For various practical reasons, OCaml's algebraic effects only allow
continuations to be resumed a single time. There is no fundamental
reason for effect reflection to be so restricted, and we ignore the
restriction in this paper, but our actual implementation inherits it
from OCaml. Note that OxCaml's \lstinline[style=oxcaml]{once}
mode~\cite{lorenzen2024oxidizing} allows us to enforce this restriction
statically.

\subsection{Example: Generators}

A more realistic use of effect reflection than integer state is a
\emph{generator} effect. This effect has a single operation
\lstinline[style=oxcaml]{Gen} from \lstinline[style=oxcaml]{int} to
\lstinline[style=oxcaml]{unit}, along with a handler that turns
computations using \lstinline[style=oxcaml]{Gen} into streams of
integers, shown in Fig.~\ref{fig:gen}.
\begin{figure}
\begin{lstlisting}[style=oxcaml]
  type ints = Finished | More of int * (unit -> ints)

  let handle_gen f =
    let rec loop : unit Term(Gen).t -> ints = function
      | Return () -> Finished
      | Perform(Gen i, k) ->
          More(i, fun () -> loop (Gen_eff.continue_global k ()))
    in
    loop (Gen_eff.reify_global f)
\end{lstlisting}
\caption{Handler for integer generators}
\label{fig:gen}
\end{figure}
Unlike the state handler, here we must use
\lstinline[style=oxcaml]{reify_global} rather than
\lstinline[style=oxcaml]{reify} because our intention is that the
resulting stream of integers be a global value that can escape the
current region. This in turn forces us to require that the handled
function be global.

\subsection{Example: Asynchronous I/O}

Perhaps the most common use case for algebraic effects is for
concurrency and asynchronous I/O. Implementing asynchronous I/O from
scratch is beyond the scope of this paper, but we can build a simple
version on top of an existing monadic concurrency library
(Fig.~\ref{fig:aio}). Assuming we have a monadic future type
\lstinline[style=oxcaml]{'a Deferred.t} we can write concurrent code in
direct style by using an effect with a single
\lstinline[style=oxcaml]{Await} operation that waits for a future to be
completed.
\begin{figure}
\begin{lstlisting}[style=oxcaml]
  let handle_await f =
    let rec loop : 'a Term(Await).t -> 'a Deferred.t = function
      | Return x -> Deferred.return x
      | Perform(Await d, k) ->
          Deferred.bind d (fun x -> loop (Await_eff.continue_global k x))
    in
    loop (Await_eff.reify_global f)
\end{lstlisting}
\caption{Handler for Asynchronous I/O}
\label{fig:aio}
\end{figure}

\subsection{Nested effect handlers}

A key feature of algebraic effects is how easily they compose. We can
use state whilst using asynchronous I/O by simply nesting their
handlers:
\begin{lstlisting}[style=oxcaml]
    handle_await (fun ah ->
      handle_state i (fun sh ->
        List.iter (fun fl ->
          let s = await ah (File.read fl) in
          set sh (int_of_string s + get sh)) files;
        get sh))
\end{lstlisting}
This relies on the fact that \lstinline[style=oxcaml]{handle_state} uses
\lstinline[style=oxcaml]{reify} rather than
\lstinline[style=oxcaml]{reify_global} and so is able to operate on a
local computation that closes over the local await handler value
\lstinline[style=oxcaml]{ah}.

\section{Related work}
\label{sec:related-work}

\subsection{Lightweight effect polymorphism}

\looseness=-1
There have been a number of efforts to avoid the complexity of effect
polymorphism by treating effect annotations as relevant to some ambient
effect. Frank~\cite{convent2020doo} proposed that higher-order functions
should state the effects available to their arguments relative to the
effects that they perform. This allows functions like
\lstinline[style=oxcaml]{List.map} to have types that do not mention
effects. However, in Frank, this was merely syntactic sugar: under the
hood the type for \lstinline[style=oxcaml]{List.map} was still using
effect polymorphism.

Effekt~\cite{brachthauser2020effects} takes the idea further than just
syntax, with all functions stating their effects relative to the
current set of available effects. However, it requires that functions be
second-class values to ensure that they don't escape the scope of a
handler that they might be relying on.

More recent work on Effekt~\cite{brachthauser2022effects} adds support
for turning second-class functions into first-class values by wrapping
them in a modality that tracks which effect capabilities the function
uses. There is no lightweight effect polymorphism for these wrapped
values though, so any code which places its functions inside of data
structures must fall back to ordinary effect polymorphism. This approach
also requires native support for these effect capability modalities.

Modal effect types~\cite{tang2025modal} also make effect annotations
relative to the current set of available effects. This system uses
modal effect types to track the difference between the currently available effects and
the effects required by a value. This avoids needing to treat functions
as second class, but does still require specific effect support in the
type system.

\subsection{Lexical and named effect handlers}

Effect capabilities are closely related to \emph{lexical effect
  handlers} in systems such as Biernacki et
al.~\cite{biernacki2019binders}. Lexical effect handlers have a value
that represents the effect handler, similar to $\yoneda{\Sigma}$ values,
but these values are second class and require their own special typing
rules. These systems still use absolute effect annotations that indicate
all the effects used by a computation.

\emph{Named effect handlers}~\cite{xie2022first} also have values that
represent effect handlers. Rather than make these values second class,
they use higher-rank polymorphism to emulate locality tracking in much
the same way as the \lstinline[style=haskell]{ST} monad in Haskell. This
still requires using an effect system to track which named effects are
used by a computation. Using higher-rank polymorphism prevents global
type inference and demands a higher annotation burden on the programmer.

\subsection{Monadic reflection}

Effect reflection's presentation as reification and reflection
operations is very similar to monadic
reflection~\cite{filinski1999representing}. Monadic reflection allows
arbitrary monads to be reified and reflected. As arbitrary monads do not
always have well-defined sums, the user must also define
\emph{glue} functions that describe the interaction between the monad
being reified and the current computation monad.

Monadic reflection also relies on an effect system to track the monads
being used. By using locality and $\yoneda{\Sigma}$ values we avoid the
need to have an effect system.

\subsection{Semantics of algebraic effect handlers}

Hyland et al.~\cite{hyland2006combining} investigate combining algebraic
effects, including the key property of sums of algebraic theories (our
Lemma \ref{lemma:sums}) on which handlers are based.

\looseness=-1
The original work on algebraic effect
handlers~\cite{plotkin2009handlers,plotkin2013handling} gives a
semantics in terms of free algebras but the semantics works with a fixed
countable algebraic theory: handlers do not actually change the ambient
monad. Our Ambient Monad model naturally accommodates changing the
ambient monad.

Bauer and Pretnar give an untyped denotational semantics for
Eff~\cite{bauer2015programming}, and a typed one in which effects are
treated as extrinsic to the semantics~\cite{bauer2014effect}.

Forster et al.~\cite{forster2017expressive} give a set-theoretic
denotational semantics of a calculus with algebraic effect handlers. It
is typed and represents effects using their free algebras. However,
their calculus supports neither nesting effect handlers nor effect
polymorphism, which means the handlers described are not modular or
composable.

\subsection{Comonadic purity, locality and presheaves}

Our use of a comonadic global modality to track values which do not
depend on the ambient monad is essentially the same as the purity
comonad described by Choudhury and
Krishnaswami~\cite{choudhury2020recovering}. Their semantic description
of their comonad is very different -- based on a semantics of
capabilities -- but the typing rules, and the practical result, are the
same.

The Ambient Monad model is closely related to presheaf semantics for
higher-order abstract syntax~\cite{fiore1999abstract, hofmann1999semantical, hu2022category}. In both cases
presheaves are used to index the semantics of types and terms by some
implicit notion of context, with the Yoneda embedding used to access
this context and the global modality used to control dependence on it.

\section{Future work}
\label{sec:future-work}

\paragraph{Reification with equations}

\looseness=-1
In this paper we only support reifying effect signatures with no
equations as W-types. It should be possible to extend this to reifying
arbitrary effect theories as QW-types~\cite{fiore2020constructing}. This
would require working in a base language that can support such types,
e.g. Observational Type Theory~\cite{altenkirch2007observational,
  pujet2022observational}, and generally extending the scheme to
dependent types. It would also require using something more general than
Lemma~\ref{lemma:sums} for representing the sum of two algebraic theories.

\paragraph{Separation and commuting effects}
In addition to having a sum, $\kappa$-bounded Lawvere theories $L$ and
$L^\prime$ also have a tensor product
$L \otimes L^\prime$~\cite{hyland2006combining}, which gives a symmetric
monoidal structure on $\lawc$.  Presheaves over the opposite of a
symmetric monoidal category are the standard categorical semantics of
the logic of Bunched Implications~\cite{o1999logic}, which is the basis
of the assertion language in Separation Logic. We could thus use the
Ambient Monad model as a model of languages that have a notion of
separation. Operations on two separated effect capabilities would be
known to commute.

\section{Subject reduction}
\label{apdx:subject-reduction}

In this section we prove subject reduction for our operational
semantics. We start by proving some general lemmas that we'll need in
the proof. Note that we will refer to a property that applies to both
value and computation terms, and which must be shown by mutual
induction, as a single lemma.

\subsection{Context division lemmas}

We will need some simple lemmas describing the behaviour of the context
division operator $\cdiv{\Gamma}$, all of which follow directly by
induction on the context.
\begin{lemma}
\label{lemma:local-cdiv}
  \begin{equation*}
    \cdiv{(\ccons{\lbind{\Gamma_1}{x}{\tau}}{\Gamma_2})} = \cdiv{(\ccons{\Gamma_1}{\Gamma_2})}
  \end{equation*}
\end{lemma}
\begin{lemma}
\label{lemma:yoneda-cdiv}
  \begin{equation*}
    \cdiv{(\ccons{\lbind{\Gamma_1}{\loc}{\Sigma}}{\Gamma_2})} = \cdiv{(\ccons{\Gamma_1}{\Gamma_2})}
  \end{equation*}
\end{lemma}
\begin{lemma}
\label{lemma:global-cdiv}
  \begin{equation*}
    \cdiv{(\ccons{\gbind{\Gamma_1}{x}{\tau}}{\Gamma_2})} = \ccons{\gbind{\cdiv{\Gamma_1}}{x}{\tau}}{\cdiv{\Gamma_2}}
  \end{equation*}
\end{lemma}
\begin{lemma}
\label{lemma:cdiv-idempotent}
  \begin{equation*}
    \cdiv{\cdiv{\Gamma}} = \cdiv{\Gamma}
  \end{equation*}
\end{lemma}

\subsection{Weakening lemmas}

We need lemmas stating that we can weaken typing judgements with new
variable bindings of both $x$ and $\loc$ variables.
\begin{lemma}
\label{lemma:local-weakening}
  \begin{align*}
    &\ccons{\Gamma_1}{\Gamma_2} \turnv v \types \tau_1
    \quad \implies \quad \ccons{\lbind{\Gamma_1}{x}{\tau_2}}{\Gamma_2} \turnv v \types \tau_1 \\
    &\ccons{\Gamma_1}{\Gamma_2} \turnc c \types \tau_1
    \quad \implies \quad \ccons{\lbind{\Gamma_1}{x}{\tau_2}}{\Gamma_2} \turnc c \types \tau_1
  \end{align*}
\end{lemma}
\begin{lemma}
\label{lemma:yoneda-weakening}
  \begin{align*}
    &\ccons{\Gamma_1}{\Gamma_2} \turnv v \types \tau
    \quad \implies \quad \ccons{\lbind{\Gamma_1}{\loc}{\Sigma}}{\Gamma_2} \turnv v \types \tau \\
    &\ccons{\Gamma_1}{\Gamma_2} \turnc c \types \tau
    \quad \implies \quad \ccons{\lbind{\Gamma_1}{\loc}{\Sigma}}{\Gamma_2} \turnc c \types \tau
  \end{align*}
\end{lemma}
The proofs of these follow by mutual induction on the value and
computation typing rules. The only aspect that isn't straightforward is
that rules with premises featuring $\cdiv{\Gamma}$ rely on
\ref{lemma:local-cdiv} and \ref{lemma:yoneda-cdiv} to reuse those
premises with the weakened context.

We similarly need a lemma stating that we can weaken typing
judgements with new global variable bindings.
\begin{lemma}
\label{lemma:global-weakening}
  \begin{align*}
    &\ccons{\Gamma_1}{\Gamma_2} \turnv v \types \tau_1
    \quad \implies \quad \ccons{\gbind{\Gamma_1}{x}{\tau_2}}{\Gamma_2} \turnv v \types \tau_1 \\
    &\ccons{\Gamma_1}{\Gamma_2} \turnc c \types \tau_1
    \quad \implies \quad \ccons{\gbind{\Gamma_1}{x}{\tau_2}}{\Gamma_2} \turnc c \types \tau_1
  \end{align*}
\end{lemma}
This again follows by mutual induction on the value and computation
typing rules. Rules with premises featuring $\cdiv{\Gamma}$ rely on
\ref{lemma:global-cdiv} in order to make use of the inductive hypothesis
on those premises.

We also need a lemma stating that we can weaken from $\cdiv{\Gamma}$ to
$\Gamma$.
\begin{lemma}
\label{lemma:cdiv-weakening}
  \begin{align*}
    &\ccons{\cdiv{\Gamma_1}}{\Gamma_2} \turnv v \types \tau
    \quad \implies \quad \ccons{\Gamma_1}{\Gamma_2} \turnv v \types \tau \\
    &\ccons{\cdiv{\Gamma_1}}{\Gamma_2} \turnc c \types \tau
    \quad \implies \quad \ccons{\Gamma_1}{\Gamma_2} \turnc c \types \tau
  \end{align*}
\end{lemma}
This follows by induction on $\Gamma_1$ via the local weakening lemmas
(\ref{lemma:local-weakening} and \ref{lemma:yoneda-weakening}).

\subsection{Substitution lemmas}

We need a simple lemma stating that substituting unbound variables does
nothing, which follows directly from mutual induction on typing rules:
\begin{lemma}
\label{lemma:unbound-substitution}
  \begin{align*}
    &\Gamma \turnv v_1 \types \tau
    \quad \wedge \quad x \notin \Gamma
    \quad \implies \quad \sbst{v_1}{x}{v_2} = v_1 \\
    &\Gamma \turnc c \types \tau
    \quad \wedge \quad x \notin \Gamma
    \quad \implies \quad \sbst{c}{x}{v} = c
  \end{align*}
\end{lemma}

We need a lemma demonstrating that substitution for local bindings
preserves typing.
\begin{lemma}
\label{lemma:local-substitution}
  \begin{align*}
    &\ccons{\lbind{\Gamma_1}{x}{\tau_1}}{\Gamma_2} \turnv v_1 \types \tau_2
    \quad \wedge \quad \ccons{\Gamma_1}{\Gamma_2} \turnv v_2 \types \tau_1
    \quad \implies \quad \ccons{\Gamma_1}{\Gamma_2} \turnv \sbst{v_1}{x}{v_2} \types \tau_2 \\
    &\ccons{\lbind{\Gamma_1}{x}{\tau_1}}{\Gamma_2} \turnc c \types \tau_2
    \quad \wedge \quad \ccons{\Gamma_1}{\Gamma_2} \turnv v \types \tau_1
    \quad \implies \quad \ccons{\Gamma_1}{\Gamma_2} \turnc \sbst{c}{x}{v} \types \tau_2
  \end{align*}
\end{lemma}
This follows by mutual induction on the typing rules for $v_1$ and
$c$. Cases with premises that extend the context rely on weakening
(\ref{lemma:local-weakening} and \ref{lemma:global-weakening}) to apply
the inductive hypothesis on those premises. Cases with premises that use
$\cdiv{}$ rely on \ref{lemma:unbound-substitution} to reuse the original
premise.

Similarly, we need a lemma demonstrating that substitution for global bindings
preserves typing.
\begin{lemma}
\label{lemma:global-substitution}
  \begin{align*}
    &\ccons{\gbind{\Gamma_1}{x}{\tau_1}}{\Gamma_2} \turnv v_1 \types \tau_2
    \quad \wedge \quad \cdiv{\ccons{\Gamma_1}{\Gamma_2}} \turnv v_2 \types \tau_1
    \quad \implies \quad \ccons{\Gamma_1}{\Gamma_2} \turnv \sbst{v_1}{x}{v_2} \types \tau_2 \\
    &\ccons{\gbind{\Gamma_1}{x}{\tau_1}}{\Gamma_2} \turnc c \types \tau_2
    \quad \wedge \quad \cdiv{\ccons{\Gamma_1}{\Gamma_2}} \turnv v \types \tau_1
    \quad \implies \quad \ccons{\Gamma_1}{\Gamma_2} \turnc \sbst{c}{x}{v} \types \tau_2
  \end{align*}
\end{lemma}
This follows by mutual induction on the typing rules for $v_1$ and
$c$. Cases with premises that extend the context with global bindings
rely on weakening (\ref{lemma:global-weakening}) to apply the inductive
hypothesis on those premises. Cases with premises that extend the
context with local bindings can already apply the inductive hypothesis
without weakening. Cases with premises that use $\cdiv{}$ rely on the
idempotence of $\cdiv{}$ (\ref{lemma:cdiv-idempotent}) to apply the
inductive hypothesis. The variable case that actually substitutes $v_2$
uses Lemma \ref{lemma:cdiv-weakening} to weaken $v_2$ to the right
context.

\subsection{Subject reduction}

We prove subject reduction (Theorem~\ref{lemma:subject-reduction}):
\begin{align*}
  &\Gamma \turnv v_1 \types \tau
  \quad \wedge \quad v_1 \stepstov v_2
  \quad \implies \quad \Gamma \turnv v_2 \types \tau \\
  &\Gamma \turnc c_1 \types \tau
  \quad \wedge \quad c_1 \stepstoc c_2
  \quad \implies \quad \Gamma \turnc c_2 \types \tau
\end{align*}
by mutual induction over the two reduction relations. The reduction
relations are the least relations closed under the rules in
Fig.~\ref{fig:reduction} combined with the obvious congruence rules.

\begin{proof}
As all the typing rules are entirely compositional, the cases for the
congruence rules all follow directly by induction. This leaves only the
rules from Fig.~\ref{fig:reduction}.

Note that the typing rules are syntax directed so there is always only a
single typing rule that we need to consider.

\begin{description}
\item[Products] For the product beta rules:
\begin{align*}
\fst{(v_1, v_2)} &\stepstov v_1 \\
\snd{(v_1, v_2)} &\stepstov v_2
\end{align*}
the cases follow directly by inversion on the typing rule.

\item[Sums] For the sum rules:
\begin{align*}
\casem{(\inl{v_1})}{x_1}{v_2}{x_2}{v_3} &\stepstov \sbst{v_2}{x_1}{v_1} \\
\casem{(\inr{v_1})}{x_1}{v_2}{x_2}{v_3} &\stepstov \sbst{v_3}{x_2}{v_1}
\end{align*}
the cases follow by inversion on the typing rules followed by case
splitting on the modality $m$ and applying either the global
(\ref{lemma:global-substitution}) or local
(\ref{lemma:local-substitution}) substitution lemma.

\item[Global modality] For the global modality rule:
\begin{equation*}
\gunbox{x}{\gbox{v_1}}{v_2} \stepstov \sbst{v_2}{x}{v_1}
\end{equation*}
the case follows by inversion on the typing rules followed by the global
substitution lemma (\ref{lemma:global-substitution}).

For the run rule:
\begin{equation*}
\grun{\return{v}} \stepstov v
\end{equation*}
the case follows by inversion on the typing rules along with weakening
via Lemma \ref{lemma:cdiv-weakening}.

\item[Inductive types]
For the $\indelimname$/$\retname$ rule:
\begin{equation*}
\indelim{(\ret{v_s})}{\indretcase{x}{v_e} \seq \ldots} \stepstov \sbst{v_e}{x}{v_s}
\end{equation*}
the case follows by inversion on the typing rules followed by the global
substitution lemma (\ref{lemma:global-substitution}).

For the $\indelimname$/$op$ rule:
\begin{align*}
\indelim{(\indintro{op}{v_1}{v_2})}{H_1 \seq \indcase{op}{x_1}{x_2}{v_3} \seq H_2} &\stepstov \\
  \sbst{\sbst{v_3}{x_1}{v_1}}{x_2}
  {\abs{x_a}{\letv{x_w}{\app{v_2}{x_a}}{&\return{(\indelim{x_w}{H_1 \seq \indcase{op}{x_1}{x_2}{v_3} \seq H_2})}}}}
\end{align*}
the case follows by inversion on the typing rules followed by the global
substitution lemma (\ref{lemma:global-substitution}) for $x_1$ and the
local substitution lemma (\ref{lemma:local-substitution}) for $x_2$.

\item[Functions]
The case for the function beta rule:
\begin{equation*}
\app{(\abs{x}{c})}{v} \stepstoc \sbst{c}{x}{v}
\end{equation*}
follows by inversion on the typing rules followed by the local
substitution lemma (\ref{lemma:local-substitution}).

\item[Bind]
The case for the bind/return rule:
\begin{equation*}
\letv{x}{\return{v}}{c} \stepstoc \sbst{c}{x}{v}
\end{equation*}
follows by inversion on the typing rules followed by the local
substitution lemma (\ref{lemma:local-substitution}).

The case for the bind commuting rule: 
\begin{equation*}
\letv{x_2}{\letv{x_1}{\perform{\loc}{op}{v}}{c_1}}{c_2} \stepstoc \letv{x_1}{\perform{\loc}{op}{v}}{\letv{x_2}{c_1}{c_2}}
\end{equation*}
follows by inversion on the typing rules followed by weakening $c_2$ by
the local binding of $x_1$.

\item[Reflection]

The cases for the $\outlname$ and $\outrname$ rules
\begin{align*}
\perform{(\outl{v_1})}{op}{v_2} &\stepstoc \perform{v_1}{\mathrm{left}(op)}{v_2} \\
\perform{(\outr{v_1})}{op}{v_2} &\stepstoc \perform{v_1}{\mathrm{right}(op)}{v_2}
\end{align*}
follow directly by inversion on the typing rules.

\item[Reification]

The cases for the $\reifyname$ rules:
\begin{align*}
\reify{\loc}{\return{(\gbox{v})}} &\stepstoc \return{\ret{v}} \\
\reify{\loc_1}{\perform{\loc_1}{op}{v}} &\stepstoc \return{\indintro{op}{v}{\abs{(\gbox{x})}{\return{\ret{x}}}}} \\
\reify{\loc_1}{\letv{x}{\perform{\loc_1}{op}{v}}{c}} &\stepstoc \return{\indintro{op}{v}{\abs{x}{\reify{\loc_1}{c}}}} \\
\reify{\loc_1}{\perform{\loc_2}{op}{v}} &\stepstoc \letv{(\gbox{x})}{\perform{\loc_2}{op}{v}}{\return{\ret{x}}} \qquad (\loc_1 \neq \loc_2) \\
\reify{\loc_1}{\letv{x}{\perform{\loc_2}{op}{v}}{c}} &\stepstoc \letv{x}{\perform{\loc_2}{op}{v}}{\reify{\loc_1}{c}} \qquad (\loc_1 \neq \loc_2)
\end{align*}
follow by inversion on the typing rules followed by \ref{lemma:yoneda-cdiv}.
\end{description}
\end{proof}

\section{Confluence}
\label{apdx:church-rosser}

We prove that the reduction relations are confluent:
\begin{align*}
  &v_1 \reducestov v_2
    \quad \wedge \quad v_1 \reducestov v_3
    \quad \implies \quad \exists\, v_4. \quad v_2 \reducestov v_4
    \quad \wedge \quad v_3 \reducestov v_4 \\
  &c_1 \reducestoc c_2
    \quad \wedge \quad c_1 \reducestoc c_3
    \quad \implies \quad \exists\, c_4. \quad c_2 \reducestoc c_4
    \quad \wedge \quad c_3 \reducestoc c_4
\end{align*}

$\parastepstov$ and $\parastepstoc$. The inference rules describing
parallel reduction are given in Fig.~\ref{fig:parallel-value-reduction}

Parallel reductions are reflexive:
\begin{lemma}
\label{lemma:parallel-reduction-reflexive}
  \begin{equation*}
    v \parastepstov v \qquad
    c \parastepstoc c
  \end{equation*}
\end{lemma}
which follows by induction on $v$ and $c$ via the congruence rules.

A single step of ordinary reduction is a valid parallel reduction:
\begin{lemma}
\label{lemma:parallel-reduction-of-reduction}
  \begin{align*}
    &v_1 \stepstov v_2
    \quad \implies \quad v_1 \parastepstov v_2 \\
    &c_1 \stepstoc c_2
    \quad \implies \quad c_1 \parastepstoc c_2
  \end{align*}
\end{lemma}
This follows by induction on the ordinary reductions. Each rule of the
ordinary reduction has a corresponding rule in the parallel reduction
that can be used, applying reflexivity of the parallel reduction
\ref{lemma:parallel-reduction-reflexive} on subterms as needed.

A single step of parallel reduction corresponds to a sequence of steps
in the ordinary reduction.
\begin{lemma}
\label{lemma:reductions-of-parallel-reduction}
  \begin{align*}
    &v_1 \parastepstov v_2
    \quad \implies \quad v_1 \reducestov v_2 \\
    &c_1 \parastepstoc c_2
    \quad \implies \quad c_1 \reducestoc c_2
  \end{align*}
\end{lemma}
This follows by induction on the parallel reductions. Each rule of the
parallel reduction relation has a corresponding rule of the ordinary
reduction relation. We use transitivity of $\reducestoname$ to first
apply congruence rules to reduce subterms before applying the actual
corresponding rule.

\subsection{Substitution}

The above lemmas mean that showing confluence of $\parareducestoname$ is
sufficient to show confluence of $\reducestoname$. To do that we first
need a lemma showing that substitution commutes with parallel reduction:
\begin{lemma}
\label{lemma:subst-of-parallel-reduction}
  \begin{align*}
  &v_1 \parastepstov v_3
    \quad \wedge \quad v_2 \parastepstov v_4
    \quad \implies \quad \sbst{v_1}{x}{v_2} \parastepstov \sbst{v_3}{x}{v_4} \\
  &c_1 \parastepstoc c_2
    \quad \wedge \quad v_1 \parastepstov v_2
    \quad \implies \quad \sbst{c_1}{x}{v_1} \parastepstoc \sbst{c_2}{x}{v_2}
  \end{align*}
\end{lemma}
\begin{proof}
We prove this by mutual induction on the parallel reduction relations on
$v_1$ and $c_1$.
\begin{description}
\item[Variables]
  If the variable is $x$ then this case follows directly from $v_2 \parastepstov v_4$,
  otherwise it follows directly from $v_1 \parastepstov v_3$.
\item[Other congruence rules] For congruence rules other than the
  variable rule we apply the same congruence rule and use the inductive
  hypothesis for any subcomponents.
\item[Reduction rules] For reduction rules we apply the same reduction
  rule, commute any substitutions produced by the reduction with the
  substitution of $x$, and then use the inductive hypothesis for any
  subcomponents.
\end{description}
\end{proof}

\subsection{The diamond property}

We can now show confluence of $\parareducestoname$ by proving the
stronger property that $\parastepstoname$ satisfies the diamond
property:
\begin{lemma}
\label{lemma:parallel-reduction-diamond}
\begin{align*}
  &v_a \parastepstov v_b
    \quad \wedge \quad v_a \parastepstov v_c
    \quad \implies \quad \exists\, v_d. \quad v_b \parastepstov v_d
    \quad \wedge \quad v_c \parastepstov v_d \\
  &c_a \parastepstoc c_b
    \quad \wedge \quad c_a \parastepstoc c_c
    \quad \implies \quad \exists\, c_d. \quad c_b \parastepstoc c_d
    \quad \wedge \quad c_c \parastepstoc c_d
\end{align*}
\end{lemma}
\begin{proof}
  We prove this by mutual induction on the parallel reductions to $v_b$
  and $c_b$, followed by inversion of the parallel reductions to $v_c$
  and $c_c$. As all congruence rules operate on different constructs,
  and no two reduction rules can apply to the same term, there are only
  two cases we must consider:
\begin{description}
\item[The same rule] If both reductions are the same rule then the
  induction hypotheses give us a value and associated parallel
  reductions for each subcomponent. We use these values to build
  $v_d$/$c_d$ and apply the rule to build the required parallel
  reductions.
\item[A reduction rule and a congruence rule] Cases where
  one reduction is a reduction rule and the other is a congruence rule
  all follow the same reasoning. We illustrate this reasoning by
  describing the case for the $\letvname/\returnname$ reduction rule.

  We have $c_a = \letv{x_l}{\return{v_{ar}}}{c_{as}}$,
  $c_b = \sbst{c_{bs}}{x_l}{v_{br}}$ and
  $c_c = \letv{x_l}{c_{cl}}{c_{cs}}$, and the rules in
  question are:
  \begin{mathpar}
    \inferrule{v_{ar} \parastepstov v_{br} \\ c_{as} \parastepstoc c_{bs}}
    {\letv{x_l}{\return{v_{ar}}}{c_{as}} \parastepstoc \sbst{c_{bs}}{x_l}{v_{br}}}
    \and
    \inferrule{\return{v_{ar}} \parastepstoc c_{cl} \\ c_{as} \parastepstoc c_{cs}}
    {\letv{x_l}{\return{v_{ar}}}{c_{as}} \parastepstoc \letv{x_l}{c_{cl}}{c_{cs}}}
  \end{mathpar}
  All our reduction rules have a single subcomponent that is not a
  metavariable -- in this case it is $\return{v_{ar}}$ -- and there are no
  reduction rules which could apply to that subcomponent. That means
  we know by inversion that $\return{v_{ar}} \parastepstoc c_{cl}$ must be the congruence rule on $\returnname$,
  which gives us $c_{cl} = \return{v_{cr}}$, and the combined congruence rules amount to:
  \begin{mathpar}
    \inferrule{v_{ar} \parastepstov v_{cr} \\ c_{as} \parastepstoc c_{cs}}
    {\letv{x_l}{\return{v_{ar}}}{c_{as}} \parastepstoc \letv{x_l}{\return{v_{cr}}}{c_{cs}}}
  \end{mathpar}
  For some of the cases, e.g. the $\reifyname$/$\returnname$ rule, the
  subcomponent itself has a nested subcomponent that is not a
  metavariable and this inversion step must be repeated a second time.

  By the inductive hypothesis, we know that:
  \begin{align*}
  \exists\, v_{dr}. \,v_{br} \parastepstov v_{dr} \, \wedge \, v_{cr} \parastepstov v_{dr} \\
  \exists\, c_{ds}. \,c_{bs} \parastepstoc c_{ds} \, \wedge \, c_{cs} \parastepstoc c_{ds}
  \end{align*}
  We take $c_d$ to be $\sbst{c_{ds}}{x_l}{v_{dr}}$. We have
  $\sbst{c_{bs}}{x_l}{v_{br}} \parastepstoc \sbst{c_{ds}}{x_l}{v_{dr}}$
  using \ref{lemma:subst-of-parallel-reduction}, and we have
  $\letv{x_l}{\return{v_{cr}}}{c_{cs}} \parastepstoc \sbst{c_{ds}}{x_l}{v_{dr}}$
  by applying the reduction rule. In some cases there is no
  substitution and so the lemma is not needed, and in some other cases
  the result of the reduction is not a metavariable and so we must
  first apply the relevant congruence rule.
\end{description}
\end{proof}

\section{Strong normalization}
\label{apdx:strong-normalization}

\begin{align*}
    &\Gamma \turnv v \types \tau
      \quad \implies \quad v \in \snv \\
    &\Gamma \turnc c \types \tau
      \quad \implies \quad c \in \snc
\end{align*}

We prove strong normalization in the standard way for a simply typed
calculus via logical relations. In addition to being indexed by types
these relations will be parameterized by an \emph{effect context},
which records the locations on which a term may perform operations.

Rather than recording the syntactic signature of each location, an
effect context records a \emph{semantic signature}: a function $S$
from a finite set of operation names to pairs $(P, A)$ of sets of
values, where each $P$ is a set of strongly normalizing values that is
closed under reduction, each $A$ is a non-empty set of values, and
both $P$ and $A$ are closed under permutations of locations. We write
$op \types P \rightarrowtail A \in S$ when $op$ is in the domain of $S$
and $S(op) = (P, A)$. The set $P$ plays the role of the parameter type
of the operation and $A$ plays the role of its arity: $P$ contains the
values that may be passed to the operation and $A$ contains the values
that may be passed to its continuation. Closure under permutations
ensures that these sets do not depend on the names of particular
locations, which is what allows us to treat the locations bound by
reification as fresh with respect to the effect context, in the same
way that we treat bound variables as fresh. Operation names are closed
under the tags $\mathrm{left}$ and $\mathrm{right}$, and the sum
$S_1 + S_2$ of two semantic signatures is the semantic signature with
$(S_1 + S_2)(\mathrm{left}(op)) = S_1(op)$ for $op$ in the domain of
$S_1$ and $(S_1 + S_2)(\mathrm{right}(op)) = S_2(op)$ for $op$ in the
domain of $S_2$.
\begin{equation*}
  \mathrm{effect\ contexts}, \Delta ::=\; \cempty \mid \lbind{\Delta}{\loc}{S}
\end{equation*}
We write $\Delta \subseteq \Delta^{\prime}$ when every binding of
$\Delta$ is also a binding of $\Delta^{\prime}$.

Reducibility at function types will quantify over all extensions of
the effect context, in the style of a Kripke logical relation, so that
a reducible function remains reducible when new locations are
introduced by reification. Using semantic rather than syntactic
signatures keeps this definition well-founded: the parameter and arity
types of the operations available in the extended contexts are not
mentioned by the definition, only the sets of values that interpret
them. This is the same device as the reducibility candidates used to
handle the polymorphism of System F~\cite{girard1989proofs}.

As in Girard~\cite{girard1989proofs}, we will use the fact that strongly normalizable
terms must have a bound on the length of their possible reduction
sequences.
\begin{lemma}
\label{lemma:sn-bound}
For any strongly normalizable value $v$ (or computation $c$) there is a
number $\bound{v}$ (or $\bound{c}$) which bounds the length of every
normalization sequence beginning with $v$ (or $c$).
\end{lemma}
\begin{proof}
We can represent the possible normalization sequences as a tree, where the nodes
are reducts. Since there are a finite number of subterms of any value this tree
must be finitely branching. As the term is strongly normalizing it cannot contain
any infinite branches. Thus, by K\H{o}nig's lemma, the whole tree is finite and
there must be a $\bound{v}$ that bounds its height.
\end{proof}

We define three mutually defined families of logical relations.
$\redva{\Delta}{\tau}{\alpha}$ on values and
$\redca{\Delta}{\tau}{\alpha}$ on computations are indexed by an
effect context, a type and an ordinal, whilst
$\redya{\Delta}{S}{\alpha}$ on values is indexed by an effect context,
a semantic signature and an ordinal. The definitions are given in
Fig.~\ref{fig:reducibility-predicates}.

The ordinal $\alpha$ controls the rank of the well-founded trees
corresponding to inductive types and computations. It appears in these
definitions only positively so the predicates are monotonic in
$\alpha$. We write $\redv{\Delta}{\tau}$ for
$\mathrm{lim}_{\alpha} \redva{\Delta}{\tau}{\alpha}$, and similarly
$\redc{\Delta}{\tau}$ and $\redy{\Delta}{S}$. These limits are
well-defined because the predicates are monotonic in $\alpha$: they are
increasing unions of subsets of the set of terms, so no bound on the
range of $\alpha$ is required. Monotonicity also means that any
\emph{set} of reducible terms is contained in
$\redva{\Delta}{\tau}{\alpha}$ for some $\alpha$, by taking $\alpha$ to
be the supremum of the ordinals for its elements.

The definition make use of the interpretation $\redsig{\Sigma}$ of a
syntactic signature as a semantic signature, which interprets the
parameter and arity types of each operation using the reducibility
predicates in the empty effect context. Its domain is the set of
operations of $\Sigma$, and for each
$op \types \tau_p \rightarrowtail \tau_a \in \Sigma$:
\begin{equation*}
  \redsig{\Sigma}(op) = (\redv{\cempty}{\tau_p}, \redv{\cempty}{\glob \tau_a})
\end{equation*}
The arities are interpreted at global types because the continuation
of an operation receives a global value. Since the operations of a
sum $\Sigma_1 + \Sigma_2$ of syntactic signatures are the tagged
operations of $\Sigma_1$ and $\Sigma_2$, we have
$\redsig{\Sigma_1 + \Sigma_2} = \redsig{\Sigma_1} + \redsig{\Sigma_2}$.

These definitions are well-founded. The predicates
$\redya{\Delta}{S}{\alpha}$ are defined for all effect contexts and
semantic signatures simultaneously by transfinite induction on
$\alpha$, as they only refer to themselves at smaller ordinals. The
predicates $\redva{\Delta}{\tau}{\alpha}$ and
$\redca{\Delta}{\tau}{\alpha}$ are defined for all effect contexts
simultaneously by induction on the structure of $\tau$, and for a
fixed $\tau$ by transfinite induction on $\alpha$, with
$\redca{\Delta}{\tau}{\alpha}$ defined after
$\redva{\Delta}{\tau}{\alpha}$. Apart from
$\redya{\Delta}{S}{\alpha}$, the only predicates mentioned by the
cases for $\tau$ are those at types that are strictly smaller than
$\tau$ -- including the parameter and arity types of the operations of
$\Sigma$ in the cases for $\yoneda{\Sigma}$ and $\ind{\Sigma}(\tau_1)$
-- and those at $\tau$ itself at ordinals no larger than $\alpha$. In
particular, the semantic signatures bound in the effect context
contribute only sets of values to the definition, so quantifying over
all extensions $\Delta^{\prime} \supseteq \Delta$ in the case for
function types does not introduce any circularity.

Note that reducibility at global types does not depend on either the
effect context or the ordinal: $\redva{\Delta}{\glob \tau}{\alpha} =
\redv{\cempty}{\glob \tau}$. In particular, the arity sets of
$\redsig{\Sigma}$ are $\redv{\Delta}{\glob \tau_a}$ for any $\Delta$.

\subsection{Properties of reducibility}

We prove the three properties of reducibility referred to as CR1, CR2 and
CR3 in Girard~\cite{girard1989proofs}, by a simultaneous induction on
the structure of types.

Reducible values and computations are strongly normalizing (CR1):
\begin{lemma}
\label{lemma:red-implies-sn}
\begin{align*}
  &\redv{\Delta}{\tau} \subseteq \snv \\
  &\redc{\Delta}{\tau} \subseteq \snc \\
  &\redy{\Delta}{S} \subseteq \snv
\end{align*}
\end{lemma}
\begin{proof}
We prove this by induction on $\tau$. Most of the cases follow directly
by the definitions of $\redvname$, $\redcname$ and $\redyname$. The exceptions are
pair and function types.
\begin{description}
\item[$\tau_1 \times \tau_2$:] We have $\fst{v} \in \snv$ and
  $\snd{v} \in \snv$ and must show that $v \in \snv$. This holds because
  if there was an infinite chain of reductions for $v$ then there would
  be an infinite chain of reductions for $\fst{v}$ by congruence.
\item[$\tau_1 \arr \tau_2$:] Taking $\Delta^{\prime} = \Delta$ and $v_2$
  to be a variable, which is in $\redv{\Delta}{\tau_1}$ by CR3 at
  $\tau_1$, we have $\app{v_1}{v_2} \in \snc$ and must show that
  $v_1 \in \snv$. This holds because if there was an infinite chain of
  reductions for $v_1$ then there would be an infinite chain of
  reductions for $\app{v_1}{v_2}$ by congruence.
\end{description}
\end{proof}

Reducibility predicates are compatible with reductions (CR2):
\begin{lemma}
\label{lemma:red-reduces}
\begin{align*}
  &v_1 \in \redva{\Delta}{\tau}{\alpha} \; \wedge \; v_1 \reducestov v_2 \;
    \implies \; v_2 \in \redva{\Delta}{\tau}{\alpha} \\
  &c_1 \in \redca{\Delta}{\tau}{\alpha} \; \wedge \; c_1 \reducestoc c_2 \;
    \implies \; c_2 \in \redca{\Delta}{\tau}{\alpha} \\
  &v_1 \in \redya{\Delta}{S}{\alpha} \; \wedge \; v_1 \reducestov v_2 \;
    \implies \; v_2 \in \redya{\Delta}{S}{\alpha}
\end{align*}
\end{lemma}
\begin{proof}
  We prove this by induction on $\tau$. The reasoning for computations
  is the same for all types so we treat it as a separate case, and
  the reasoning for $\redyname$ does not depend on the type.
\begin{description}
\item[$1$:] If $v_1 \in \snv$ then $v_2 \in \snv$ because an infinite
  chain in $v_2$ would produce an infinite chain in $v_1$.
\item[$\tau_1 \times \tau_2$:] By congruence we have
  $\fst{v_1} \reducestov \fst{v_2}$ and
  $\snd{v_1} \reducestov \snd{v_2}$, so
  $\fst{v_2} \in \redv{\Delta}{\tau_1}$ and
  $\snd{v_2} \in \redv{\Delta}{\tau_2}$ follow by the induction
  hypothesis.
\item[$\tau_1 + \tau_2$:] Given $v_2 \reducestov \inl{v_3}$ we have
  $v_1 \reducestov \inl{v_3}$ and thus $v_3 \in
  \redv{\Delta}{\tau_1}$. Similarly, given $v_2 \reducestov \inr{v_4}$
  we have $v_4 \in \redv{\Delta}{\tau_2}$.
\item[$\tau_1 \arr \tau_2$:] Given $\Delta^{\prime} \supseteq \Delta$
  and $v_3 \in \redv{\Delta^{\prime}}{\tau_1}$, we have that
  $\app{v_1}{v_3}$ reduces to $\app{v_2}{v_3}$ by congruence, so
  $\app{v_2}{v_3} \in \redc{\Delta^{\prime}}{\tau_2}$ by the induction
  hypothesis.
\item[$\glob \tau$:] Given $v_2 \reducestov \gbox{v_3}$ we have
  $v_1 \reducestov \gbox{v_3}$ and thus $v_3 \in \redv{\cempty}{\tau}$.
\item[$\yoneda{\Sigma}$:] Follows from the case for $\redyname$.
\item[$\ind{\Sigma}(\tau)$:] Given $v_2 \reducestov \ret{v_3}$
  or $v_2 \reducestov \indintro{op}{v_4}{v_5}$ then $v_1$ also reduces to those
  values and thus they have the required properties.
\item[$\redyname$:] Given $v_2 \reducestov \loc$,
  $v_2 \reducestov \outl{v_3}$ or $v_2 \reducestov \outr{v_3}$ then
  $v_1$ also reduces to those values and thus they have the required
  properties.
\item[$\redcname$:] Given $c_2 \reducestoc \return{v_3}$,
  $c_2 \reducestoc \perform{\loc}{op}{v_4}$ or
  $c_2 \reducestoc \letv{x}{\perform{\loc}{op}{v_5}}{c_3}$ then $c_1$
  also reduces to those computations and thus they have the required
  properties.
\end{description}
\end{proof}

A term is neutral if it is not an introduction form. We consider
$\return{v}$, $\perform{\loc}{op}{v}$ and
$\letv{x}{\perform{\loc}{op}{v}}{c}$ to be the introduction forms for
computations. If a term is neutral, and whenever we reduce it we obtain a
term that is reducible, then the original term is reducible (CR3).
\begin{lemma}
\label{lemma:red-neutral}
For all neutral values $v_n$ and neutral computations $c_n$:
\begin{align*}
  &(\forall v_r. \; v_n \stepstov v_r \implies v_r \in \redva{\Delta}{\tau}{\alpha}) \implies v_n \in \redva{\Delta}{\tau}{\alpha} \\
  &(\forall c_r. \; c_n \stepstoc c_r \implies c_r \in \redca{\Delta}{\tau}{\alpha}) \implies c_n \in \redca{\Delta}{\tau}{\alpha} \\
  &(\forall v_r. \; v_n \stepstov v_r \implies v_r \in \redya{\Delta}{S}{\alpha}) \implies v_n \in \redya{\Delta}{S}{\alpha}
\end{align*}
\end{lemma}
\begin{proof}
  We prove this by induction on $\tau$. The reasoning for computations
  is the same for all types so we treat it as a separate case, and
  the reasoning for $\redyname$ does not depend on the type.
\begin{description}
\item[$1$:] Any chain from $v_n$ must pass through one of the $v_r$ and
  so must be finite.
\item[$\tau_1 \times \tau_2$:] As $v_n$ is neutral, the only reduction
  rule that applies to $\fst{v_n}$ is congruence, so any reduction must
  be of the form $\fst{v_n} \stepstov \fst{v_r}$. We have
  $v_r \in \redva{\Delta}{\tau_1 \times \tau_2}{\alpha}$ and thus
  $\fst{v_r} \in \redv{\Delta}{\tau_1}$, so by the induction hypothesis
  we have $\fst{v_n} \in \redv{\Delta}{\tau_1}$. Similarly, we have
  $\snd{v_n} \in \redv{\Delta}{\tau_2}$.
\item[$\tau_1 + \tau_2$:] Any reduction $v_n \reducestov \inl{v_i}$ must
  go through one of the $v_r$ because $v_n$ cannot equal $\inl{v_i}$ as
  it is neutral. From $v_r \reducestov \inl{v_i}$ we have
  $v_i \in \redv{\Delta}{\tau_1}$. Similarly we have that if
  $v_n \reducestov \inr{v_i}$ then $v_i \in \redv{\Delta}{\tau_2}$.
\item[$\tau_1 \arr \tau_2$:] For any $\Delta^{\prime} \supseteq \Delta$
  and $v_a \in \redv{\Delta^{\prime}}{\tau_1}$, we have by
  CR1(\ref{lemma:red-implies-sn}) that $v_a \in \snv$.
  We prove that $\app{v_n}{v_a} \in \redc{\Delta^{\prime}}{\tau_2}$ by
  induction on $\bound{v_a}$.
  By the outer induction hypothesis it is sufficient to show that any reduct
  of $\app{v_n}{v_a}$ is itself in $\redc{\Delta^{\prime}}{\tau_2}$.
  As $v_n$ is neutral the only reduction rules that apply to $\app{v_n}{v_a}$ are the
  congruences, so any reduction must be one of:
  \begin{itemize}
    \item $\app{v_n}{v_a} \stepstoc \app{v_r}{v_a}$
    \item $\app{v_n}{v_a} \stepstoc \app{v_n}{v_b}$ where $v_a \stepstov v_b$
  \end{itemize}
  In the first case, we have
  $v_r \in \redva{\Delta}{\tau_1 \arr \tau_2}{\alpha}$ and thus
  $\app{v_r}{v_a} \in \redc{\Delta^{\prime}}{\tau_2}$. In the second case, we
  have $v_b \in \redv{\Delta^{\prime}}{\tau_1}$ by CR2(\ref{lemma:red-reduces}),
  and $\bound{v_b} < \bound{v_a}$, so we have
  $\app{v_n}{v_b} \in \redc{\Delta^{\prime}}{\tau_2}$ by the inner induction
  hypothesis.
\item[$\glob \tau$:] Any reduction $v_n \reducestov \gbox{v_b}$ must
  go through one of the $v_r$ because $v_n$ cannot equal $\gbox{v_b}$ as
  it is neutral. From $v_r \reducestov \gbox{v_b}$ we have
  $v_b \in \redv{\cempty}{\tau}$.
\item[$\yoneda{\Sigma}$:] Follows from the case for $\redyname$.
\item[$\ind{\Sigma}(\tau)$:] Any reduction $v_n \reducestov \ret{v_t}$
  or $v_n \reducestov \indintro{op}{v_p}{v_a}$ must go through one of
  the $v_r$ because $v_n$ cannot equal $\ret{v_t}$ or
  $\indintro{op}{v_p}{v_a}$ as it is neutral. Since they reduce from
  $v_r$ and $v_r \in \redva{\Delta}{\ind{\Sigma}(\tau)}{\alpha}$ they
  must have the required properties.
\item[$\redyname$:] Any reduction $v_n \reducestov \loc$,
  $v_n \reducestov \outl{v_i}$ or $v_n \reducestov \outr{v_i}$ must go
  through one of the $v_r$ because $v_n$ cannot equal $\loc$,
  $\outl{v_i}$ or $\outr{v_i}$ as it is neutral. Since they reduce from
  $v_r$ and $v_r \in \redya{\Delta}{S}{\alpha}$ they must
  have the required properties.
\item[$\redcname$:] Any reduction of $c_n$ to $\return{v_t}$, to
  $\perform{\loc}{op}{v_p}$, or to
  $\letv{x}{\perform{\loc}{op}{v_p}}{c_k}$ must go through one of the
  $c_r$, because $c_n$ is neutral and so cannot equal any of these
  forms. Since they reduce from $c_r$ and
  $c_r \in \redca{\Delta}{\tau}{\alpha}$ they must have the required
  properties.
\end{description}
\end{proof}

As a corollary, we get that any neutral normal form is reducible. In
particular, the variable term $x$ is reducible at every type, in every
effect context and at every ordinal, so none of the reducibility
predicates is empty.

The reducibility predicates are invariant under renaming locations:
applying a permutation of locations to a term and to the locations
bound by the effect context preserves membership of each of the
predicates. This is immediate from the definitions, since reduction
and the predicates only ever compare locations for equality, and the
sets in semantic signatures are closed under permutations of
locations. In particular, the predicates in the empty effect context
are closed under permutations of locations. Together with the
identification of terms up to renaming of bound locations, this
allows us to assume that the location bound by a reification does not
occur in any particular value under consideration.

The interpretation of a syntactic signature is a semantic signature:
\begin{lemma}
\label{lemma:red-sig}
For any syntactic signature $\Sigma$, $\redsig{\Sigma}$ is a semantic
signature. Moreover, its arity sets are also strongly normalizing and
closed under reduction.
\end{lemma}
\begin{proof}
  The parameter set $\redv{\cempty}{\tau_p}$ and the arity set
  $\redv{\cempty}{\glob \tau_a}$ of each operation consist of strongly
  normalizing values by CR1(\ref{lemma:red-implies-sn}) and are closed
  under reduction by CR2(\ref{lemma:red-reduces}). The arity set
  contains the variables by CR3(\ref{lemma:red-neutral}) and so is
  non-empty. Both sets are closed under permutations of locations by
  the invariance of reducibility under renaming.
\end{proof}
Note that the requirement that arity sets be non-empty does not
prevent arity types from being empty, were the calculus extended
with an empty type: the reducibility predicate at any type contains
the variables, so the arity set of an operation with an empty arity
type would still be non-empty.

\subsection{Effect weakening}

Reducibility can have its effect context extended:
\begin{lemma}
\label{lemma:red-weaken}
If $\Delta \subseteq \Delta^{\prime}$ then:
\begin{align*}
  &\redva{\Delta}{\tau}{\alpha} \subseteq \redva{\Delta^{\prime}}{\tau}{\alpha} \\
  &\redca{\Delta}{\tau}{\alpha} \subseteq \redca{\Delta^{\prime}}{\tau}{\alpha} \\
  &\redya{\Delta}{S}{\alpha} \subseteq \redya{\Delta^{\prime}}{S}{\alpha}
\end{align*}
\end{lemma}
\begin{proof}
  The case for $\redyname$ is by induction on $\alpha$: the condition
  on reducts of the form $\loc$ holds because $\loc \types S \in \Delta$
  implies $\loc \types S \in \Delta^{\prime}$, and the conditions on
  reducts of the forms $\outl{v}$ and $\outr{v}$ hold by the inductive
  hypothesis. The other cases are by induction on $\tau$ and then on
  $\alpha$. Most of the value cases follow immediately by the
  inductive hypotheses as they do not mention $\Delta$ otherwise. For
  function types, given
  $v_1 \in \redva{\Delta}{\tau_1 \arr \tau_2}{\alpha}$ and
  $\Delta^{\prime\prime} \supseteq \Delta^{\prime}$, we have
  $\Delta^{\prime\prime} \supseteq \Delta$ and so
  $\app{v_1}{v_2} \in \redc{\Delta^{\prime\prime}}{\tau_2}$ for any
  $v_2 \in \redv{\Delta^{\prime\prime}}{\tau_1}$ directly from the
  definition. For computations, the condition on reducts of the form
  $\return{v}$ and the condition
  $A \subseteq \redva{\Delta}{\tau}{\alpha}$ follow from the case for
  values at $\tau$, and the remaining conditions on reducts of the
  forms $\perform{\loc}{op}{v}$ and
  $\letv{x}{\perform{\loc}{op}{v}}{c}$ follow from the fact that
  $\loc \types S \in \Delta$ implies
  $\loc \types S \in \Delta^{\prime}$, using the inductive hypothesis
  on $\alpha$ for the condition on continuations.
\end{proof}

\subsection{Products}

Pair terms are reducible when built from reducible subterms.
\begin{lemma}
\label{lemma:red-pair}
\begin{align*}
  v_1 \in \redv{\Delta}{\tau_1} \; \wedge \; v_2 \in \redv{\Delta}{\tau_2}
  \; \implies \; (v_1, v_2) \in \redv{\Delta}{\tau_1 \times \tau_2}
\end{align*}
\end{lemma}
\begin{proof}
  By induction on $\bound{v_1} + \bound{v_2}$.  $\fst{(v_1, v_2)}$ is
  neutral so we can use CR3(\ref{lemma:red-neutral}). There are three
  possibilities for a reduct of $\fst{(v_1, v_2)}$.
  \begin{itemize}
  \item It can reduce by the $\fstname$ reduction rule to $v_1$.
  \item It can reduce by congruence to $\fst{(v_3, v_2)}$ where $v_1 \stepstov v_3$.
  \item It can reduce by congruence to $\fst{(v_1, v_4)}$ where $v_2 \stepstov v_4$.
  \end{itemize}
  The first case is reducible by hypothesis. The second and third cases
  hold by the inductive hypothesis using
  CR2(\ref{lemma:red-reduces}). The same reasoning applies to
  $\snd{(v_1, v_2)}$.
\end{proof}

Projection terms are reducible when built from reducible subterms.
\begin{lemma}
\label{lemma:red-proj}
\begin{align*}
  &v \in \redv{\Delta}{\tau_1 \times \tau_2} \; \implies \; \fst{v} \in \redv{\Delta}{\tau_1} \\
  &v \in \redv{\Delta}{\tau_1 \times \tau_2} \; \implies \; \snd{v} \in \redv{\Delta}{\tau_2}
\end{align*}
\end{lemma}
\begin{proof}
  Follows directly from the definition of $\redv{\Delta}{\tau_1 \times \tau_2}$.
\end{proof}

\subsection{Functions}

Applying an abstraction to an argument is reducible when the
corresponding substitution instance of its body is reducible.
\begin{lemma}
\label{lemma:red-beta}
For any set $V$ of strongly normalizing values that is closed under
reduction:
\begin{align*}
  (\forall v_a \in V. \; \sbst{c_b}{x}{v_a} \in \redc{\Delta}{\tau})
  \; \implies \;
  \forall v_a \in V. \; \app{(\abs{x}{c_b})}{v_a} \in \redc{\Delta}{\tau}
\end{align*}
\end{lemma}
\begin{proof}
  If $V$ is empty there is nothing to show. Otherwise $c_b$ is
  strongly normalizing, since $\sbst{c_b}{x}{v_a}$ is strongly
  normalizing for any $v_a \in V$ and any infinite chain of reductions
  from $c_b$ would give one from $\sbst{c_b}{x}{v_a}$. Fix
  $v_a \in V$. We proceed by induction on
  $\bound{c_b} + \bound{v_a}$. As $\app{(\abs{x}{c_b})}{v_a}$ is neutral,
  we can use CR3(\ref{lemma:red-neutral}). There are three possibilities for a
  reduct of $\app{(\abs{x}{c_b})}{v_a}$.
  \begin{itemize}
  \item It can reduce by beta reduction to $\sbst{c_b}{x}{v_a}$.
  \item It can reduce by congruence to $\app{(\abs{x}{c_d})}{v_a}$ where $c_b \stepstoc c_d$.
  \item It can reduce by congruence to $\app{(\abs{x}{c_b})}{v_e}$ where $v_a \stepstov v_e$.
  \end{itemize}
  The first case is reducible by hypothesis. The second and third cases
  are reducible by the inductive hypothesis: in the second case each
  $\sbst{c_d}{x}{v_a}$ is a reduct of $\sbst{c_b}{x}{v_a}$ and so is
  reducible by CR2(\ref{lemma:red-reduces}), and in the third case
  $v_e \in V$ as $V$ is closed under reduction.
\end{proof}

Abstraction terms are reducible when built from a reducible subterm.
Since reducibility at function types quantifies over extensions of
the effect context, so does the hypothesis of this lemma.
\begin{lemma}
\label{lemma:red-abs}
\begin{align*}
  &(\forall \Delta^{\prime} \supseteq \Delta. \;
    \forall v_a \in \redv{\Delta^{\prime}}{\tau_1}. \;
    \sbst{c_b}{x}{v_a} \in \redc{\Delta^{\prime}}{\tau_2}) \\
  &\implies \; \abs{x}{c_b} \in \redv{\Delta}{\tau_1 \arr \tau_2}
\end{align*}
\end{lemma}
\begin{proof}
  We need to show that
  $\app{(\abs{x}{c_b})}{v_a} \in \redc{\Delta^{\prime}}{\tau_2}$ for any
  $\Delta^{\prime} \supseteq \Delta$ and
  $v_a \in \redv{\Delta^{\prime}}{\tau_1}$. For each such
  $\Delta^{\prime}$ this is Lemma~\ref{lemma:red-beta} with
  $V = \redv{\Delta^{\prime}}{\tau_1}$, which is strongly normalizing
  by CR1(\ref{lemma:red-implies-sn}) and closed under reduction by
  CR2(\ref{lemma:red-reduces}).
\end{proof}

Application terms are reducible when built from reducible subterms.
\begin{lemma}
\label{lemma:red-app}
\begin{align*}
  v_1 \in \redv{\Delta}{\tau_1 \arr \tau_2} \; \wedge \; v_2 \in \redv{\Delta}{\tau_1}
  \; \implies \; \app{v_1}{v_2} \in \redc{\Delta}{\tau_2}
\end{align*}
\end{lemma}
\begin{proof}
  Follows directly from the definition of
  $\redv{\Delta}{\tau_1 \arr \tau_2}$, taking $\Delta^{\prime} = \Delta$.
\end{proof}

\subsection{Sums}

Injection terms are reducible when built from reducible subterms.
\begin{lemma}
\label{lemma:red-inj}
\begin{align*}
  &v_i \in \redv{\Delta}{\tau_1} \; \implies \; \inl{v_i} \in \redv{\Delta}{\tau_1 + \tau_2} \\
  &v_i \in \redv{\Delta}{\tau_2} \; \implies \; \inr{v_i} \in \redv{\Delta}{\tau_1 + \tau_2}
\end{align*}
\end{lemma}
\begin{proof}
  By induction on $\bound{v_i}$. For left injection, we must show two
  things:
  \begin{itemize}
  \item We must show that $\inl{v_i} \in \snv$. The only reduction rule that can apply
    to $\inl{v_i}$ is the congruence rule. Thus any reduct would be of
    the form $\inl{v_j}$ with $v_i \stepstov v_j$ and so, by the
    inductive hypothesis via CR2(\ref{lemma:red-reduces}), would be
    strongly normalizing. Since every reduct is strongly normalizing then
    so is $\inl{v_i}$.
  \item We must show that $v_j \in \redv{\Delta}{\tau_1}$ for any $v_j$ such that $\inl{v_i} \reducestov \inl{v_j}$.
    The reduction is either from reflexivity or by stepping to some intermediate term. If
    it is by reflexivity then $v_j$ is reducible by hypothesis. Only the
    congruence reduction rule applies to $\inl{v_i}$, so the intermediate
    term must be of the form $\inl{v_k}$, which means we can use the
    inductive hypothesis on $v_k$ via CR2(\ref{lemma:red-reduces}) to show
    that $v_j$ is reducible.
  \end{itemize}

  The case for right injection follows by the same reasoning.
\end{proof}

Case terms are reducible when built from reducible subterms.
\begin{lemma}
\label{lemma:red-case}
\begin{align*}
  &v_1 \in \redv{\Delta_1}{\tau_1 + \tau_2} \\
  &\wedge \; (\forall v_4 \in \redv{\Delta_1}{\tau_1}. \; \sbst{v_2}{x_1}{v_4} \in \redv{\Delta_2}{\tau_3}) \\
  &\wedge \; (\forall v_5 \in \redv{\Delta_1}{\tau_2}. \; \sbst{v_3}{x_2}{v_5} \in \redv{\Delta_2}{\tau_3}) \\
  &\implies \; \casem{v_1}{x_1}{v_2}{x_2}{v_3} \in \redv{\Delta_2}{\tau_3}
\end{align*}
\end{lemma}
\begin{proof}
  By induction on $\bound{v_1} + \bound{v_2} + \bound{v_3}$.
  $\casem{v_1}{x_1}{v_2}{x_2}{v_3}$ is neutral so we can use CR3(\ref{lemma:red-neutral}). There are five
  possibilities for a reduct of $\casem{v_1}{x_1}{v_2}{x_2}{v_3}$.
  \begin{itemize}
  \item It can reduce to $\sbst{v_2}{x_1}{v_4}$ if $v_1$ is of the form $\inl{v_4}$.
  \item It can reduce to $\sbst{v_3}{x_2}{v_5}$ if $v_1$ is of the form $\inr{v_5}$.
  \item It can reduce by congruence to $\casem{v_6}{x_1}{v_2}{x_2}{v_3}$ where $v_1 \stepstov v_6$.
  \item It can reduce by congruence to $\casem{v_1}{x_1}{v_7}{x_2}{v_3}$ where $v_2 \stepstov v_7$.
  \item It can reduce by congruence to $\casem{v_1}{x_1}{v_2}{x_2}{v_8}$ where $v_3 \stepstov v_8$.
  \end{itemize}
  In the first case we have $v_4 \in \redv{\Delta_1}{\tau_1}$ from $v_1 \in \redv{\Delta_1}{\tau_1 + \tau_2}$ 
  and so the reduct is reducible by hypothesis. Similarly, in the second case we have $v_5 \in \redv{\Delta_1}{\tau_2}$
  and so the reduct is reducible by hypothesis. The last three cases
  are reducible by the inductive hypothesis using
  CR2(\ref{lemma:red-reduces}).
\end{proof}

\subsection{Unit}

Unit terms are reducible.
\begin{lemma}
\label{lemma:red-unit}
\begin{align*}
  () \in \redv{\Delta}{1}
\end{align*}
\end{lemma}
\begin{proof}
  No reduction rules apply to $()$ so it is strongly normalizable.
\end{proof}

Unboxing terms are reducible when built from reducible subterms.
\begin{lemma}
\label{lemma:red-unbox}
\begin{align*}
  &v_1 \in \redv{\Delta}{\glob \tau_1} \\
  &\wedge \; (\forall v_3 \in \redv{\cempty}{\tau_1}.
    \; \sbst{v_2}{x}{v_3} \in \redv{\Delta}{\tau_2}) \\

\end{align*}
\end{lemma}
\begin{proof}

  \bound{v_2}$. $\gunbox{x}{v_1}{v_2}$ is neutral so we can use

  reduct of $\gunbox{x}{v_1}{v_2}$:
  \begin{itemize}
  \item It can reduce to $\sbst{v_2}{x}{v_3}$ if $v_1$ is of the form $\gbox{v_3}$.
  \item It can reduce by congruence to $\gunbox{x}{v_4}{v_2}$ where $v_1 \stepstov v_4$.
  \item It can reduce by congruence to $\gunbox{x}{v_1}{v_5}$ where $v_2 \stepstov v_5$.
  \end{itemize}
  In the first case we have $v_3 \in \redv{\cempty}{\tau_1}$ from
  $v_1 \in \redv{\Delta}{\glob \tau_1}$ and so the reduct is reducible
  by hypothesis. The second and third cases are reducible by the
  inductive hypothesis using CR2(\ref{lemma:red-reduces}).
\end{proof}

\subsection{Computations}

Return terms are reducible when built from reducible subterms.
\begin{lemma}
\label{lemma:red-return}
\begin{align*}
  &v_r \in \redv{\Delta}{\tau} \\
  &\implies \; \return{v_r} \in \redc{\Delta}{\tau}
\end{align*}
\end{lemma}
\begin{proof}
  By induction on $\bound{v_r}$. We must show three things:
  \begin{itemize}
  \item We must show that $\return{v_r} \in \snc$. The only reduction rule that can apply
    to $\return{v_r}$ is the congruence rule. Thus any reduct would be of
    the form $\return{v_t}$ with $v_r \stepstov v_t$ and so, by the
    inductive hypothesis via CR2(\ref{lemma:red-reduces}), would be
    strongly normalizing. Since every reduct is strongly normalizing then
    so is $\return{v_r}$.
  \item We must show that $v_t \in \redv{\Delta}{\tau}$ for any $v_t$
    such that $\return{v_r} \reducestoc \return{v_t}$. The reduction is
    either from reflexivity or by stepping to some intermediate term. If
    it is by reflexivity then $v_t$ is reducible by hypothesis. Only the
    congruence reduction rule applies to $\return{v_r}$, so the
    intermediate term must be of the form $\return{v_s}$, which means we
    can use the inductive hypothesis on $v_s$ via
    CR2(\ref{lemma:red-reduces}) to show that $v_t$ is reducible.
  \item We must show that various properties hold for any term of the
    form $\perform{\loc}{op}{v_a}$ or
    $\letv{x}{\perform{\loc}{op}{v_a}}{c_k}$ that $\return{v_r}$ reduces
    to. The reduction would have to be by stepping to some intermediate
    term as it can't be via reflexivity. Only the congruence reduction
    rule applies to $\return{v_r}$, so the intermediate term must be of
    the form $\return{v_t}$, which means we can use the inductive
    hypothesis on $v_t$ via CR2(\ref{lemma:red-reduces}) to show that
    the properties would hold.
  \end{itemize}
\end{proof}

Non-neutral perform terms are reducible when built from reducible subterms.
\begin{lemma}
\label{lemma:red-perform-intro}
\begin{align*}
  &\loc_e \types S \in \Delta
   \; \wedge \; op \types P \rightarrowtail A \in S
   \; \wedge \; v_p \in P
   \; \wedge \; A \subseteq \redv{\Delta}{\tau} \\
  &\implies \; \perform{\loc_e}{op}{v_p} \in \redc{\Delta}{\tau}
\end{align*}
\end{lemma}
\begin{proof}
  There is some $\alpha$ with
  $A \subseteq \redva{\Delta}{\tau}{\alpha}$. We show that
  $\perform{\loc_e}{op}{v_p} \in \redca{\Delta}{\tau}{\alpha}$. As
  $P \subseteq \snv$, $v_p$ is strongly normalizing and we can proceed
  by induction on $\bound{v_p}$. We must show three things:
  \begin{itemize}
  \item We must show that $\perform{\loc_e}{op}{v_p} \in \snc$. The only
    reduction rule that can apply to $\perform{\loc_e}{op}{v_p}$ is the
    congruence rule. Thus any reduct would be of the form
    $\perform{\loc_e}{op}{v_q}$ with $v_p \stepstov v_q$. As $P$ is
    closed under reduction $v_q \in P$, so by the inductive
    hypothesis the reduct is reducible and hence strongly
    normalizing. Since every reduct is strongly normalizing then so is
    $\perform{\loc_e}{op}{v_p}$.
  \item We must show that $v_q \in P$ for any $v_q$ such that
    $\perform{\loc_e}{op}{v_p} \reducestoc \perform{\loc_e}{op}{v_q}$,
    since $\loc_e \types S \in \Delta$, $op \types P \rightarrowtail A
    \in S$ and $A \subseteq \redva{\Delta}{\tau}{\alpha}$ hold by
    hypothesis. Only the congruence reduction rule applies to
    $\perform{\loc_e}{op}{v_p}$, so $v_p \reducestov v_q$ and $v_q \in P$
    as $P$ is closed under reduction.
  \item We must show that various properties hold for any term of the
    form $\return{v_r}$, $\perform{\loc_f}{op}{v_q}$ (where
    $\loc_f \neq \loc_e$) or $\letv{x}{\perform{\loc}{op}{v_p}}{c_k}$
    that $\perform{\loc_e}{op}{v_p}$ reduces to. Only the congruence
    reduction rule applies to $\perform{\loc_e}{op}{v_p}$, so every
    reduct is of the form $\perform{\loc_e}{op}{v_q}$ and the
    conditions hold vacuously.
  \end{itemize}
\end{proof}
As a corollary, if $\loc_e \types \redsig{\Sigma} \in \Delta$,
$op \types \tau_p \rightarrowtail \tau_a \in \Sigma$ and
$v_p \in \redv{\cempty}{\tau_p}$ then
$\perform{\loc_e}{op}{v_p} \in \redc{\Delta}{\glob \tau_a}$, since
$\redsig{\Sigma}$ contains
$op \types \redv{\cempty}{\tau_p} \rightarrowtail
\redv{\cempty}{\glob \tau_a}$ and
$\redv{\cempty}{\glob \tau_a} = \redv{\Delta}{\glob \tau_a}$.

Non-neutral bind terms are reducible when built from reducible subterms.
\begin{lemma}
\label{lemma:red-bind-intro}
\begin{align*}
  &\loc_e \types S \in \Delta
   \; \wedge \; op \types P \rightarrowtail A \in S
   \; \wedge \; v_p \in P \\
  &\wedge \; (\forall v_a \in A. \; \sbst{c_k}{x}{v_a} \in \redc{\Delta}{\tau_k}) \\
  &\implies \; \letv{x}{\perform{\loc_e}{op}{v_p}}{c_k} \in \redc{\Delta}{\tau_k}
\end{align*}
\end{lemma}
\begin{proof}
  As $P \subseteq \snv$, $v_p$ is strongly normalizing. As $A$ is
  non-empty, $c_k$ is also strongly normalizing. As
  $\{ \, \sbst{c_k}{x}{v_a} \; | \; v_a \in A \, \}$ is a set of
  reducible computations there is some $\alpha$ with
  $\sbst{c_k}{x}{v_a} \in \redca{\Delta}{\tau_k}{\alpha}$ for all
  $v_a \in A$. We show that
  $\letv{x}{\perform{\loc_e}{op}{v_p}}{c_k} \in
  \redca{\Delta}{\tau_k}{\alpha + 1}$, by induction on
  $\bound{v_p} + \bound{c_k}$. We must show three things:
  \begin{itemize}
  \item We must show that $\letv{x}{\perform{\loc_e}{op}{v_p}}{c_k} \in \snc$. The only
    reduction rule that can apply to $\letv{x}{\perform{\loc_e}{op}{v_p}}{c_k}$ is the
    congruence rule. Thus any reducts would be one of two forms:
    \begin{itemize}
    \item $\letv{x}{\perform{\loc_e}{op}{v_q}}{c_k}$ with $v_p \stepstov v_q$
    \item $\letv{x}{\perform{\loc_e}{op}{v_p}}{c_j}$ with $c_k \stepstoc c_j$
    \end{itemize}
    In the first case $v_q \in P$ as $P$ is closed under reduction. In
    the second case each $\sbst{c_j}{x}{v_a}$ is a reduct of
    $\sbst{c_k}{x}{v_a}$ and so is reducible by
    CR2(\ref{lemma:red-reduces}). In both cases the reduct is
    reducible by the inductive hypothesis and hence strongly
    normalizing. Since every reduct is strongly normalizing then so is
    $\letv{x}{\perform{\loc_e}{op}{v_p}}{c_k}$.
  \item We must show that $v_q \in P$ and
    $\forall v_a \in A. \; \exists \beta < \alpha + 1. \;
    \sbst{c_j}{x}{v_a} \in \redca{\Delta}{\tau_k}{\beta}$ for any $v_q$
    and $c_j$ such that
    $\letv{x}{\perform{\loc_e}{op}{v_p}}{c_k} \reducestoc
    \letv{x}{\perform{\loc_e}{op}{v_q}}{c_j}$, since
    $\loc_e \types S \in \Delta$ and $op \types P \rightarrowtail A \in
    S$ hold by hypothesis. Only the congruence reduction rule applies
    to $\letv{x}{\perform{\loc_e}{op}{v_p}}{c_k}$, so
    $v_p \reducestov v_q$ and $c_k \reducestoc c_j$. Thus $v_q \in P$ as
    $P$ is closed under reduction, and for each $v_a \in A$ the
    computation $\sbst{c_j}{x}{v_a}$ is a reduct of
    $\sbst{c_k}{x}{v_a}$ and so is in $\redca{\Delta}{\tau_k}{\alpha}$
    by CR2(\ref{lemma:red-reduces}), which gives the condition with
    $\beta = \alpha$.
  \item We must show that various properties hold for any term of the
    form $\return{v_r}$, $\perform{\loc_g}{op}{v_p}$ or
    $\letv{x}{\perform{\loc_f}{op}{v_q}}{c_j}$ (where
    $\loc_f \neq \loc_e$) that
    $\letv{x}{\perform{\loc_e}{op}{v_p}}{c_k}$ reduces to. Only the
    congruence reduction rule applies to
    $\letv{x}{\perform{\loc_e}{op}{v_p}}{c_k}$, so every reduct is of
    the form $\letv{x}{\perform{\loc_e}{op}{v_r}}{c_l}$ and the
    conditions hold vacuously.
  \end{itemize}
\end{proof}

Bind terms are reducible when built from reducible subterms.
\begin{lemma}
\label{lemma:red-bind}
\begin{align*}
  &c_1 \in \redca{\Delta}{\tau_1}{\alpha} \\
  &\wedge \; (\forall v \in \redva{\Delta}{\tau_1}{\alpha}. \; \sbst{c_2}{x}{v} \in \redc{\Delta}{\tau_2}) \\
  &\implies \; \letv{x}{c_1}{c_2} \in \redc{\Delta}{\tau_2}
\end{align*}
\end{lemma}
\begin{proof}
  Note that $c_2$ is strongly normalizing, since
  $\redva{\Delta}{\tau_1}{\alpha}$ contains the variables by
  CR3(\ref{lemma:red-neutral}). We proceed by induction on $\alpha$ and
  $\bound{c_1} + \bound{c_2}$.

  We first consider the case where $c_1$ is of the form
  $\perform{\loc_e}{op}{v_p}$. Then
  $c_1 \in \redca{\Delta}{\tau_1}{\alpha}$ gives us, via reflexivity,
  that $\loc_e \types S \in \Delta$,
  $op \types P \rightarrowtail A \in S$, $v_p \in P$ and
  $A \subseteq \redva{\Delta}{\tau_1}{\alpha}$. The hypothesis on $c_2$
  then gives us
  $\forall v_a \in A. \; \sbst{c_2}{x}{v_a} \in \redc{\Delta}{\tau_2}$,
  and the case follows by Lemma~\ref{lemma:red-bind-intro}.

  Otherwise $\letv{x}{c_1}{c_2}$ is neutral, so we can use
  CR3(\ref{lemma:red-neutral}). There are four possibilities for a
  reduct of $\letv{x}{c_1}{c_2}$:
  \begin{itemize}
  \item It can reduce by congruence to $\letv{x}{c_3}{c_2}$ where
    $c_1 \stepstoc c_3$. By CR2(\ref{lemma:red-reduces}) we have
    $c_3 \in \redca{\Delta}{\tau_1}{\alpha}$, so the reduct is reducible
    by the inductive hypothesis.
  \item It can reduce by congruence to $\letv{x}{c_1}{c_4}$ where
    $c_2 \stepstoc c_4$. For any $v \in \redva{\Delta}{\tau_1}{\alpha}$
    we have that $\sbst{c_4}{x}{v}$ is a reduct of $\sbst{c_2}{x}{v}$
    and so is reducible by CR2(\ref{lemma:red-reduces}). Thus the reduct
    is reducible by the inductive hypothesis.
  \item If $c_1$ is of the form $\return{v_1}$ then it can reduce to
    $\sbst{c_2}{x}{v_1}$. From $c_1 \in \redca{\Delta}{\tau_1}{\alpha}$
    we have, via reflexivity, that
    $v_1 \in \redva{\Delta}{\tau_1}{\alpha}$, so the reduct is reducible
    by hypothesis.
  \item If $c_1$ is of the form
    $\letv{y}{\perform{\loc_e}{op}{v_p}}{c_3}$ then it can reduce by the
    commuting rule to
    $\letv{y}{\perform{\loc_e}{op}{v_p}}{(\letv{x}{c_3}{c_2})}$, where
    we may assume that $y$ does not occur free in $c_2$. From
    $c_1 \in \redca{\Delta}{\tau_1}{\alpha}$ we have, via reflexivity,
    that $\loc_e \types S \in \Delta$,
    $op \types P \rightarrowtail A \in S$ and $v_p \in P$, and that
    for any $v_a \in A$ there is some $\beta < \alpha$ with
    $\sbst{c_3}{y}{v_a} \in \redca{\Delta}{\tau_1}{\beta}$. For any
    such $v_a$ we have
    $\sbst{(\letv{x}{c_3}{c_2})}{y}{v_a} =
    \letv{x}{\sbst{c_3}{y}{v_a}}{c_2}$, which is reducible by the
    inductive hypothesis on $\beta$, using the monotonicity of the
    predicates in $\alpha$ for the hypothesis on $c_2$. The reduct is
    then reducible by Lemma~\ref{lemma:red-bind-intro}.
  \end{itemize}
\end{proof}

Run terms are reducible when built from reducible subterms.
\begin{lemma}
\label{lemma:red-run}
\begin{align*}
  &c_r \in \redc{\cempty}{\tau} \\
  &\implies \; \grun{c_r} \in \redv{\Delta}{\tau}
\end{align*}
\end{lemma}
\begin{proof}
  By induction on $\bound{c_r}$. $\grun{c_r}$ is neutral so we can use
  CR3(\ref{lemma:red-neutral}). There are two possibilities for a reduct
  of $\grun{c_r}$:
  \begin{itemize}
  \item It can reduce by congruence to $\grun{c_s}$ where
    $c_r \stepstoc c_s$. By CR2(\ref{lemma:red-reduces}) we have
    $c_s \in \redc{\cempty}{\tau}$, so the reduct is reducible by the
    inductive hypothesis.
  \item If $c_r$ is of the form $\return{v}$ then it can reduce to
    $v$. From $c_r \in \redc{\cempty}{\tau}$ we have, via reflexivity,
    that $v \in \redv{\cempty}{\tau}$, and thus that
    $v \in \redv{\Delta}{\tau}$ by effect weakening
    (\ref{lemma:red-weaken}).
  \end{itemize}
\end{proof}

\subsection{Effect capability types}

Reducibility at an effect capability type is reducibility at the
interpretation of its signature, so we state the lemmas of this section
in terms of semantic signatures.

Location terms are reducible when they are bound in the effect context.
\begin{lemma}
\label{lemma:red-loc}
\begin{align*}
  \loc \types S \in \Delta
  \; \implies \; \loc \in \redy{\Delta}{S}
\end{align*}
\end{lemma}
\begin{proof}
  No reduction rules apply to $\loc$, so it is strongly normalizing and
  its only reduct, via reflexivity, is $\loc$ itself, for which we have
  $\loc \types S \in \Delta$ by hypothesis. The conditions for
  reducts of the forms $\outl{v}$ and $\outr{v}$ hold vacuously.
\end{proof}

Selection terms are reducible when built from reducible subterms.
\begin{lemma}
\label{lemma:red-out}
\begin{align*}
  &v_s \in \redy{\Delta}{S_1 + S_2}
    \; \implies \; \outl{v_s} \in \redy{\Delta}{S_1} \\
  &v_s \in \redy{\Delta}{S_1 + S_2}
    \; \implies \; \outr{v_s} \in \redy{\Delta}{S_2}
\end{align*}
\end{lemma}
\begin{proof}
  By induction on $\bound{v_s}$. For left selection, we must show three
  things:
  \begin{itemize}
  \item We must show that $\outl{v_s} \in \snv$. The only reduction rule
    that can apply to $\outl{v_s}$ is the congruence rule. Thus any
    reduct would be of the form $\outl{v_r}$ with $v_s \stepstov v_r$
    and so, by the inductive hypothesis via
    CR2(\ref{lemma:red-reduces}), would be strongly normalizing. Since
    every reduct is strongly normalizing then so is $\outl{v_s}$.
  \item We must show, for any $v_r$ such that
    $\outl{v_s} \reducestov \outl{v_r}$, that there are some $S$
    and $\beta$ with
    $v_r \in \redya{\Delta}{S_1 + S}{\beta}$. Only
    the congruence reduction rule applies to $\outl{v_s}$, so
    $v_s \reducestov v_r$ and thus
    $v_r \in \redy{\Delta}{S_1 + S_2}$ by
    CR2(\ref{lemma:red-reduces}), giving
    $v_r \in \redya{\Delta}{S_1 + S_2}{\beta}$ for
    some $\beta$.
  \item We must show that various properties hold for any term of the
    form $\loc$ or $\outr{v_r}$ that $\outl{v_s}$ reduces to. Only the
    congruence reduction rule applies to $\outl{v_s}$, so every reduct
    is of the form $\outl{v_r}$ and the conditions hold vacuously.
  \end{itemize}
  The case for right selection follows by the same reasoning.
\end{proof}

Perform terms are reducible when built from reducible subterms.
\begin{lemma}
\label{lemma:red-perform}
\begin{align*}
  &op \types P \rightarrowtail A \in S
  \; \wedge \; v_l \in \redya{\Delta}{S}{\alpha}
  \; \wedge \; v_a \in P
  \; \wedge \; A \subseteq \redv{\Delta}{\tau} \\
  &\implies \; \perform{v_l}{op}{v_a} \in \redc{\Delta}{\tau}
\end{align*}
\end{lemma}
\begin{proof}
  As $P \subseteq \snv$, $v_a$ is strongly normalizing. We proceed by
  induction on $\alpha$ and $\bound{v_l} + \bound{v_a}$.

  We first consider the case where $v_l$ is a location $\loc$. Then
  $v_l \in \redya{\Delta}{S}{\alpha}$ gives us, via
  reflexivity, that $\loc \types S \in \Delta$, and the case
  follows by Lemma~\ref{lemma:red-perform-intro}.

  Otherwise $\perform{v_l}{op}{v_a}$ is neutral, so we can use
  CR3(\ref{lemma:red-neutral}). There are four possibilities for a
  reduct of $\perform{v_l}{op}{v_a}$:
  \begin{itemize}
  \item It can reduce by congruence to $\perform{v_m}{op}{v_a}$ where
    $v_l \stepstov v_m$. By CR2(\ref{lemma:red-reduces}) we have
    $v_m \in \redya{\Delta}{S}{\alpha}$, so the reduct is
    reducible by the inductive hypothesis.
  \item It can reduce by congruence to $\perform{v_l}{op}{v_b}$ where
    $v_a \stepstov v_b$. As $P$ is closed under reduction we have
    $v_b \in P$, so the reduct is reducible by the
    inductive hypothesis.
  \item If $v_l$ is of the form $\outl{v_m}$ then it can reduce to
    $\perform{v_m}{\mathrm{left}(op)}{v_a}$. From
    $v_l \in \redya{\Delta}{S}{\alpha}$ we have, via
    reflexivity, some $S_2$ and $\beta < \alpha$ with
    $v_m \in \redya{\Delta}{S + S_2}{\beta}$. Since
    $\mathrm{left}(op) \types P \rightarrowtail A \in S +
    S_2$, the reduct is reducible by the inductive hypothesis on
    $\beta$.
  \item If $v_l$ is of the form $\outr{v_m}$ then it can reduce to
    $\perform{v_m}{\mathrm{right}(op)}{v_a}$, which is reducible by the
    same reasoning as the previous case.
  \end{itemize}
\end{proof}
As a corollary, $\perform{v_l}{op}{v_a} \in \redc{\Delta}{\glob \tau_a}$
whenever $op \types \tau_p \rightarrowtail \tau_a \in \Sigma$,
$v_l \in \redv{\Delta}{\yoneda{\Sigma}}$ and
$v_a \in \redv{\cempty}{\tau_p}$.

\subsection{Inductive types}

Ret terms are reducible when built from reducible subterms.
\begin{lemma}
\label{lemma:red-ret}
\begin{align*}
  &v_r \in \redv{\cempty}{\tau_1} \\
  &\implies \; \ret{v_r} \in \redv{\Delta}{\ind{\Sigma}(\tau_1)}
\end{align*}
\end{lemma}
\begin{proof}
  By induction on $\bound{v_r}$. We must show three things:
  \begin{itemize}
  \item We must show that $\ret{v_r} \in \snv$. The only reduction rule
    that can apply to $\ret{v_r}$ is the congruence rule. Thus any
    reduct would be of the form $\ret{v_t}$ with $v_r \stepstov v_t$ and
    so, by the inductive hypothesis via CR2(\ref{lemma:red-reduces}),
    would be strongly normalizing. Since every reduct is strongly
    normalizing then so is $\ret{v_r}$.
  \item We must show that $v_t \in \redv{\cempty}{\tau_1}$ for any $v_t$
    such that $\ret{v_r} \reducestov \ret{v_t}$. The reduction is either
    from reflexivity or by stepping to some intermediate term. If it is
    by reflexivity then $v_t$ is reducible by hypothesis. Only the
    congruence reduction rule applies to $\ret{v_r}$, so the
    intermediate term must be of the form $\ret{v_s}$, which means we
    can use the inductive hypothesis on $v_s$ via
    CR2(\ref{lemma:red-reduces}) to show that $v_t$ is reducible.
  \item We must show that various properties hold for any term of the
    form $\indintro{op}{v_3}{v_4}$ that $\ret{v_r}$ reduces to. Only the
    congruence reduction rule applies to $\ret{v_r}$, so every reduct is
    of the form $\ret{v_t}$ and the condition holds vacuously.
  \end{itemize}
\end{proof}

Operation terms are reducible when built from reducible subterms.
\begin{lemma}
\label{lemma:red-indintro}
\begin{align*}
  &op \types P \rightarrowtail A \in \redsig{\Sigma}
   \; \wedge \; v_p \in P \\
  &\wedge \; (\forall v_a \in A. \;
     \app{v_k}{v_a} \in \redc{\Delta}{\ind{\Sigma}(\tau_1)}) \\
  &\implies \; \indintro{op}{v_p}{v_k} \in \redv{\Delta}{\ind{\Sigma}(\tau_1)}
\end{align*}
\end{lemma}
\begin{proof}
  By Lemma~\ref{lemma:red-sig}, $P \subseteq \snv$ and is closed under
  reduction, and $A$ is non-empty. Thus $v_p$ is strongly normalizing,
  and so is $v_k$, since $\app{v_k}{v_a}$ is strongly normalizing for
  any $v_a \in A$ and any infinite chain of reductions from $v_k$ would
  give one from $\app{v_k}{v_a}$. By induction on
  $\bound{v_p} + \bound{v_k}$. We must show three things:
  \begin{itemize}
  \item We must show that $\indintro{op}{v_p}{v_k} \in \snv$. The only
    reduction rule that can apply to $\indintro{op}{v_p}{v_k}$ is the
    congruence rule. Thus any reduct would be of the form
    $\indintro{op}{v_q}{v_k}$ with $v_p \stepstov v_q$ or
    $\indintro{op}{v_p}{v_l}$ with $v_k \stepstov v_l$. In the first
    case $v_q \in P$ as $P$ is closed under reduction, and in the
    second case each $\app{v_l}{v_a}$ is a reduct of $\app{v_k}{v_a}$
    and so is reducible by CR2(\ref{lemma:red-reduces}). In both cases
    the reduct is reducible by the inductive hypothesis and hence
    strongly normalizing. Since every reduct is strongly normalizing
    then so is $\indintro{op}{v_p}{v_k}$.
  \item We must show that various properties hold for any term of the
    form $\ret{v_2}$ that $\indintro{op}{v_p}{v_k}$ reduces to. Only the
    congruence reduction rule applies to $\indintro{op}{v_p}{v_k}$, so
    every reduct is of the form $\indintro{op}{v_q}{v_l}$ and the
    condition holds vacuously.
  \item We must show, for any $v_q$ and $v_l$ such that
    $\indintro{op}{v_p}{v_k} \reducestov \indintro{op}{v_q}{v_l}$, that
    $v_q \in P$ and that for any $v_a \in A$ there is some $\beta$ with
    $\app{v_l}{v_a} \in \redca{\Delta}{\ind{\Sigma}(\tau_1)}{\beta}$.
    Only the congruence reduction rule applies to
    $\indintro{op}{v_p}{v_k}$, so $v_p \reducestov v_q$ and
    $v_k \reducestov v_l$. Thus $v_q \in P$ as $P$ is closed under
    reduction, and $\app{v_l}{v_a}$ is a reduct of $\app{v_k}{v_a}$ and
    so is in $\redc{\Delta}{\ind{\Sigma}(\tau_1)}$ by
    CR2(\ref{lemma:red-reduces}), and hence in
    $\redca{\Delta}{\ind{\Sigma}(\tau_1)}{\beta}$ for some
    $\beta$. Taking $\alpha$ to be a strict upper bound of these
    $\beta$ gives
    $\indintro{op}{v_p}{v_k} \in
    \redva{\Delta}{\ind{\Sigma}(\tau_1)}{\alpha}$.
  \end{itemize}
\end{proof}
As a corollary, if $op \types \tau_p \rightarrowtail \tau_a \in \Sigma$,
$v_p \in \redv{\cempty}{\tau_p}$ and
$v_k \in \redv{\Delta}{\glob \tau_a \arr \ind{\Sigma}(\tau_1)}$ then
$\indintro{op}{v_p}{v_k} \in \redv{\Delta}{\ind{\Sigma}(\tau_1)}$.

Reification terms are reducible when built from reducible subterms.
\begin{lemma}
\label{lemma:red-reify}
\begin{align*}
  &c \in \redca{\lbind{\Delta}{\loc}{\redsig{\Sigma}}}{\glob \tau}{\alpha} \\
  &\implies \; \reify{\loc}{c} \in \redc{\Delta}{\ind{\Sigma}(\tau)}
\end{align*}
\end{lemma}
\begin{proof}
  By induction on $\alpha$, for all $\Delta$ and $\loc$, and then on
  $\bound{c}$. Write $\Delta_{\loc}$ for
  $\lbind{\Delta}{\loc}{\redsig{\Sigma}}$, and note that
  $\Delta \subseteq \Delta_{\loc}$. $\reify{\loc}{c}$ is neutral so we
  can use CR3(\ref{lemma:red-neutral}). There are six possibilities
  for a reduct of $\reify{\loc}{c}$:
  \begin{itemize}
  \item It can reduce by congruence to $\reify{\loc}{c^{\prime}}$ where
    $c \stepstoc c^{\prime}$. By CR2(\ref{lemma:red-reduces}) we have
    $c^{\prime} \in \redca{\Delta_{\loc}}{\glob \tau}{\alpha}$, so the
    reduct is reducible by the inductive hypothesis.
  \item If $c$ is of the form $\return{(\gbox{v})}$ then it can reduce
    to $\return{\ret{v}}$. From the reducibility of $c$ we have, via
    reflexivity, that
    $\gbox{v} \in \redv{\Delta_{\loc}}{\glob \tau}$ and
    thus that $v \in \redv{\cempty}{\tau}$. The reduct is then reducible
    by Lemmas~\ref{lemma:red-ret} and \ref{lemma:red-return}.
  \item If $c$ is of the form $\perform{\loc}{op}{v}$ then it can reduce
    to
    $\return{\indintro{op}{v}{\abs{(\gbox{x})}{\return{\ret{x}}}}}$.
    From the reducibility of $c$ we have, via reflexivity, that
    $op \types P \rightarrowtail A \in \redsig{\Sigma}$, as $\loc$ is
    bound to $\redsig{\Sigma}$ in $\Delta_{\loc}$, that $v \in P$, and
    that $A \subseteq \redva{\Delta_{\loc}}{\glob \tau}{\alpha}
    \subseteq \redv{\Delta}{\glob \tau}$, as reducibility at global
    types does not depend on the effect context. The continuation is in
    $\redv{\Delta}{\glob \tau \arr \ind{\Sigma}(\tau)}$ by
    Lemma~\ref{lemma:red-abs}, since for any
    $\Delta^{\prime} \supseteq \Delta$ and
    $v_b \in \redv{\Delta^{\prime}}{\glob \tau}$ its body with $v_b$
    substituted for $x$ is in $\redc{\Delta^{\prime}}{\ind{\Sigma}(\tau)}$
    by Lemmas~\ref{lemma:red-unbox}, \ref{lemma:red-ret} and
    \ref{lemma:red-return}. Thus for any $v_a \in A$ the continuation
    applied to $v_a$ is in $\redc{\Delta}{\ind{\Sigma}(\tau)}$ by
    Lemma~\ref{lemma:red-app}, and the reduct is reducible by
    Lemmas~\ref{lemma:red-indintro} and \ref{lemma:red-return}.
  \item If $c$ is of the form $\letv{x}{\perform{\loc}{op}{v}}{c_2}$
    then it can reduce to
    $\return{\indintro{op}{v}{\abs{x}{\reify{\loc}{c_2}}}}$. As in the
    previous case, from the reducibility of $c$ we have, via
    reflexivity, that $op \types P \rightarrowtail A \in \redsig{\Sigma}$
    and $v \in P$, and additionally that for any $v_b \in A$ there is
    some $\beta < \alpha$ with $\sbst{c_2}{x}{v_b} \in
    \redca{\Delta_{\loc}}{\glob \tau}{\beta}$. By
    Lemma~\ref{lemma:red-indintro} it is sufficient to show that for
    any $v_b \in A$ the continuation applied to $v_b$ is in
    $\redc{\Delta}{\ind{\Sigma}(\tau)}$, for which, by
    Lemma~\ref{lemma:red-beta} -- $A$ being strongly normalizing and
    closed under reduction by Lemma~\ref{lemma:red-sig} -- it is
    sufficient to show that
    $\reify{\loc}{\sbst{c_2}{x}{v_b}}$, which is in
    $\redc{\Delta}{\ind{\Sigma}(\tau)}$ by the inductive hypothesis on
    $\beta$. The reduct is then reducible by
    Lemmas~\ref{lemma:red-indintro} and \ref{lemma:red-return}.
  \item If $c$ is of the form $\perform{\loc_2}{op}{v}$ with
    $\loc_2 \neq \loc$ then it can reduce to
    \begin{equation*}
      \letv{(\gbox{x})}{\perform{\loc_2}{op}{v}}{\return{\ret{x}}}
    \end{equation*}
    From the reducibility of $c$ we have, via reflexivity, that
    $\loc_2 \types S \in \Delta_{\loc}$, and since $\loc_2 \neq \loc$
    that $\loc_2 \types S \in \Delta$, along with
    $op \types P \rightarrowtail A \in S$, $v \in P$ and
    $A \subseteq \redva{\Delta_{\loc}}{\glob \tau}{\alpha} =
    \redv{\Delta}{\glob \tau}$. Thus the reduct is reducible by
    Lemmas~\ref{lemma:red-bind-intro}, \ref{lemma:red-unbox},
    \ref{lemma:red-return} and \ref{lemma:red-ret}.
  \item If $c$ is of the form $\letv{x}{\perform{\loc_2}{op}{v}}{c_2}$
    with $\loc_2 \neq \loc$ then it can reduce to
    $\letv{x}{\perform{\loc_2}{op}{v}}{\reify{\loc}{c_2}}$. From the
    reducibility of $c$ we have, via reflexivity, that
    $\loc_2 \types S \in \Delta$, $op \types P \rightarrowtail A \in S$
    and $v \in P$, and that for any $v_a \in A$ there is some
    $\beta < \alpha$ with
    $\sbst{c_2}{x}{v_a} \in \redca{\Delta_{\loc}}{\glob
      \tau}{\beta}$. By Lemma~\ref{lemma:red-bind-intro} it is
    sufficient to show that
    $\reify{\loc}{\sbst{c_2}{x}{v_a}} \in
    \redc{\Delta}{\ind{\Sigma}(\tau)}$ for any $v_a \in A$, which holds
    by the inductive hypothesis on $\beta$.
  \end{itemize}
\end{proof}

Recursion terms are reducible when built from reducible subterms. As
the recursion constructs a continuation, the hypotheses for the
operation branches quantify over extensions of the effect context.
\begin{lemma}
\label{lemma:red-rec}
\begin{align*}
  &v_s \in \redva{\Delta}{\ind{\{ op_1 \types \tau_{p_1} \rightarrowtail \tau_{a_1};
      \ldots; op_n\types \tau_{p_n} \rightarrowtail \tau_{a_n} \}}(\tau_1)}{\alpha} \\
  &\wedge \; (\forall v_r \in \redv{\cempty}{\tau_1}. \;
      \sbst{v_e}{x_r}{v_r} \in \redv{\Delta}{\tau_2}) \\
  &\wedge \; (\forall \Delta^{\prime} \supseteq \Delta. \;
      \forall v_{p_1} \in \redv{\cempty}{\tau_{p_1}}, \;
      v_{k_1} \in \redv{\Delta^{\prime}}{\glob \tau_{a_1} \arr \tau_2}. \\
    &\qquad \sbst{\sbst{v_1}{x_{p_1}}{v_{p_1}}}{x_{k_1}}{v_{k_1}} \in \redv{\Delta^{\prime}}{\tau_2}) \\
  &\ldots \\
  &\wedge \; (\forall \Delta^{\prime} \supseteq \Delta. \;
      \forall v_{p_n} \in \redv{\cempty}{\tau_{p_n}}, \;
      v_{k_n} \in \redv{\Delta^{\prime}}{\glob \tau_{a_n} \arr \tau_2}. \\
    &\qquad \sbst{\sbst{v_n}{x_{p_n}}{v_{p_n}}}{x_{k_n}}{v_{k_n}} \in \redv{\Delta^{\prime}}{\tau_2}) \\
  &\implies \\
  &\indelim{v_s}{\indretcase{x_r}{v_e} \seq
            \indcase{op_1}{x_{p_1}}{x_{k_1}}{v_1} \seq \ldots \seq
            \indcase{op_n}{x_{p_n}}{x_{k_n}}{v_n}}
    \in \redv{\Delta}{\tau_2}
\end{align*}
\end{lemma}
\begin{proof}
  Write $\Sigma$ for the signature and $H$ for the handler
  \begin{equation*}
    \indretcase{x_r}{v_e} \seq
    \indcase{op_1}{x_{p_1}}{x_{k_1}}{v_1} \seq \ldots \seq
    \indcase{op_n}{x_{p_n}}{x_{k_n}}{v_n}
  \end{equation*}
  Note that $v_e$ and each $v_i$ are strongly normalizing, since their
  substitution instances with variables are reducible. We proceed by
  induction on $\alpha$, for all $\Delta$, and then on
  $\bound{v_s} + \bound{v_e} + \bound{v_1} + \ldots +
  \bound{v_n}$. $\indelim{v_s}{H}$ is neutral so we can use
  CR3(\ref{lemma:red-neutral}). There are three kinds of reduct of
  $\indelim{v_s}{H}$:
  \begin{itemize}
  \item It can reduce by congruence in $v_s$, $v_e$ or one of the
    $v_i$. The subterms of the reduct remain reducible by
    CR2(\ref{lemma:red-reduces}) -- for the branches this is because
    each substitution instance of the reduced branch is a reduct of the
    corresponding substitution instance of the original branch -- so the
    reduct is reducible by the inductive hypothesis.
  \item If $v_s$ is of the form $\ret{v_r}$ then it can reduce to
    $\sbst{v_e}{x_r}{v_r}$. From
    $v_s \in \redva{\Delta}{\ind{\Sigma}(\tau_1)}{\alpha}$ we have,
    via reflexivity, that $v_r \in \redv{\cempty}{\tau_1}$, so
    the reduct is reducible by hypothesis.
  \item If $v_s$ is of the form $\indintro{op_i}{v_p}{v_k}$ then it can
    reduce to $\sbst{\sbst{v_i}{x_{p_i}}{v_p}}{x_{k_i}}{v_c}$ where
    \begin{equation*}
      v_c =
      \abs{x_a}{\letv{x_w}{\app{v_k}{x_a}}{\return{(\indelim{x_w}{H})}}}
    \end{equation*}
    $\redsig{\Sigma}$ contains $op_i \types P \rightarrowtail A$ with
    $P = \redv{\cempty}{\tau_{p_i}}$ and
    $A = \redv{\cempty}{\glob \tau_{a_i}}$, so from
    $v_s \in \redva{\Delta}{\ind{\Sigma}(\tau_1)}{\alpha}$ we
    have, via reflexivity, that
    $v_p \in \redv{\cempty}{\tau_{p_i}}$ and that for any
    $v_a \in \redv{\cempty}{\glob \tau_{a_i}}$ there is some
    $\beta < \alpha$ with
    $\app{v_k}{v_a} \in
    \redca{\Delta}{\ind{\Sigma}(\tau_1)}{\beta}$. We show that
    $v_c \in \redv{\Delta}{\glob \tau_{a_i} \arr \tau_2}$,
    for which, by Lemma~\ref{lemma:red-abs}, it is sufficient to show
    that $\letv{x_w}{\app{v_k}{v_a}}{\return{(\indelim{x_w}{H})}}$ is
    in $\redc{\Delta^{\prime}}{\tau_2}$ for any
    $\Delta^{\prime} \supseteq \Delta$ and
    $v_a \in \redv{\Delta^{\prime}}{\glob \tau_{a_i}} =
    \redv{\cempty}{\glob \tau_{a_i}}$. Fix such a $\Delta^{\prime}$
    and $v_a$, and let $\beta < \alpha$ be such that
    $\app{v_k}{v_a} \in \redca{\Delta}{\ind{\Sigma}(\tau_1)}{\beta}$,
    so that also
    $\app{v_k}{v_a} \in \redca{\Delta^{\prime}}{\ind{\Sigma}(\tau_1)}{\beta}$
    by effect weakening (\ref{lemma:red-weaken}). The hypotheses of
    this lemma hold for $\Delta^{\prime}$ as well as for $\Delta$: the
    hypothesis for the $\retname$ branch by effect weakening, and the
    hypotheses for the operation branches because any
    $\Delta^{\prime\prime} \supseteq \Delta^{\prime}$ also
    satisfies $\Delta^{\prime\prime} \supseteq \Delta$. Thus for any
    $v_w \in \redva{\Delta^{\prime}}{\ind{\Sigma}(\tau_1)}{\beta}$ we
    have that $\indelim{v_w}{H}$ is in $\redv{\Delta^{\prime}}{\tau_2}$
    by the inductive hypothesis on $\beta$ for $\Delta^{\prime}$, and
    thus $\return{(\indelim{v_w}{H})}$ is in
    $\redc{\Delta^{\prime}}{\tau_2}$ by
    Lemma~\ref{lemma:red-return}. Thus
    $\letv{x_w}{\app{v_k}{v_a}}{\return{(\indelim{x_w}{H})}}$ is in
    $\redc{\Delta^{\prime}}{\tau_2}$ by Lemma~\ref{lemma:red-bind},
    and so $v_c$ is reducible. The reduct is then reducible by the
    hypothesis for the $op_i$ branch, taking $\Delta^{\prime} = \Delta$.
  \end{itemize}
\end{proof}

\subsection{Reducible substitutions}

A substitution $\sigma$ is a sequence of single variable substitutions
$\sub{x_1}{v_1} \cdots \sub{x_n}{v_n}$, applied to a term one at a time
from left to right. We write $\fv{\sigma}$ for the free variables of
the values of $\sigma$.

We define a notion of reducibility for substitutions as a reducibility
predicate $\reds{\Delta}{\Gamma}$ indexed by an effect context and a
typing context. A substitution in $\reds{\Delta}{\Gamma}$ should be
thought of as an interpretation of the typing context $\Gamma$
in the effect context $\Delta$: it has one entry for each variable
binding of $\Gamma$, with the values for local bindings reducible in
$\Delta$ and the values for global bindings reducible in the empty
effect context, and it requires $\Delta$ to bind each location of
$\Gamma$ to the interpretation of its signature. Note that $\Delta$ is
not a context for $\Gamma$ in the sense of binding things that
$\Gamma$ may refer to, but the effect context in which the terms of
$\Gamma$ are interpreted. The freshness conditions ensure that the
entries of a reducible substitution do not interact with one another,
so that it behaves as a simultaneous substitution.
\begin{align*}
  &\reds{\Delta}{\cempty} =
    \{ \, \cempty \, \} \\
  &\reds{\Delta}{\lbind{\Gamma}{x}{\tau}} =
    \{ \, \sigma \cdot \sub{x}{v} \; | \;
       x \notin \fv{\sigma}
       \; \wedge \; \sigma \in \reds{\Delta}{\Gamma}
       \; \wedge \; v \in \redv{\Delta}{\tau} \, \} \\
  &\reds{\Delta}{\gbind{\Gamma}{x}{\tau}} =
    \{ \, \sigma \cdot \sub{x}{v} \; | \;
       x \notin \fv{\sigma}
       \; \wedge \; \sigma \in \reds{\Delta}{\Gamma}
       \; \wedge \; v \in \redv{\cempty}{\tau} \, \} \\
  &\reds{\Delta}{\lbind{\Gamma}{\loc}{\Sigma}} =
    \{ \, \sigma \; | \;
       \sigma \in \reds{\Delta}{\Gamma}
       \; \wedge \; \loc \types \redsig{\Sigma} \in \Delta \, \}
\end{align*}
where $\cempty$ is the empty sequence.

Reducible substitutions can be extended with reducible values and with
location bindings:
\begin{lemma}
\label{lemma:red-subst-extend}
Providing that $x$ does not occur free in the values of $\sigma$:
\begin{align*}
  &\sigma \in \reds{\Delta}{\Gamma}
   \; \wedge \; v \in \redv{\Delta}{\tau} \\
  &\quad \implies \;
   \sigma \cdot \sub{x}{v} \in \reds{\Delta}{\lbind{\Gamma}{x}{\tau}} \\
  &\sigma \in \reds{\Delta}{\Gamma}
   \; \wedge \; v \in \redv{\cempty}{\tau} \\
  &\quad \implies \;
   \sigma \cdot \sub{x}{v} \in \reds{\Delta}{\gbind{\Gamma}{x}{\tau}} \\
  &\sigma \in \reds{\Delta}{\Gamma}
   \; \wedge \; \loc \types \redsig{\Sigma} \in \Delta
   \; \implies \;
   \sigma \in \reds{\Delta}{\lbind{\Gamma}{\loc}{\Sigma}}
\end{align*}
\end{lemma}
\begin{proof}
  Immediate from the definition of $\redsname$.
\end{proof}

An interpretation in an effect context is also an interpretation in
any extension of it:
\begin{lemma}
\label{lemma:red-subst-weaken}
\begin{align*}
  \sigma \in \reds{\Delta}{\Gamma}
  \; \wedge \; \Delta \subseteq \Delta^{\prime}
  \; \implies \;
  \sigma \in \reds{\Delta^{\prime}}{\Gamma}
\end{align*}
\end{lemma}
\begin{proof}
  By induction on $\Gamma$. The values for local bindings remain
  reducible by effect weakening (\ref{lemma:red-weaken}), the
  conditions on the values for global bindings do not mention the
  effect context, and every location binding of $\Delta$ is also a
  binding of $\Delta^{\prime}$.
\end{proof}

Reducible substitutions substitute reducible values for variables, and
the effect context binds the locations of the typing context:
\begin{lemma}
\label{lemma:red-subst-var}
\begin{align*}
  &\sigma \in \reds{\Delta}{\ccons{\lbind{\Gamma_1}{x}{\tau}}{\Gamma_2}}
    \; \implies \;
    x[\sigma] \in \redv{\Delta}{\tau} \\
  &\sigma \in \reds{\Delta}{\ccons{\gbind{\Gamma_1}{x}{\tau}}{\Gamma_2}}
    \; \implies \;
    x[\sigma] \in \redv{\Delta}{\tau} \\
  &\sigma \in \reds{\Delta}{\ccons{\lbind{\Gamma_1}{\loc}{\Sigma}}{\Gamma_2}}
    \; \implies \;
    \loc \types \redsig{\Sigma} \in \Delta
\end{align*}
\end{lemma}
\begin{proof}
  By induction on $\Gamma_2$. The entries for the bindings before $x$
  bind other variables, so they leave the term $x$ unchanged, and the
  freshness conditions for the entries for the bindings after $x$
  ensure that they do not affect the value $v$ substituted for $x$, so
  $x[\sigma] = v$. For a local binding the definition gives
  $v \in \redv{\Delta}{\tau}$ directly. For a global binding the
  definition gives $v \in \redv{\cempty}{\tau}$, and the result follows
  by effect weakening (\ref{lemma:red-weaken}). For a location binding
  the definition gives $\loc \types \redsig{\Sigma} \in \Delta$
  directly.
\end{proof}

Finally, reducible substitutions can be divided. We write
$\cdiv{\sigma}$ for the subsequence of $\sigma$ consisting of the
entries for the global bindings of the context.
\begin{lemma}
\label{lemma:red-subst-cdiv}
\begin{align*}
  \sigma \in \reds{\Delta}{\Gamma}
  \; \implies \;
  \cdiv{\sigma} \in \reds{\Delta^{\prime}}{\cdiv{\Gamma}}
\end{align*}
for any effect context $\Delta^{\prime}$, and in particular for
$\Delta^{\prime} = \cempty$.
\end{lemma}
\begin{proof}
  By induction on $\Gamma$. The entries for local bindings are dropped
  along with their bindings, the location bindings are dropped, the
  freshness conditions for the remaining entries are implied by those
  for $\sigma$, and the conditions on the entries for global bindings
  do not mention the effect context.
\end{proof}
Note that a term typed in $\cdiv{\Gamma}$ contains no free occurrences
of the local variables or locations of $\Gamma$, so, using the
freshness conditions, for such a term $v$ we have
$v[\sigma] = v[\cdiv{\sigma}]$.

\subsection{Reducibility theorem}
Well-typed terms are reducible under any reducible substitution:
\begin{align*}
    &\Gamma \turnv v \types \tau
      \quad \wedge \quad \sigma \in \reds{\Delta}{\Gamma}
      \quad \implies \quad v[\sigma] \in \redv{\Delta}{\tau} \\
    &\Gamma \turnc c \types \tau
      \quad \wedge \quad \sigma \in \reds{\Delta}{\Gamma}
      \quad \implies \quad c[\sigma] \in \redc{\Delta}{\tau}
\end{align*}
\begin{proof}
  By mutual induction on the typing derivations for $v$ and $c$, for
  all $\Delta$ and $\sigma$. The variable and location cases follow
  from Lemma~\ref{lemma:red-subst-var}, using Lemma~\ref{lemma:red-loc}
  for the latter. Every other case consists of applying the
  corresponding lemma from the preceding subsections
  (\ref{lemma:red-pair}--\ref{lemma:red-rec}) or its associated
  corollary. The premises of those lemmas are met as follows.
  \begin{itemize}
  \item Premises typed in $\Gamma$ itself use the inductive hypothesis
    with $\sigma$ directly.
  \item Premises typed under additional variable bindings use the
    inductive hypothesis with $\sigma$ extended by the extension lemma
    (\ref{lemma:red-subst-extend}): the reducible values quantified over
    by the lemmas for the binding forms are exactly those required by
    the extension lemma.
  \item Premises that are quantified over extensions
    $\Delta^{\prime} \supseteq \Delta$ of the effect context first move
    $\sigma$ to $\Delta^{\prime}$ using
    Lemma~\ref{lemma:red-subst-weaken}, and then proceed as above with
    $\Delta^{\prime}$ in place of $\Delta$.
  \item Premises typed under an additional location binding
    $\loc \types \Sigma$ first move $\sigma$ to
    $\lbind{\Delta}{\loc}{\redsig{\Sigma}}$ using
    Lemma~\ref{lemma:red-subst-weaken}, and then use the inductive
    hypothesis with $\sigma$ extended by the location binding via the
    extension lemma (\ref{lemma:red-subst-extend}).
  \item Premises typed in the divided context $\cdiv{\Gamma}$ use the
    inductive hypothesis with $\cdiv{\sigma}$ in the empty effect
    context via the division lemma (\ref{lemma:red-subst-cdiv}).
  \end{itemize}
\end{proof}

Write $\clocs{\Gamma}$ for the effect context that keeps only its
location bindings, binding $\loc$ to $\redsig{\Sigma}$ for each location
binding $\loc \types \Sigma$ of $\Gamma$. The substitution that replaces
every variable of $\Gamma$ with itself is in
$\reds{\clocs{\Gamma}}{\Gamma}$, since variables are reducible by
CR3(\ref{lemma:red-neutral}). As a corollary we get:
\begin{align*}
    &\Gamma \turnv v \types \tau
      \quad \implies \quad v \in \redv{\clocs{\Gamma}}{\tau} \\
    &\Gamma \turnc c \types \tau
      \quad \implies \quad c \in \redc{\clocs{\Gamma}}{\tau}
\end{align*}
from which it immediately follows by CR1(\ref{lemma:red-implies-sn})
that well-typed terms are strongly normalizing.

\subsection{Effect safety}
\label{apdx:effect-safety}

We now prove the effect safety theorem
(Theorem~\ref{lemma:effect-safety}). We write $v \stepsnotv$ to indicate
that $v$ has no reducts under $\stepstov$. We says such values are
irreducible. Similarly, we write $c \stepsnotc$ for irreducible
computations. Since the reduction relations are closed under congruence,
every immediate subterm of an irreducible term is itself irreducible,
including the bodies of binders.

\begin{lemma}[Canonical forms]
\label{lemma:canonical-forms}
  If $\Gamma \turnv \omega \types \tau$ for a normal value $\omega$
  that is not a neutral normal value $\eta$, then:
  \begin{itemize}
  \item if $\tau = \tau_1 \times \tau_2$ then $\omega$ is of the form
    $(\omega_1, \omega_2)$;
  \item if $\tau = 1$ then $\omega$ is $()$;
  \item if $\tau = \tau_1 + \tau_2$ then $\omega$ is of the form
    $\inl{\omega_1}$ or $\inr{\omega_1}$;
  \item if $\tau = \tau_1 \arr \tau_2$ then $\omega$ is of the form
    $\abs{x}{\mu}$;
  \item if $\tau = \glob \tau_1$ then $\omega$ is of the form
    $\gbox{\omega_1}$;
  \item if $\tau = \ind{\Sigma}(\tau_1)$ then $\omega$ is of the form
    $\ret{\omega_1}$ or $\indintro{op}{\omega_1}{\omega_2}$;
  \item if $\tau = \yoneda{\Sigma}$ then $\omega$ is of the form
    $\loc$, $\outl{\omega_1}$ or $\outr{\omega_1}$.
  \end{itemize}
\end{lemma}
\begin{proof}
  By inspection of the grammar of normal values
  (Fig.~\ref{fig:normal}) and the typing rules: each non-neutral normal
  value form is an introduction form, and its typing rule determines the
  outermost type constructor of its type.
\end{proof}

\begin{lemma}[Progress]
\label{lemma:progress}
  Well-typed irreducible terms are normal forms:
  \begin{align*}
    &\Gamma \turnv v \types \tau
      \quad \wedge \quad v \stepsnotv
      \quad \implies \quad v \text{ is a normal value } \omega \\
    &\Gamma \turnc c \types \tau
      \quad \wedge \quad c \stepsnotc
      \quad \implies \quad c \text{ is a normal computation } \mu
  \end{align*}
\end{lemma}
\begin{proof}
  By mutual induction on the typing derivations. In each case the
  immediate subterms are irreducible and well-typed, so by the
  inductive hypothesis they are normal values or normal computations.
  \begin{description}
  \item[Variables] $x$ is a neutral normal value and
    $\loc$ is a normal value.
  \item[Introduction] $\abs{x}{\mu}$, $(\omega_1, \omega_2)$,
    $()$, $\inl{\omega}$, $\inr{\omega}$, $\gbox{\omega}$,
    $\ret{\omega}$, $\indintro{op}{\omega_1}{\omega_2}$, $\outl{\omega}$
    and $\outr{\omega}$ are all normal values by the grammar of
    Fig.~\ref{fig:normal}.
  \item[Projections] For $\fst{\omega}$, $\omega$ has a product type,
    so by Lemma~\ref{lemma:canonical-forms} it is either a pair, in
    which case $\fst{\omega}$ reduces, or neutral, in which case
    $\fst{\omega}$ is neutral. The case for $\sndname$ is the same.
  \item[Case] For $\casem{\omega_1}{x_1}{\omega_2}{x_2}{\omega_3}$,
    $\omega_1$ has a sum type, so it is either an injection, in which
    case the term reduces, or neutral, in which case the term is
    neutral.
  \item[Unbox] For $\gunbox{x}{\omega_1}{\omega_2}$, $\omega_1$ has a
    global type, so it is either of the form $\gbox{\omega}$, in which
    case the term reduces, or neutral, in which case the term is
    neutral.
  \item[Run] For $\grun{\mu}$, the computation $\mu$ is typed in the
    divided context $\cdiv{\Gamma}$, which contains no location
    bindings. The normal computation forms $\perform{\loc}{op}{\omega}$
    and $\letv{x}{\perform{\loc}{op}{\omega}}{\mu^{\prime}}$ require a
    binding for $\loc$ in the context, so $\mu$ is either of the form
    $\return{\omega}$, in which case $\grun{\mu}$ reduces, or a neutral
    normal computation $\nu$, in which case $\grun{\nu}$ is neutral.
  \item[Recursion] For $\indelim{\omega_s}{\ldots}$, $\omega_s$ has an
    inductive type, so it is either of the form $\ret{\omega}$ or
    $\indintro{op}{\omega_1}{\omega_2}$, in which case the term
    reduces, or neutral, in which case the term is neutral.
  \item[Return] $\return{\omega}$ is a normal computation.
  \item[Application] For $\app{\omega_1}{\omega_2}$, $\omega_1$ has a
    function type, so it is either an abstraction, in which case the
    term reduces, or neutral, in which case the term is neutral.
  \item[Let] For $\letv{x}{\mu_1}{\mu_2}$ we consider the form of
    $\mu_1$. If it is $\return{\omega}$ then the term reduces. If it is
    $\letv{x_1}{\perform{\loc}{op}{\omega}}{\mu^{\prime}}$ then the
    term reduces by the commuting rule. If it is
    $\perform{\loc}{op}{\omega}$ then the term is a normal computation
    of the form $\letv{x}{\perform{\loc}{op}{\omega}}{\mu_2}$. If it is
    neutral then the term is neutral.
  \item[Reflection] For $\perform{\omega_1}{op}{\omega_2}$, $\omega_1$
    has a capability type, so by Lemma~\ref{lemma:canonical-forms} it
    is either of the form $\outl{\omega}$ or $\outr{\omega}$, in which
    case the term reduces, a location $\loc$, in which case the term is
    a normal computation, or neutral, in which case the term is
    neutral.
  \item[Reification] For $\reify{\loc}{\mu}$ we consider the form of
    $\mu$. If it is of the form $\perform{\loc^{\prime}}{op}{\omega}$,
    or of the form
    $\letv{x}{\perform{\loc^{\prime}}{op}{\omega}}{\mu^{\prime}}$, then
    the term reduces, whether or not $\loc^{\prime} = \loc$. If it is
    $\return{\omega}$ then $\omega$ has a global type, so it is either
    of the form $\gbox{\omega^{\prime}}$, in which case the term
    reduces, or neutral, in which case $\reify{\loc}{\return{\eta}}$ is
    neutral. If $\mu$ is neutral then the term is neutral.
  \end{description}
\end{proof}

\begin{lemma}[Closed normal forms]
\label{lemma:closed-normal-forms}
  Every neutral normal value $\eta$ and every neutral normal
  computation $\nu$ has a free variable. Every normal computation $\mu$
  that is not of the form $\return{\omega}$ has a free variable or a
  free location.
\end{lemma}
\begin{proof}
  By mutual induction on the grammar of Fig.~\ref{fig:normal}. A neutral
  normal value is either a variable, or has an immediate subterm that is
  a neutral normal value or neutral normal computation in a position
  that is not under a binder (the scrutinee of a projection,
  $\casename$, global $\letvname$ or $\indelimname$, or the body of
  $\grunname$). A neutral normal computation similarly has such a
  subterm in a position that is not under a variable binder: the
  function of an application, the capability of a reflection, the bound
  computation of a $\letvname$, or the body of a reification, which
  binds only a location. Finally, a normal computation is either
  neutral, of the form $\return{\omega}$, or of one of the forms
  $\perform{\loc}{op}{\omega}$ and
  $\letv{x}{\perform{\loc}{op}{\omega}}{\mu}$ in which $\loc$ is free.
\end{proof}

\begin{proof}[Proof of Theorem~\ref{lemma:effect-safety}]
  Let $\turnc c \types \tau$. By strong normalization
  (Theorem~\ref{lemma:strong-normalization}) there is an irreducible
  $c^{\prime}$ with $c \reducestoc c^{\prime}$, and by subject
  reduction (Theorem~\ref{lemma:subject-reduction})
  $\turnc c^{\prime} \types \tau$. By Lemma~\ref{lemma:progress},
  $c^{\prime}$ is a normal computation, and since it is well-typed in
  the empty context it has no free variables or locations. Hence by
  Lemma~\ref{lemma:closed-normal-forms} it is of the form
  $\return{\omega}$.
\end{proof}

\section{Embedding the Simply-Typed Lambda Calculus}
\label{apdx:embedding}
We define an embedding $\embed{\_}$ on types, contexts and terms of the
Simply-Typed Lambda Calculus (STLC) in Fig.\ref{fig:stlc}.
\begin{figure}
\begin{equation*}
\begin{aligned}[c]
  &\embed{1} = 1 \\
  &\embed{A \times B} = \embed{A} \times \embed{B} \\
  &\embed{A \rightarrow B} = \glob \embed{A} \arr \embed{B} \\ \\
  &\embed{\cempty} = \cempty \\
  &\embed{\lbind{\Gamma}{x}{A}} = \gbind{\embed{\Gamma}}{x}{\embed{A}}
\end{aligned}
\qquad
\begin{aligned}[c]
  &\embed{x} = x \\
  &\embed{(e, f)} = (\embed{e}, \embed{f}) \\
  &\embed{\fst{e}} = \fst{\embed{e}} \\
  &\embed{\snd{e}} = \snd{\embed{e}} \\
  &\embed{\abs{x}{e}} =
    \abs{(\gbox{x})}{\return{\embed{e}}} \\
  &\embed{\app{f}{e}} = \grun{\app{\embed{f}}{\gbox{\embed{e}}}}
\end{aligned}
\end{equation*}
\caption{Embedding of Simply-Typed Lambda Calculus into values}
\label{fig:stlc}
\end{figure}

Note that the embedding produces contexts with only global bindings so
that:
\begin{lemma}
\label{lemma:stlc-global-context}
  \begin{equation*}
    \cdiv{\embed{\Gamma}} = \embed{\Gamma}
  \end{equation*}
\end{lemma}

This embedding maps well-typed STLC terms to well-typed values:
\begin{lemma}
\label{lemma:stlc-well-typed}
  \begin{equation*}
    \Gamma \turnstlc e \types t
    \quad \implies \quad \embed{\Gamma} \turnv \embed{e} \types \embed{t}
  \end{equation*}
\end{lemma}
which is proved by induction on the STLC typing derivation. The case for
the app rule relies on \ref{lemma:stlc-global-context} in order to apply
$\grunname$ to the embedded expression.

Reduction of STLC terms is modelled by the reduction of the embedded
terms:
\begin{lemma}
\label{lemma:stlc-reduces}
  \begin{equation*}
    e_1 \stepstostlc e_2
    \quad \implies \quad \embed{e_1} \reducestov \embed{e_2}
  \end{equation*}
\end{lemma}
We prove this via induction on the STLC reduction relation. All cases
are trivial except for the function beta-reduction case:
\begin{equation*}
  \embed{\app{(\abs{x}{e_1})}{e_2}} \reducestov \embed{\sbst{e_1}{x}{e_2}}
\end{equation*}
which expands to:
\begin{equation*}
\grun{\app{(\abs{(\gbox{x})}{\return{\embed{e_1}}})}{\gbox{\embed{e_2}}}}  \reducestov \embed{\sbst{e_1}{x}{e_2}}
\end{equation*}
applying the function beta rule, the unboxing rule for the global
modality, the $\grunname$ reduction rule and reflexivity, this becomes:
\begin{equation*}
\embed{\sbst{e_1}{x}{e_2}} = \sbst{\embed{e_1}}{x}{\embed{e_2}}
\end{equation*}
which follows by induction on $e_1$.

Normal forms of STLC are embedded to normal forms:
\begin{lemma}
\label{lemma:normal}
  \begin{equation*}
    e \stepsnotstlc
    \quad \implies \quad \embed{e} \stepsnotv
  \end{equation*}
\end{lemma}
This follows from observing that the neutral forms and normal forms of
STLC embed to neutral and normal forms respectively. Since our language
is strongly normalizing (\ref{lemma:strong-normalization}) this is
sufficient to show that the embedding correctly models STLC.

\section{Bounded Lawvere theories and predicative signatures}
\label{apdx:bounds}

In this appendix we prove the claims made in Sections~\ref{sec:small}
and~\ref{sec:predicative}: that $\lawc$ is a small category closed under
the constructions used by our semantics, and that for any predicative
signature $\Sigma$ there is a cardinal $\card{\Sigma}$, determined by
the syntax of $\Sigma$ and independent of $\kappa$, that bounds the
parameters and arities of the operations of $\sem{\Sigma}$. Consequently
$\sem{\Sigma}$ is an object of $\lawc$ for any regular $\kappa$ with
$\card{\Sigma} < \kappa$, and thus a sufficiently large $\kappa$ always
exists.

Throughout this appendix, $2^{<\kappa}$ denotes the cardinal
$\sup_{\lambda < \kappa} 2^{\lambda}$. We treat the
semantics of types as covariant functors $\lawc \arr \setc$ as described
in Section~\ref{sec:presheaves}. When we say that a cardinal is
determined by some syntax ``independently of $\kappa$'' we mean that it
takes the same value for every regular $\kappa$ at which the semantics
is defined.

\subsection{Properties of $\lawc$}
\label{apdx:lawprops}

\begin{lemma}
\label{lemma:cardinal-arithmetic}
  $\kappa \le 2^{<\kappa}$, and $(2^{<\kappa})^{\lambda} = 2^{<\kappa}$
  for every $\lambda < \kappa$.
\end{lemma}
\begin{proof}
  Standard cardinal arithmetic.
\end{proof}

\begin{lemma}
\label{lemma:term-count}
Let $L$ be an algebraic theory presented by at most $2^{<\kappa}$
operations, each with arity smaller than $\kappa$, together with any
set of equations. Then, the theory can be represented as a
$\kappa$-bounded Lawvere theory.
\end{lemma}
\begin{proof}
  The constraint we need to meet is that the set of morphisms is at most
  $2^{<\kappa}$. The morphisms $X^S \arr X$ are just the terms of $L$ in
  a set $S$ of variables with $|S| < \kappa$. Terms are well-founded, so
  every path from the root of a term to a variable is finite, but when
  arities are infinite the heights of terms may also be infinite. For
  instance, with a single $\aleph_0$-ary operation $g$, the term
  $g(t_0, t_1, \ldots)$, where each $t_n$ is built from $n$ nested
  applications of $g$, has subterms of unbounded finite height and so
  itself has height $\omega$. We therefore count terms by transfinite
  iteration. Let $T^{0} = S$, let $T^{\alpha+1}$ extend $T^{\alpha}$
  with every term $op(t_i)_{i \in A}$ whose immediate subterms $t_i$ are
  drawn from $T^{\alpha}$, and let
  $T^{\lambda} = \bigcup_{\alpha < \lambda} T^{\alpha}$ for limit
  ordinals $\lambda$. Operation arities are less than $\kappa$, and
  $\kappa$ is regular, so every term appears in $T^{\kappa}$. We show
  that $|T^{\alpha}| \le 2^{<\kappa}$ for every $\alpha \le \kappa$, by
  transfinite induction using Lemma~\ref{lemma:cardinal-arithmetic}:
  \begin{align*}
    |T^{0}| &= |S| < \kappa \le 2^{<\kappa} \\
    |T^{\alpha+1}| &\le |T^{\alpha}| + 2^{<\kappa} \cdot |T^{\alpha}|^{<\kappa}
      \le 2^{<\kappa} + 2^{<\kappa} \cdot 2^{<\kappa}
      = 2^{<\kappa} \\
    |T^{\lambda}| &\le \textstyle\sum_{\alpha < \lambda} |T^{\alpha}|
      \le \kappa \cdot 2^{<\kappa}
      = 2^{<\kappa}
      && \text{for limit $\lambda$}
  \end{align*}
  Since $\kappa$ is itself a limit ordinal,
  $|T^{\kappa}| \le 2^{<\kappa}$.

  Quotienting by the equations of $L$ only shrinks this set, so $L$ has
  at most $2^{<\kappa}$ terms, and there are at most $2^{<\kappa}$
  morphisms $X^S \arr X$. The morphisms $X^S \arr X^{S^\prime}$
  correspond to $S^\prime$-indexed families of morphisms $X^S \arr X$,
  of which there are at most $(2^{<\kappa})^{|S^\prime|} = 2^{<\kappa}$;
  so there are at most
  $\kappa \cdot \kappa \cdot 2^{<\kappa} = 2^{<\kappa}$ morphisms in
  total.
\end{proof}

\begin{lemma}
\label{lemma:presentations}
  An algebraic theory is in $\lawc$ if and only if its operations have
  arities smaller than $\kappa$ and it can be presented using at most
  $2^{<\kappa}$ operations and at most $2^{<\kappa}$ equations.
\end{lemma}
\begin{proof}
  One direction is Lemma~\ref{lemma:term-count}. For the other, a
  theory $L$ in $\lawc$ has a canonical presentation by its own
  morphisms: one operation of arity $S$ for each morphism
  $X^S \arr X$ -- at most $2^{<\kappa}$ of them -- together with its
  composition table: for each morphism $f \types X^{S} \arr X$ and each
  $S$-indexed family of morphisms $g_i \types X^{S^\prime} \arr X$, an
  equation identifying the term $f(g_i)_{i \in S}$ with the morphism it
  composes to. By Lemma~\ref{lemma:cardinal-arithmetic} there are at
  most $2^{<\kappa} \cdot (2^{<\kappa})^{<\kappa} = 2^{<\kappa}$ such
  equations.
\end{proof}

Lemma~\ref{lemma:presentations} justifies describing the objects of
$\lawc$ as the algebraic theories that can be presented using at most
$2^{<\kappa}$ operations whose arities are smaller than $\kappa$, as we
did in Section~\ref{sec:small}.

\begin{lemma}
\label{lemma:smallness}
  Up to isomorphism, there are at most $2^{2^{<\kappa}}$
  $\kappa$-bounded Lawvere theories, and so $\lawc$ is a small
  category.
\end{lemma}
\begin{proof}
  Every $\kappa$-bounded Lawvere theory is isomorphic to one whose
  objects are the products $X^{\lambda}$ for cardinals
  $\lambda < \kappa$ and whose morphisms are drawn from a single fixed
  set of cardinality $2^{<\kappa}$. Such a theory is determined by its
  sets of objects and morphisms together with its source, target,
  composition and product structure -- all functions between sets of
  cardinality at most $2^{<\kappa}$ -- so there are at most
  $2^{2^{<\kappa}}$ of them. Taking one
  representative of each isomorphism class, and noting that the
  morphisms of $\lawc$ between any two theories form a set, $\lawc$ is
  a small category.
\end{proof}

\begin{lemma}
\label{lemma:law-closure}
  $\lawc$ contains the initial theory $\initial$ and is closed under
  binary coproducts.
\end{lemma}
\begin{proof}
  Morphisms out of a theory presented by some operations and equations
  correspond to interpretations of those operations as terms of the
  target theory that preserve the equations
  (Section~\ref{sec:small}); in particular, for a theory $L$ in
  $\lawc$, interpretations of the canonical presentation of
  Lemma~\ref{lemma:presentations} in $M$ correspond to morphisms
  $L \arr M$.

  The theory presented by no operations and no equations has exactly
  one interpretation in every theory -- there is nothing to interpret
  -- and hence a unique morphism to every theory, so it is the initial
  theory $\initial$. It is in $\lawc$ by
  Lemma~\ref{lemma:term-count}. Its only terms are variables, so its
  morphisms $X^S \arr X^{S^\prime}$ are the functions
  $S^\prime \arr S$ and
  $|\mathrm{Mor}(\initial)| = \sup_{\mu, \lambda < \kappa}
  \mu^{\lambda} = 2^{<\kappa}$.

  For coproducts, take the canonical presentations of $L$ and
  $L^\prime$ and let $C$ be the theory presented by their union. An
  interpretation of the union presentation in a theory $M$ is exactly
  a pair of interpretations of the two presentations, so:
  \begin{equation*}
    \homset{\lawc}{C}{M} \cong
    \homset{\lawc}{L}{M} \times \homset{\lawc}{L^\prime}{M}
  \end{equation*}
  naturally in $M$, with the projections given by composition with the
  morphisms $L \arr C$ and $L^\prime \arr C$ induced by the inclusions
  of the presentations. So $C$ is the coproduct $L + L^\prime$. The
  union presentation uses at most $2^{<\kappa}$ operations, with
  arities smaller than $\kappa$, so $L + L^\prime$ is in $\lawc$ by
  Lemma~\ref{lemma:term-count}.
\end{proof}

\subsection{Generated types are coproducts of representables}
\label{apdx:generated}

The development in this appendix rests on one structural fact: every
generated type denotes a coproduct of representable presheaves, indexed
by a family of theories that can be read off from the syntax of the
type. For each generated type $\taug$ we define an indexed family
$\mathcal{G}(\taug)$ of $\kappa$-bounded Lawvere theories by recursion
on $\taug$:
\begin{align*}
  \mathcal{G}(1) &= \{ \initial \} \\
  \mathcal{G}(\yoneda{\Sigma}) &= \{ \sem{\Sigma} \} \\
  \mathcal{G}(\glob \taub) &= \{ \initial \}_{s \in \sem{\taub}(\initial)} \\
  \mathcal{G}({\taug}_1 + {\taug}_2) &= \mathcal{G}({\taug}_1) \uplus \mathcal{G}({\taug}_2) \\
  \mathcal{G}({\taug}_1 \times {\taug}_2) &=
    \{ A_1 + A_2 \}_{A_1 \in \mathcal{G}({\taug}_1),\, A_2 \in \mathcal{G}({\taug}_2)}
\end{align*}
where the coproducts $A_1 + A_2$ are taken in $\lawc$.

\begin{lemma}
\label{lemma:generated}
  For every generated type $\taug$:
  \begin{equation*}
    \sem{\taug} \cong \coprod_{A \in \mathcal{G}(\taug)} \yoneda{A}
  \end{equation*}
\end{lemma}
\begin{proof}
  By induction on $\taug$, using that coproducts in $\pshlawcop$ are
  computed pointwise.
  \begin{itemize}
  \item $\sem{1} = 1 \cong \yoneda{\initial}$: since $\initial$ is
    initial in $\lawc$, $\homset{\lawc}{\initial}{L}$ is a singleton
    for every $L$.
  \item $\sem{\yoneda{\Sigma}} = \yoneda{\sem{\Sigma}}$ by definition
    (Section~\ref{sec:reflection}).
  \item $\sem{\glob \taub}$ is the constant presheaf at the set
    $\sem{\taub}(\initial)$ (Section~\ref{sec:global}), and a constant
    presheaf at a set $S$ is
    $\coprod_{s \in S} 1 \cong \coprod_{s \in S} \yoneda{\initial}$.
  \item For sums, a coproduct of coproducts is a coproduct: the index
    families concatenate and the representables are unchanged. (A
    coproduct $\yoneda{A_1} + \yoneda{A_2}$ is of course not itself
    representable; nothing here requires it to be.)
  \item For products, $\pshlawcop$ is a topos, so products distribute
    over coproducts, and
    $\yoneda{A_1} \times \yoneda{A_2} \cong \yoneda{A_1 + A_2}$ since
    the Yoneda embedding maps coproducts in $\lawc$ to products of
    presheaves (Section~\ref{sec:reflection}). Hence:
    \begin{equation*}
      \Big(\coprod_{A_1 \in \mathcal{G}({\taug}_1)} \yoneda{A_1}\Big)
      \times
      \Big(\coprod_{A_2 \in \mathcal{G}({\taug}_2)} \yoneda{A_2}\Big)
      \cong
      \coprod_{A_1,\, A_2} \yoneda{A_1 + A_2}
    \end{equation*}
  \end{itemize}
\end{proof}
The product clause is the only one that forms coproducts of theories,
and it only forms binary ones, which remain in $\lawc$ by
Lemma~\ref{lemma:law-closure}. Being a coproduct of representables is a
stronger condition than the related notions of $\lambda$-generated and
$\lambda$-presentable object~\cite{adamek1994locally}: coproducts of
representables are presented without any relations, which is why the
next lemma gives an isomorphism rather than a bound.

\begin{lemma}
\label{lemma:evaluation}
  If $F \cong \coprod_{i \in I} \yoneda{A_i}$ then, for every $G$ in
  $\pshlawcop$:
  \begin{equation*}
    \homset{\pshlawcop}{F}{G} \cong \prod_{i \in I} G(A_i)
  \end{equation*}
\end{lemma}
\begin{proof}
  $\homset{\pshlawcop}{\_}{G}$ maps colimits to limits, and
  $\homset{\pshlawcop}{\yoneda{A}}{G} \cong G(A)$ by the Yoneda lemma.
\end{proof}

Since Lemma~\ref{lemma:evaluation} is an isomorphism, not merely a
bound, the cardinality computations below are exact wherever their
inputs are.

\subsection{Inductive types are bounded}

\begin{lemma}
\label{lemma:w-size}
  Let $\Sigma$ be a predicative signature, $\taub$ a bounded type and
  $L$ a theory in $\lawc$. Then
  $\ind{\sem{\Sigma}}(\sem{\taub})(L)$ is an initial algebra of the
  $\setc$ endofunctor
  $H_L(S) = \sem{\taub}(\initial) + F_{\sem{\Sigma}}(T_L(S))$, and so
  its cardinality is determined by $L$, $\sem{\Sigma}$ and
  $|\sem{\taub}(\initial)|$, independently of $\kappa$.
\end{lemma}
\begin{proof}
  Write $H(P) = (\glob \sem{\taub}) + F_{\sem{\Sigma}}(\mon P)$, with
  $F_{\sem{\Sigma}}$ applied pointwise, so that
  $\ind{\sem{\Sigma}}(\sem{\taub}) = \mu X. H(X)$
  (Section~\ref{sec:reification}). Writing $ev_L$ for the functor
  evaluating a presheaf at $L$:
  \begin{equation*}
    H(P)(L) = \sem{\taub}(\initial) + F_{\sem{\Sigma}}(T_L(P(L)))
            = H_L(P(L))
  \end{equation*}
  naturally in $P$, so $ev_L \circ H = H_L \circ ev_L$ and $ev_L$ maps
  $H$-algebras to $H_L$-algebras. Since colimits in $\pshlawcop$ are
  computed pointwise, $ev_L$ preserves colimits and so has a right
  adjoint. This adjunction lifts to an adjunction between the
  categories of $H$-algebras and of $H_L$-algebras, and left adjoints
  preserve initial objects, so $(\mu X. H(X))(L)$ is an initial algebra
  of $H_L$. Initial algebras are unique up to isomorphism, and $H_L$ is
  built from the set $\sem{\taub}(\initial)$, the operations of
  $\sem{\Sigma}$ and the monad $T_L$, none of which depend on $\kappa$.
\end{proof}

\subsection{Bounded types have $\kappa$-independent cardinality}

\begin{lemma}
\label{lemma:bounded-size}
  By mutual induction on the syntax of types and signatures:
  \begin{enumerate}
  \item For every predicative signature $\Sigma$, the parameter and
    arity sets $\sem{{\taub}_{p_i}}(\initial)$ and
    $\sem{{\taub}_{a_i}}(\initial)$ of the operations of $\sem{\Sigma}$
    are determined by the syntax of $\Sigma$, independently of
    $\kappa$.
  \item For every generated type $\taug$, the index family
    $\mathcal{G}(\taug)$ is determined by the syntax of $\taug$,
    independently of $\kappa$; moreover every member of
    $\mathcal{G}(\taug)$ is either $\initial$ or $\sem{\Sigma^\prime}$
    for a signature $\Sigma^\prime$ built as a sum of signatures
    occurring in $\taug$.
  \item For every bounded type $\taub$ and theory $L$ in $\lawc$, the
    cardinality $|\sem{\taub}(L)|$ is determined by $L$ and the syntax
    of $\taub$, independently of $\kappa$.
  \end{enumerate}
\end{lemma}
\begin{proof}
  Claim 1 is claim 3 applied at $\initial$ to the types ${\taub}_{p_i}$
  and ${\taub}_{a_i}$ of the operations of $\Sigma$, which are
  structurally smaller than $\Sigma$.

  For claim 2, the members of $\mathcal{G}(\taug)$ are $\initial$, the
  theories $\sem{\Sigma^\prime}$ for signatures $\Sigma^\prime$
  occurring in $\taug$, and -- from the product clause alone -- binary
  coproducts in $\lawc$ of such members. These coproducts stay within
  the class: $\initial$ is initial, so $\initial + A \cong A$, and
  $\sem{\Sigma_1} + \sem{\Sigma_2} \cong \sem{\Sigma_1 + \Sigma_2}$,
  since coproducts of theories union their operations
  (Section~\ref{sec:small}) and signatures are closed under sums
  (Section~\ref{sec:signatures}). The size of the index family is $1$
  for $1$ and $\yoneda{\Sigma}$; it is $|\sem{\taub}(\initial)|$ for
  $\glob \taub$, which is determined by claim 3; and it adds over sums
  and multiplies over products.

  For claim 3 we consider each clause of the grammar of bounded
  types. The unit, product and sum clauses are the pointwise
  constructions of Section~\ref{sec:presheaves}, so their
  cardinalities are determined by those of their subterms at $L$. The
  $\glob$ clause has $|\sem{\glob \taub}(L)| = |\sem{\taub}(\initial)|$
  (Section~\ref{sec:global}), determined by the induction hypothesis at
  $\initial$. For $\yoneda{\Sigma}$, the theory $\sem{\Sigma}$ is free
  on the operations of $\Sigma$, so a morphism $\sem{\Sigma} \arr L$ is
  precisely an independent choice, for each operation
  $op \types {\taub}_{p} \rightarrowtail {\taub}_{a}$ of $\Sigma$ and
  each element of $\sem{{\taub}_{p}}(\initial)$, of a term of $L$ of
  arity $\sem{{\taub}_{a}}(\initial)$ (Section~\ref{sec:small}). Hence:
  \begin{equation*}
    |\yoneda{\sem{\Sigma}}(L)|
    = \prod_{op_i \in \Sigma}
      |T_L(\sem{{\taub}_{a_i}}(\initial))|^{|\sem{{\taub}_{p_i}}(\initial)|}
  \end{equation*}
  where the parameter and arity sets are determined by claim 1, and
  $|T_L(S)|$ is determined by $L$ and $|S|$. The clause for inductive
  types is Lemma~\ref{lemma:w-size}.

  For function types, exponentials of presheaves satisfy
  $\arrow{P}{Q}(L) \cong \homset{\pshlawcop}{\yoneda{L} \times P}{Q}$
  (Section~\ref{sec:reification}). By Lemma~\ref{lemma:generated} and
  the product clause of its proof:
  \begin{equation*}
    \yoneda{L} \times \sem{\taug}
    \cong \coprod_{A \in \mathcal{G}(\taug)} \yoneda{L + A}
  \end{equation*}
  so by Lemma~\ref{lemma:evaluation}:
  \begin{equation*}
    \sem{\taug \arr \taub}(L)
    \cong \prod_{A \in \mathcal{G}(\taug)} \mon(\sem{\taub})(L + A)
  \end{equation*}
  The quantification over all of $\lawc$ has become a product over
  $\mathcal{G}(\taug)$, which claim 2 determines from the syntax; each
  factor is $T_{(L + A)}(\sem{\taub}(L + A))$, determined by the theory
  $L + A$ and, by the induction hypothesis, by the syntax of $\taub$.
\end{proof}

\begin{corollary}
\label{corollary:predicative-bound}
  For a predicative signature $\Sigma$ with operations
  $op_i \types {\taub}_{p_i} \rightarrowtail {\taub}_{a_i}$, define:
  \begin{equation*}
    \card{\Sigma} = \max_{op_i \in \Sigma}
      \max\big(|\sem{{\taub}_{p_i}}(\initial)|,\,
               |\sem{{\taub}_{a_i}}(\initial)|\big)
  \end{equation*}
  a cardinal determined by the syntax of $\Sigma$ and independent of
  $\kappa$. Then $\sem{\Sigma}$ is an object of $\lawc$ for every
  regular $\kappa$ with $\card{\Sigma} < \kappa$.
\end{corollary}
\begin{proof}
  Claim 1 of Lemma~\ref{lemma:bounded-size} shows that $\card{\Sigma}$
  is well-defined and independent of $\kappa$. For regular $\kappa$
  with $\card{\Sigma} < \kappa$, the arities of the operations of
  $\sem{\Sigma}$ are smaller than $\kappa$. The number of operations of
  $\sem{\Sigma}$ is $\sum_{op_i \in \Sigma}
  |\sem{{\taub}_{p_i}}(\initial)|$ -- a finite sum of cardinals no
  greater than $\card{\Sigma}$, so certainly at most $2^{<\kappa}$ -- and
  $\sem{\Sigma}$ has no equations, so $\sem{\Sigma}$ is in $\lawc$ by
  Lemma~\ref{lemma:term-count}.
\end{proof}

Since $\card{\Sigma}$ does not mention $\kappa$ and successor cardinals
are regular, $\kappa = \card{\Sigma}^{+}$ always suffices; no
large-cardinal assumptions are required. A given program mentions only
finitely many signatures, so taking $\kappa$ greater than the maximum
of their bounds justifies deferring the choice of $\kappa$ as we did in
Section~\ref{sec:small}.

\subsection{Weakening}

We will need lemmas showing that weakening is equivalent to projection
for local bindings:
\begin{lemma}
\label{lemma:sem-weakening-local}
\begin{align*}
  \sem{\Gamma \turnv v \types \tau_1} \circ \fstc{\sem{\Gamma}}{\sem{\tau_2}}
  &= \sem{\lbind{\Gamma}{x}{\tau_2} \turnv v \types \tau_1} \\
  \sem{\Gamma \turnc c \types \tau_1} \circ \fstc{\sem{\Gamma}}{\sem{\tau_2}}
  &= \sem{\lbind{\Gamma}{x}{\tau_2} \turnc c \types \tau_1}
\end{align*}
\end{lemma}
and global bindings:
\begin{lemma}
\label{lemma:sem-weakening-global}
\begin{align*}
  \sem{\Gamma \turnv v \types \tau_1} \circ \fstc{\sem{\Gamma}}{\glob(\sem{\tau_2})}
  &= \sem{\gbind{\Gamma}{x}{\tau_2} \turnv v \types \tau_1} \\
  \sem{\Gamma \turnc c \types \tau_1} \circ \fstc{\sem{\Gamma}}{\glob(\sem{\tau_2})}
  &= \sem{\gbind{\Gamma}{x}{\tau_2} \turnc c \types \tau_1}
\end{align*}
\end{lemma}
and effect capability bindings:
\begin{lemma}
\label{lemma:sem-weakening-yoneda}
\begin{align*}
  \sem{\Gamma \turnv v \types \tau_1} \circ \fstc{\sem{\Gamma}}{\yoneda{\sem{\Sigma}}}
  &= \sem{\lbind{\Gamma}{\loc}{\Sigma} \turnv v \types \tau_1} \\
  \sem{\Gamma \turnc c \types \tau_1} \circ \fstc{\sem{\Gamma}}{\yoneda{\sem{\Sigma}}}
  &= \sem{\lbind{\Gamma}{\loc}{\Sigma} \turnc c \types \tau_1}
\end{align*}
\end{lemma}
\begin{proof}
  By mutual induction on the typing derivations for $v$ and $c$. We
  prove slightly stronger forms that allow additional bindings after
  $x$, so that we can use inductive hypotheses under additional
  bindings. The cases all follow from standard equalities about
  products and projections.
\end{proof}

We also need a lemma showing that weakening from $\cdiv{\Gamma}$ to
$\Gamma$ is equivalent to $\bdiv{\Gamma}$:
\begin{lemma}
\label{lemma:sem-weakening-cdiv}
\begin{align*}
  \sem{\cdiv{\Gamma} \turnv v \types \tau} \circ \bdiv{\Gamma}
  &= \sem{\Gamma \turnv v \types \tau} \\
  \sem{\cdiv{\Gamma} \turnc c \types \tau} \circ \bdiv{\Gamma}
  &= \sem{\Gamma \turnc c \types \tau}
\end{align*}
\end{lemma}
\begin{proof}
  By mutual induction on the typing derivations for $v$ and $c$. We
  prove slightly stronger forms that allow additional bindings after
  $\cdiv{\Gamma}$, so that we can use inductive hypotheses under
  additional bindings. The cases all follow from standard equalities
  about products and projections.
\end{proof}

\subsection{Substitution}

We will need lemmas showing that the semantics are compatible with substitution for local bindings:
\begin{lemma}
\label{lemma:sem-subst-local}
\begin{align*}
  \sem{\lbind{\Gamma}{x}{\tau_2} \turnv v_1 \types \tau_1}
      \circ \langle id_{\sem{\Gamma}}, \sem{\Gamma \turnv v_2 \types \tau_2} \rangle
  &= \sem{\Gamma \turnv \sbst{v_1}{x}{v_2} \types \tau_1} \\
  \sem{\lbind{\Gamma}{x}{\tau_2} \turnc c \types \tau_1}
      \circ \langle id_{\sem{\Gamma}}, \sem{\Gamma \turnv v \types \tau_2} \rangle
  &= \sem{\Gamma \turnc \sbst{c}{x}{v} \types \tau_1}
\end{align*}
\end{lemma}
\begin{proof}
  By mutual induction on the typing derivations for $v_1$ and $c$. We
  prove slightly stronger forms that allow additional bindings after
  $x$, so that we can use inductive hypotheses under additional
  bindings. The cases all follow from standard equalities about
  products and projections, along with the weakening lemmas
  (\ref{lemma:sem-weakening-local}, \ref{lemma:sem-weakening-global},
  \ref{lemma:sem-weakening-yoneda}) when moving under a binding.
\end{proof}

and similarly for global bindings.
\begin{lemma}
\label{lemma:sem-subst-global}
\begin{align*}
  \sem{\gbind{\Gamma}{x}{\tau_2} \turnv v_1 \types \tau_1}
    \circ \langle id_{\sem{\Gamma}},
  \glob \sem{\cdiv{\Gamma} \turnv v_2 \types \tau_2}
  \circ \comult{\glob}_{\sem{\cdiv{\Gamma}}} \circ \bdiv{\Gamma} \rangle
  &= \sem{\Gamma \turnv \sbst{v_1}{x}{v_2} \types \tau_1} \\
  \sem{\gbind{\Gamma}{x}{\tau_2} \turnc c \types \tau_1}
    \circ \langle id_{\sem{\Gamma}},
  \glob \sem{\cdiv{\Gamma} \turnv v \types \tau_2}
  \circ \comult{\glob}_{\sem{\cdiv{\Gamma}}} \circ \bdiv{\Gamma} \rangle
  &= \sem{\Gamma \turnc \sbst{c}{x}{v} \types \tau_1}
\end{align*}
\end{lemma}
\begin{proof}
  By mutual induction on the typing derivations for $v_1$ and $c$. We
  prove slightly stronger forms that allow additional bindings after
  $x$, so that we can use inductive hypotheses under additional
  bindings. The global variable case follows from the comonad laws of
  $\glob$ and weakening from $\cdiv{\Gamma}$ to $\Gamma$
  (\ref{lemma:sem-weakening-cdiv}).  The other cases all follow from
  standard equalities about products and projections, along with the
  weakening lemmas (\ref{lemma:sem-weakening-local},
  \ref{lemma:sem-weakening-global}, \ref{lemma:sem-weakening-yoneda})
  when moving under a binding.
\end{proof}

\subsection{Soundness}

\begin{align*}
  &\Gamma \turnv v_1 \types \tau
  \wedge v_1 \stepstov v_2
  \implies \sem{\Gamma \turnv v_1 \types \tau}
    = \sem{\Gamma \turnv v_2 \types \tau} \\
  &\Gamma \turnc c_1 \types \tau
  \wedge c_1 \stepstoc c_2
  \implies \sem{\Gamma \turnc c_1 \types \tau}
    = \sem{\Gamma \turnc c_2 \types \tau}
\end{align*}
\begin{proof}
  By induction on the reduction relation. The congruence rules all
  follow immediately by the inductive hypothesis, leaving just the rules
  from Fig.~\ref{fig:reduction}.

  \begin{description}
  \item[Products] For the product beta rules:
    \begin{align*}
      \fst{(v_1, v_2)} &\stepstov v_1 \\
      \snd{(v_1, v_2)} &\stepstov v_2
    \end{align*}
    the cases follow from the universal property of products.

  \item[Sums] For the sum rules:
    \begin{align*}
      \casem{(\inl{v_1})}{x_1}{v_2}{x_2}{v_3} &\stepstov \sbst{v_2}{x_1}{v_1} \\
      \casem{(\inr{v_1})}{x_1}{v_2}{x_2}{v_3} &\stepstov \sbst{v_3}{x_2}{v_1}
    \end{align*}
    the cases follow from the universal property of sums, their distribution over
    products and the substitution lemma (\ref{lemma:sem-subst-local}).

  \item[Global modality] For the global modality rule:
    \begin{equation*}
      \gunbox{x}{\gbox{v_1}}{v_2} \stepstov \sbst{v_2}{x}{v_1}
    \end{equation*}
    the case follows from the global substitution lemma
    (\ref{lemma:sem-subst-global}).

    For the run rule:
    \begin{equation*}
      \grun{\return{v}} \stepstov v
    \end{equation*}
    the case follows from the definition of $\ununit$, the comonad laws
    of $\glob$ and weakening from $\cdiv{\Gamma}$ to $\Gamma$
    (\ref{lemma:sem-weakening-cdiv}).

  \item[Inductive types]
    For the $\indelimname$/$\retname$ rule:
    \begin{equation*}
      \indelim{(\ret{v_s})}{\indretcase{x}{v_e} \seq \ldots} \stepstov \sbst{v_e}{x}{v_s}
    \end{equation*}
    the case follows from the computation rule of the recursor
    for the $\retcw{L}$ component and the global
    substitution lemma (\ref{lemma:sem-subst-global}).

    For the $\indelimname$/$op$ rule:
    \begin{align*}
      \indelim{(\indintro{op}{v_1}{v_2})}{H_1 \seq \indcase{op}{x_1}{x_2}{v_3} \seq H_2} &\stepstov \\
      \sbst{\sbst{v_3}{x_1}{v_1}}
      {x_2}{\abs{x_a}{\letv{x_w}{\app{v_2}{x_a}}{&\return{(\indelim{x_w}{H_1 \seq \indcase{op}{x_1}{x_2}{v_3} \seq H_2})}}}}
    \end{align*}
    the case follows from the computation rule of the recursor
    for the $\opcw{op}{L}$ component, using the global
    substitution lemma (\ref{lemma:sem-subst-global}) for $x_1$ and the
    local substitution lemma (\ref{lemma:sem-subst-local}) for
    $x_2$. Unfolding the semantics of abstraction, let, application and
    return, the value substituted for $x_2$ denotes the recursive
    application of the recursor to the continuation, up to the monad
    laws of $\mon$, standard equalities about products, exponentials and
    the strength, and weakening by the bindings of $x_a$ and $x_w$
    (\ref{lemma:sem-weakening-local}, \ref{lemma:sem-weakening-global}).

  \item[Functions]
    The case for the function beta rule:
    \begin{equation*}
      \app{(\abs{x}{c})}{v} \stepstoc \sbst{c}{x}{v}
    \end{equation*}
    follows from the universal property of exponentials and the local
    substitution lemma (\ref{lemma:sem-subst-local}).

  \item[Bind]
    The case for the bind/return rule:
    \begin{equation*}
      \letv{x}{\return{v}}{c} \stepstoc \sbst{c}{x}{v}
    \end{equation*}
    follows from the unit laws of the monad $\mon$, the unit axiom of
    its strength and the local substitution lemma
    (\ref{lemma:sem-subst-local}).

    The case for the bind commuting rule: 
    \begin{equation*}
      \letv{x_2}{\letv{x_1}{\perform{\loc}{op}{v}}{c_1}}{c_2} \stepstoc \letv{x_1}{\perform{\loc}{op}{v}}{\letv{x_2}{c_1}{c_2}}
    \end{equation*}
    follows from the associativity law of the monad $\mon$, the axioms
    of its strength and the local weakening lemma
    (\ref{lemma:sem-weakening-local}) applied to $c_2$.

  \item[Reflection]

    The cases for the $\outlname$ and $\outrname$ rules:
    \begin{align*}
      \perform{(\outl{v_1})}{op}{v_2} &\stepstoc \perform{v_1}{\mathrm{left}(op)}{v_2} \\
      \perform{(\outr{v_1})}{op}{v_2} &\stepstoc \perform{v_1}{\mathrm{right}(op)}{v_2}
    \end{align*}
    follow from the definition of the reflection morphisms
    (Section~\ref{sec:reflection}): precomposition with the Yoneda image
    of an injection maps the reflection of $op$ to the reflection of
    $\mathrm{left}(op)$ (respectively $\mathrm{right}(op)$).

  \item[Reification]

    The cases for the $\reifyname$ rules:
    \begin{align*}
      &\reify{\loc}{\return{(\gbox{v})}} \stepstoc \return{\ret{v}} \\
      &\reify{\loc_1}{\perform{\loc_1}{op}{v}} \stepstoc \return{\indintro{op}{v}{\abs{(\gbox{x})}{\return{\ret{x}}}}} \\
      &\reify{\loc_1}{\letv{x}{\perform{\loc_1}{op}{v}}{c}} \stepstoc \return{\indintro{op}{v}{\abs{x}{\reify{\loc_1}{c}}}} \\
      &\reify{\loc_1}{\perform{\loc_2}{op}{v}} \stepstoc \letv{(\gbox{x})}{\perform{\loc_2}{op}{v}}{\return{\ret{x}}} \qquad (\loc_1 \neq \loc_2) \\
      &\reify{\loc_1}{\letv{x}{\perform{\loc_2}{op}{v}}{c}} \stepstoc \letv{x}{\perform{\loc_2}{op}{v}}{\reify{\loc_1}{c}} \qquad (\loc_1 \neq \loc_2)
    \end{align*}
    follow from the definition of the reification isomorphism
    $\reifyc{\Sigma}{}$ (Section~\ref{sec:reification}). The first rule
    corresponds to the $\retcw{\sem{\Sigma}}$ component of the
    isomorphism in Lemma~\ref{lemma:sums2}, the second and third rules
    to its $\opcw{op}{\sem{\Sigma}}$ components, and the final two rules
    to the operations of the ambient theory, which the isomorphism
    leaves in place.

\end{description}
\end{proof}

\subsection{Contextual equivalence}

In order to prove adequacy we need to provide a precise definition of
contextual equivalence. The syntax of value and computation evaluation
contexts is given in Fig.~\ref{fig:execution-context}. We write
$\ctxv{v}$ and $\ctxc{v}$ for the value and computation respectively
obtained by replacing the $\_$ in the evaluation context with $v$.
\begin{figure}
\begin{align*}
  &\mathrm{value\ contexts}, \ctxv{\_} ::= \\
      &\qquad \_ \mid \abs{x}{\ctxc{\_}}
      \mid (\ctxv{\_}, v) \mid (v, \ctxv{\_})
      \mid \fst{\ctxv{\_}} \mid \snd{\ctxv{\_}} \\
    &\qquad \mid \inl{\ctxv{\_}} \mid \inr{\ctxv{\_}} \\
    &\qquad \mid \casem{\ctxv{\_}}{x}{v}{x}{v} \\
    &\qquad \mid \casem{v}{x}{\ctxv{\_}}{x}{v} \\
    &\qquad \mid \casem{v}{x}{v}{x}{\ctxv{\_}} \\
    &\qquad \mid \gbox{\ctxv{\_}}
      \mid \gunbox{x}{\ctxv{\_}}{v} \mid \gunbox{x}{v}{\ctxv{\_}}
      \mid \grun{\ctxc{\_}} \\
    &\qquad \mid \indintro{op}{\ctxv{\_}}{v} \mid \indintro{op}{v}{\ctxv{\_}}
      \mid \ret{\ctxv{\_}}
      \mid \outl{\ctxv{\_}} \mid \outr{\ctxv{\_}} \\
    &\qquad \mid \indelim{\ctxv{\_}}
             {\indretcase{x}{v} \seq
              \indcase{op}{x}{x}{v} \seq \ldots \seq
              \indcase{op}{x}{x}{v}} \\
    &\qquad \mid \indelim{v}
             {\indretcase{x}{\ctxv{\_}} \seq
              \indcase{op}{x}{x}{v} \seq \ldots \seq
              \indcase{op}{x}{x}{v}} \\
    &\qquad \mid \indelim{v}
             {\indretcase{x}{v} \seq \ldots \seq
              \indcase{op}{x}{x}{\ctxv{\_}} \seq \ldots \seq
              \indcase{op}{x}{x}{v}} \\[1em]
  &\mathrm{computation\ contexts}, \ctxc{\_} ::= \\
    &\qquad \return{\ctxv{\_}}
      \mid \letv{x}{\ctxc{\_}}{c} \mid \letv{x}{c}{\ctxc{\_}} \\
    &\qquad \mid \app{\ctxv{\_}}{v} \mid \app{v}{\ctxv{\_}}
      \mid \perform{\ctxv{\_}}{op}{v} \mid \perform{v}{op}{\ctxv{\_}}
      \mid \reify{\loc}{\ctxc{\_}}
\end{align*}
\caption{Syntax of evaluation contexts}
\label{fig:execution-context}
\end{figure}

We write
$\ctxv{\_} \types \Gamma_1 \turnv \tau_1 \trans \Gamma_2 \turnv \tau_2$
and
$\ctxc{\_} \types \Gamma_1 \turnv \tau_1 \trans \Gamma_2 \turnc \tau_2$
for the mutually inductive context typing relations that indicate that
if $\Gamma_1 \turnv v \types \tau_1$ then
$\Gamma_2 \turnv \ctxv{v} \types \tau_2$ and
$\Gamma_2 \turnc \ctxc{v} \types \tau_2$ respectively.

Two values are contextually equivalent if they reduce to the same normal
forms in closed boolean evaluation contexts.
\begin{align*}
\Gamma \turnv v_1 \ctxeq v_2 \types \tau \quad = \quad
&\forall \ctxv{\_}.
  \ctxv{\_} \types \Gamma \turnv \tau \trans \turnv 1 + 1 \\
  &\quad \implies \quad
  \forall \omega.
  \ctxv{v_1} \reducestov \omega \iff \ctxv{v_2} \reducestov \omega
\end{align*}

\subsection{Compositionality}

The denotational semantics is compositional:
\begin{lemma}
\label{lemma:compositionality}
\begin{align*}
  &\sem{\Gamma_1 \turnv v_1 \types \tau_1}
    = \sem{\Gamma_1 \turnv v_2 \types \tau_1}
  \quad \wedge \quad \ctxv{\_} \types \Gamma_1 \turnv \tau_1 \trans \Gamma_2 \turnv \tau_2 \\
  &\qquad \implies \quad
  \sem{\Gamma_2 \turnv \ctxv{v_1} \types \tau_2}
  = \sem{\Gamma_2 \turnv \ctxv{v_2} \types \tau_2} \\
  &\sem{\Gamma_1 \turnv v_1 \types \tau_1}
    = \sem{\Gamma_1 \turnv v_2 \types \tau_1}
  \quad \wedge \quad \ctxc{\_} \types \Gamma_1 \turnv \tau_1 \trans \Gamma_2 \turnc \tau_2 \\
  &\qquad \implies \quad
  \sem{\Gamma_2 \turnc \ctxc{v_1} \types \tau_2}
  = \sem{\Gamma_2 \turnc \ctxc{v_2} \types \tau_2}
\end{align*}
\end{lemma}
\begin{proof}
  By induction on the evaluation context typing rules. All the
  denotations only refer to subterms via the denotations of those
  subterms, so all the cases that correspond to typing rules go through
  directly using the induction hypothesis on the subterm that is an
  evaluation context. The other case is for the $\_$ rule, which goes
  through by hypothesis.
\end{proof}

\subsection{Adequacy}

The denotational semantics is adequate with respect to the operational semantics.
\begin{equation*}
    \sem{\turnv v_1 \types \tau} = \sem{\turnv v_2 \types \tau}
    \implies \turnv v_1 \ctxeq v_2 \types \tau
\end{equation*}
\begin{proof}
  Given a context $\ctxv{\_}$ such that
  $\ctxv{\_} \types \turnv \tau \trans \turnv 1 + 1$, we know by
  confluence (\ref{lemma:church-rosser}) and strong normalization
  (\ref{lemma:strong-normalization}) that there is a unique normal form
  $\omega_1$ such that $\ctxv{v_1} \reducestov \omega_1$ and a unique
  normal form $\omega_2$ such that $\ctxv{v_2} \reducestov \omega_2$. We
  know by subject reduction (\ref{lemma:subject-reduction}) that these
  normal forms are either $\inl{()}$ or $\inr{()}$. We also know by
  compositionality (\ref{lemma:compositionality}) and soundness
  (\ref{lemma:soundness}) that
  $\sem{\turnv \omega_1 \types 1 + 1} = \sem{\turnv \omega_2 \types 1 +
    1}$. Since we know that
  $\sem{\turnv \inl{()}} \neq \sem{\turnv \inr{()}}$ it must be the case
  that $\omega_1 = \omega_2$.
\end{proof}

\section{OxCaml implementation}
\label{apdx:implementation}
The implementation of our OxCaml effect reflection interface in terms of
unchecked effects\footnote{For convenience, we use the new handler
  syntax from OCaml 5.3. However, the most recently released version of
  OxCaml is based on OCaml 5.2 so the actual implementation uses
  \lstinline[style=oxcaml]{Effect.Deep.match_with} instead.} is shown in
Fig.~\ref{fig:implementation}. It assumes that handlers can close over
local values to implement \lstinline[style=oxcaml]{reify} -- but not
\lstinline[style=oxcaml]{reify_global}. Unfortunately, this is not yet
permitted by OxCaml due to the runtime not supporting pointers to stack
allocated values from different fibres. If stack allocation were
disabled then this code would be allowed.
\begin{figure}
\begin{lstlisting}[style=oxcaml]
module Handler (E : Sig) = struct

  type t = { perform : 'r. 'r E.t -> 'r }

end

module Reflection (E : Sig) = struct
  open Term(E)
  open Handler(E)

  let reify f = exclave
    let module Eff =
      struct type 'a Effect.t += C : 'a E.t -> 'a Effect.t end
    in
    let handler = { perform = fun o -> Effect.perform (Eff.C o) } in
    match f handler with
    | v -> Return v
    | effect Eff.C o, k -> Perform(o, fun x -> Effect.continue k x)

  let reify_global f =
    let module Eff =
      struct type 'a Effect.t += C : 'a E.t -> 'a Effect.t end
    in
    let handler =
      { perform = fun o -> Effect.perform (Eff.C o) }
    in
    match f handler with
    | v -> Return v
    | effect Eff.C o, k -> Perform(o, fun x -> Effect.continue k x)

  let perform t =
   fun h -> h.perform t

end

module Select (L : Sig) (R : Sig) = struct
  open Sum(L)(R)

  let outl ({perform} : Handler(Sum(L)(R)).t) : Handler(L).t =
    exclave {perform = fun op -> perform (Left op)}

  let outr ({perform} : Handler(Sum(L)(R)).t) : Handler(R).t =
    exclave {perform = fun op -> perform (Right op)}

end
